适用于 Windows、macOS 本地桌面版 VS Code 1.105+

01

安装插件

下载 VSIX，在 VS Code 扩展面板的“…”菜单中选择“从 VSIX 安装”。

02

直接使用

原型工作台可以打开 .gameflow.json 文件，也可在命令面板中运行“原型工作台: 新建策划画布”。

03

新版提示安装

启动后自动检查自身新版，点击“安装更新”后才下载安装。需要重载时，先保存文档，再按 VS Code 提示操作。
