# PSD 画布点选图层

Status: Done
Date: 2026-11-13
Scope: 切图画布点击选层与拖动平移的手势区分。

## Context and Behavior

目前 PSD 画布只支持拖动平移，选层必须在树中完成。用户要求直接点击画面元素选择。

- 左键轻点 PSD 元素：将屏幕坐标转换为 PSD 坐标，按从上到下的图层顺序选择命中的可见内容层。文字按文字区域选择；图片透明像素穿透到下层。分组、隐藏层和无图片层不拦截；蒙版/特殊混合继续遵循基础像素预览限制。
- 点击画布空白清除选择。图层树高亮并展开祖先、滚动到选中层，右侧属性与画布选框同步。选择不改变切图勾选和文档配置。
- 左键移动超过 4 屏幕像素进入平移，拖动结束不更改选层。中/右键仅平移。取消手势、失去捕获、模式切换不触发点选。
- PNG 透明度命中图按需读取并缓存，仅保留 1 bit/像素的内存掩码，不进入 PSD/sidecar。解码期间有后续操作则丢弃过期选层结果。
- 保留现有跟随面板、缩放和九宫格操作。面板内部点击不穿透到 PSD。

## Acceptance

- 测试图层堆叠、透明穿透、文字区域、隐藏和分组、画布外坐标、拖动阈值及不同缩放坐标映射。
- 浏览器真实点击标题、按钮底图及文字，确认树/属性/选框一致；拖动不误选，缩放后点选仍正确，折叠分组可被选层展开。
- 类型检查、构建、共享测试及 diff 检查通过。

## Limits

本轮不增加图层移动或像素编辑；选中效果层时仍显示既有基础像素限制。未执行的 Extension Host 检查需明确记录。
