# PSD 组件智能对象

Status: Done

日期　2026-11-25

## 生成与编辑

生成页面 PSD 时，画布中已经解析的组件实例写成嵌入式智能对象。每个实例保留自己的名称、位置和 GameFlow 图层身份。相同组件的相同内容共用一份内嵌 PSD，位置、名称及可见性各自独立。内容不同的实例使用各自的内嵌 PSD。内嵌文档保留文字和图层，供 Photoshop 编辑。

## 同步

同步把组件实例作为页面中的单个节点处理。已有普通组件组在审阅中提供「转换为智能对象」，用 PSD 现有组内容进行转换。新增实例使用原型内容生成智能对象。已有对象支持补入原型新增图层。现有内嵌图层的美术编辑在 Photoshop 中完成。后续同步保留未修改的智能对象、已保存像素和内嵌文档，原型页面保留组件引用及实例修改。其他 PSD 扩展数据继续走既有保真检查。

## 美术工作区层级

星海登录 PSD 的「服务器列表项」是外层智能对象，「服务器名称」保存在它的内嵌 PSD 中。原有图层树只读取外层结构，导致智能对象显示成普通图片且没有可展开层级。

美术工作区以智能对象图标标出对象图层，已有内嵌 PSD 的对象可展开查看文字、分组及像素层。内嵌树来自当前 PSD 文件并以只读方式呈现，选中外层对象时继续使用其整层像素和切图配置。图层顺序按 PSD 的前景到背景呈现。列表模板的运行预览行仍由原型工作区铺排。

## 同步组件新增图层

星海登录页的组件模板新增「图片」后，页面同步原先只比较「服务器列表项」的外层节点，预演漏掉了智能对象内缺少的图层。

页面审阅对 GameFlow 生成的智能对象检查原型内新增的可生成图层。按父层级、名称、类型和同名项顺序对应现有内嵌层，在外层节点下列出缺少的图层并提供「补入智能对象」。预演将生成的新图层合入已有内嵌 PSD，保留已有图层的文字和像素、外层图层 ID 和智能对象的位置。其他实例通过原有引用继续共享旧内容。再次比较时，已补入的图层应消除对应差异。

## 验收

- 星海登录页的「服务器列表项」可从生成入口导出，也可在当前 PSD 的同步审阅中转换。打开同步后预览并应用后，重新比较结果一致。
- 两个相同实例引用同一份内嵌 PSD。不同内容各自独立，内嵌文字可读回为文本层。
- 在带智能对象的 PSD 中同步另一个控件，原有智能对象和内嵌文档保留。

## 验证

真实 VS Code 使用星海登录页临时副本完成现有 PSD 的预演、覆盖、重新比较和新建 PSD。浏览器测试验证了不同位置及旋转的实例可以共享内嵌 PSD，内容不同的实例分别保存，已有美术文案保持为文字层，后续写回保留原智能对象，并可新增智能对象。已有双向和单向同步浏览器测试、397 项共享测试及生产构建通过。当前环境缺少可运行的 Photoshop，双击编辑及保存的 Photoshop 实测待完成。

美术工作区回归曾在「服务器列表项」缺少展开状态处失败。修复后真实 VS Code 和 Chrome 均可展开、收起「服务器名称」并选中外层智能对象查看实际尺寸和图层 ID。内嵌行只读，PSD 和切图配置经字节比对一致。普通层选框、切图工作区切换、397 项共享测试和生产构建通过。

真实 VS Code 在星海样例临时副本上列出「图片」，同步后预览发生变化，覆盖后验证「服务器名称」原像素一致、外层 ID 与置入变换一致、切图配置指纹正确，再次比较为零项。Chrome 覆盖组件模板新增图片、保留原有美术文案及重新比较。普通双向、单向同步浏览器回归、397 项共享测试和生产构建通过。
