# PSD 切图导出区域

Status: Done
Date: 2026-11-18
Scope: 切图属性“编辑区域”、透明留白/裁剪、PNG 导出及九宫格坐标、配置持久化。

## 1. Context

图层实际像素范围可能小于要求的导出尺寸。当前 PNG 和九宫格直接使用图层宽高，无法保留指定画布和透明留白。

## 2. Goals

- 在九宫格配置下方提供“编辑区域”，独立设置导出矩形。
- 保持图层像素原尺寸，超出内容部分透明，区域内只包含当前层。
- 预览、九宫格和实际导出使用相同区域；保存、重开、草稿及撤销/重做保留区域。

## 3. Non-Goals

不修改 PSD 图层像素/位置，不缩放内容，不重建组或高级图层效果，不增加引擎专用格式。

## 4. Current Behavior

SliceConfig 只有命名、共享及九宫格设置。makeSliceExportBatch 直接使用解码后的原始 PNG 和图层宽高。

## 5. Proposed Behavior

- 属性面板新增区域摘要、恢复原始区域和“编辑区域”按钮。弹窗设置导出宽高，再拖动图片调整图片位置；方向键移动 1 像素，Shift+方向键移动 10 像素，并提供图片 X/Y 整数输入、居中、恢复原始和实时裁剪预览。确认才提交一次历史；取消和 Escape 不修改配置。
- 导出大小和图片位置的两行字段共用固定宽度的单字标签列，宽/X、高/Y 输入框左右边缘及 px 单位上下对齐，窄窗口保留该对齐。
- 四条边线可拖动调整导出区域，保持对边和图片在预览中的位置不变；宽高及图片相对位置同步到输入框。按当前缩放换算为整数像素，并限制有效尺寸、偏移、总像素及九宫格最小中心。
- 边线复用九宫格编辑器的贯穿虚线样式：纵线贯穿预览高度、横线贯穿预览宽度，不显示左/右/上/下文字，保留无障碍名称，整条线均可拖动；导出矩形不再叠加蓝色实线外框。
- 滚轮围绕鼠标缩放预览（1%–1600%），提供缩小/放大/适应窗口；右键拖动平移视图。缩放和平移只影响查看，不改变导出宽高、图片位置或保存数据。拖动时不自动适应窗口，避免边线跳动。
- “图片居中”和“恢复原始区域”以图标放在预览右下角工具栏的缩放控件左侧，保留悬停提示和无障碍名称；输入区不再重复放文字按钮，原图尺寸移至确认/取消所在页脚。
- 弹窗可拖动标题栏移动，标题栏使用普通箭头指针，关闭按钮独立响应；右下角有拖动缩放手柄，支持方向键调整窗口大小。窗口受可视范围和最小尺寸约束，浏览器缩小时自动回到可视范围，预览随窗口大小伸缩。窗口移动/缩放不改变导出尺寸、图片位置或历史，重新打开恢复默认布局；拖动取消或失焦恢复手势前布局。
- 预览区获得键盘焦点时不显示外侧蓝色聚焦框，保留导出范围边线和键盘微调能力。
- 持久化区域 X/Y 相对图层内容左上角；负值允许透明外扩。弹窗图片位置为其相反数，例如 217×77 内容在 300×100 输出里居中显示为图片 X=41、Y=11（region.x=-41、region.y=-11）。奇数差值居中向下取整，透明像素差最多 1。
- 区域允许裁剪，展示实际导出预览；宽高 1–4096 且总像素不超过 8,000,000，X/Y 限定在 -4096–4096。
- 九宫格四边距相对导出区域。改变区域不自动改变已设置边距；若新尺寸使中心不足 1 像素，弹窗阻止确认并提示先调整九宫格。恢复原始区域同样验证，不能静默清除九宫格。
- 画布保留图层内容选框，另外显示自定义导出区域。配置区域不会自动勾选导出。

## 6. Design

- 可选 SliceConfig.region: { x, y, width, height }；缺省表示原图层范围，不在读取时插入默认值。保持 v1 元数据/sidecar 的可选扩展和未知字段保留规则。
- shared/psd-meta.ts 统一区域解析/验证，validConfig 使用有效区域尺寸检查九宫格；宿主、Worker、sidecar、草稿共用边界。
- Webview 通过透明 Canvas 按 -x/-y 绘制原始层图，不读取整图其他层。导出前逐层生成 PNG；共享批次构建必须显式接收已渲染的自定义区域 PNG，防止仅修改声明尺寸而仍导出原图。
- 目录清单沿用现有格式，尺寸记录实际 PNG 的区域宽高。九宫格编辑与拉伸预览使用同一像素渲染函数；区域只作为切图配置持久化，不更改 PSD 几何。
- 弹窗布局独立于 region/相机，用本地矩形保存位置和尺寸；标题栏与缩放角使用指针捕获，取消/失焦清理手势，视口变化重新限制边界。布局不持久化；预览 ResizeObserver 继续保持相机居中与缩放。
- 区域弹窗相机独立于 region；拖动左/上边时相机原点同步补偿，使图片和对边固定。`region-geometry.ts` 负责边线尺寸限制、视图适应及鼠标定点缩放，集中测试真实坐标约束。

## 9. Acceptance Criteria

- 217×77 层能够导出 300×100 的 PNG，内容不被拉伸，留白透明。
- 修改区域后九宫格编辑/预览与输出尺寸一致；无效输入不能提交。
- 区域取消不改变配置，确认一次可撤销、重做，保存重读及草稿恢复保留设置。
- 无 region 的已有 PSD 配置保持原图输出。
- 四边线拖动与宽高/位置输入同步，缩放后仍按正确像素调整；滚轮只缩放视图，取消弹窗保留原配置；两行输入框在宽/窄窗口均对齐。
- 边线旁无方向文字；标题栏可移动弹窗，右下角可缩放弹窗和预览，最小尺寸和视口边界有效，关闭/确认/取消及原有图片编辑可用，窗口操作不修改导出参数。
- 类型检查、共享测试、生产构建通过，实际验证范围记录在本文。

## 10. Risks and Rollback

透明大画布增加内存，通过现有单图导出像素边界和逐张编码控制。旧版工具不理解新增区域；升级版本作为该配置的编辑/导出入口。移除可选 region 即恢复原尺寸；PSD 原始像素始终保留。
