# Simplified Game UI Prototype Editor

Status: Done
Date: 2026-11-12
Scope: 参考 Figma 核心编辑体验，建立面向游戏策划的可用单人低保真 UI 编辑闭环。

## 1. Context

现有工作台具备插入和导航，缺少控件选择、变换与属性编辑。用户要求简化版 Figma，并明确总览不需要左侧页面列表/需求分析侧栏；只有双击进入页面后才显示当前页面的控件层级树。

## 2. Goals

- 总览以画布为中心，双击页面进入编辑，返回保留总览相机。
- 右侧属性采用画布上的悬浮面板，带间距、边框阴影，可拖动、收起/展开和关闭/重开。
- 页面内部显示真实父子层级树，与画布和属性面板联动。
- 节点单选、拖动、八点缩放、文字/样式属性、图片导入、复制删除、层级排序、隐藏锁定、修改父容器。
- 页面新增、重命名、尺寸和背景设置、复制删除。
- 编辑器外壳使用 VS Code 主题变量、字体和紧凑间距，与宿主主题一致；游戏控件外观独立。
- 固定工具条、常用快捷键、撤销/重做与保存。

## 3. Non-Goals

多人协作、完整 Figma 兼容、矢量路径、自动布局、组件变体、AI 接入与 LayaAir 导出。

## 4. Current Behavior

所有节点视图只读；左侧总览侧栏占用画布空间；图片仅占位。父子节点尚未按父局部坐标正确投影。浏览器预览刷新即丢失编辑。

## 5. Proposed Behavior

用户在总览新增并摆放页面，双击后通过控件工具创建内容。页面编辑模式左侧显示可折叠控件树，右侧随选中对象提供属性。父容器移动时子控件跟随；更换父容器保留视觉位置并拒绝循环父子关系。拖动/缩放只在松开时提交一个文档事务；取消不提交。文本和数值字段失焦或 Enter 提交。图片通过本地文件选择导入，嵌入文档，随保存重开恢复。

## 6. Design

- 维持 TextDocument 权威；Webview 编辑请求按确认串行提交，防止快速编辑使用陈旧版本。
- 文档编辑确认后再执行排队的保存/历史命令；历史命令完成前的新编辑基于返回快照重放。命令用固定 `commandCompleted` 确认，不能将重复文档广播误当作命令完成。合并编辑回到已提交快照时不重复提交相同内容。
- 可选 node `style`、`imageData`、`hidden`、`locked` 与 page `background` 向后兼容 schema v1。
- 节点 frame 坐标相对 parent；根节点相对页面。共享纯操作处理子树复制/删除、父变更与世界坐标。
- 仅固定 `undo`/`redo`/`save` 消息由宿主执行已定义命令，不允许任意命令。
- 浏览器适配器复用验证，使用本地存储恢复文档，提供本地撤销重做；与 VS Code 原生文档历史区分实现。
- 图片仅允许 PNG/JPEG/WebP/GIF data URI，单图最多 5 MB，不依赖远程资源。

## 7. Implementation Plan

1. 扩展兼容数据字段、纯编辑操作与协议。
2. 分离画布、树、属性与文档适配逻辑，形成真实编辑器。
3. 完成样式与缩放导航，验证本地预览交互与存储。
4. 类型检查、共享/宿主边界测试、生产构建及规格同步。

## 8. Testing Plan

纯测试验证父局部坐标、重设父级防环、子树复制映射、子树删除清理、样式/图片校验。浏览器验证总览无侧栏、页面内部层级、选中移动缩放、编辑属性、复制删除撤销重做、刷新恢复、图片上传和窄视口。构建与 diff 检查。真实 Extension Host 未完成交互验收时须注明。

## 9. Acceptance Criteria

- [x] 总览无左侧侧栏，双击页面后才显示控件树。
- [x] 树/画布选中同步，容器移动子控件跟随；变换可取消。
- [x] 创建、移动、缩放、编辑文字/样式、复制删除可保存。
- [x] 修改父级防环且保持页面视觉位置。
- [x] 图片导入、页面管理、撤销重做可使用。
- [x] 浏览器刷新恢复，快速编辑不会丢失后续修改。
- [x] 类型检查、测试、构建通过，并记录交互验收边界。

## 10. Risks and Rollback

全量 JSON 与嵌入图片适合小型低保真文档；大量图片以后需要资源管理。保持兼容可选字段；回退编辑器 UI 不需迁移既有文件。
