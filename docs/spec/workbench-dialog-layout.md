# 工作台弹窗布局

Status: Implementing

日期　2026-11-23

## 范围与目标

以原型「页面属性」为工作台自绘弹窗的视觉基准。现有同步窗、资源选择器和导出提示各自定义标题高度、底色与操作间距，预制体同步还把三个来源的值拼在同一行，长文案难以比较。

## 设计与实施

1. 自绘对话框复用属性浮窗的主题色、边框、圆角、34px 标题栏和右侧关闭按钮。标题栏保留已有的拖动处理或工具。需要确认的动作放在底部，沿用各窗口的焦点、取消和提交方式。
2. 一般表单用标签和值对齐。同步窗在正常宽度下使用节点树、双画板预览、属性详情三列，属性详情不再占用预览下方空间。标题栏展示当前目标，按字段分组展示差异，在组内逐行对齐上次值、原型值和目标值。预览随弹窗可用高度放大，画板外侧使用切图编辑器同款棋盘背景。长路径和值可查阅，选择与状态在窄窗口仍可操作。
3. 范围涵盖原型、PSD 和独立 PSD 编辑器中的工作台对话框。系统文件选择器及 VS Code 原生对话框由宿主绘制。
4. 预制体和 PSD 同步窗的节点树复用图层列表的树行。分支使用相同的展开箭头，叶节点预留同宽位置，名称前显示控件类型图标，变量名靠右。行高 28px，子级逐层缩进 10px，选中高亮覆盖整行。同步差异标记和仅预制体组件可随节点查看。

## 验收

- 对照页面属性检查标题栏、关闭按钮和外框。设置、重命名、资源选择、预览与确认窗共用同一结构。
- 从原型工作台打开预制体同步，在宽、窄视口检查差异值与处理方向，执行预演、确认、查看只读组件及关闭。验证 PSD 同步入口也采用该结构。
- 运行类型检查、生产构建与相关浏览器回归。回退可限于 Webview 界面层。
- 展开有挂载组件的节点，比较父子行的图标、行高和左边距。单击箭头只切换展开状态，单击名称切换选中节点及详情。
- 正常宽度下详情栏位于双画板右侧，双画板不因详情内容增多而变矮。两块预览使用棋盘背景且无纯黑留白。窄窗口依次排列节点树、预览和详情，均可滚动查看。
- 右下角缩放手柄使用指针捕获。居中弹窗的宽高按指针位移双倍变化，使右边缘和下边缘始终跟随指针。拖动完成立即保存尺寸，关闭并重新打开后恢复相同宽高。

## 验证记录

三列调整的根因是预览和属性详情共用同一纵向 sync-body，同时预览高度上限固定为 310px。现拆为独立的 sync-main 与 sync-detail，弹窗默认最大宽度提升到 1280px，旧尺寸键升级一次。Edge 验证详情位于双画板右侧、预览高度超过 310px、背景使用与切图编辑器相同的渐变棋盘；400px 窄窗口按节点树、预览、详情依次排列。预制体与 PSD 同步端到端回归、376 项共享测试和生产构建通过。

同步树原先各自递归绘制按钮，预制体使用文字符号，名称按钮实测为 24px。改用图层行后，同一 Edge 回归测得行高 28px、展开图标 12px、类型图标 14px、父子图标横坐标相差 10px，折叠及重新展开后仍可选择挂载组件查看参数。预制体和 PSD 同步端到端检查、376 项共享测试与生产构建通过。

生产构建与 377 项共享测试通过。Edge 从工作台完成预制体同步的文案冲突预演、提交与重新比较，校验三行的实际值、标题栏与属性面板等高、400px 窗口内节点树位于详情上方。PSD 同步的双向应用、重开和调整尺寸通过。资源模式的 17 项检查覆盖内置图片选择、窄窗口布局、运行预览及导出确认。
