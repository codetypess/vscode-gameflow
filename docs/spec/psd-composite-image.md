# PSD 切图组作为合成图片

状态：已完成
日期：2026-11-26

## 使用场景

按钮的普通态可以由一个叫 `@normal` 的 PSD 组制作。美术把底图、描边和高光放在组内，原型按钮使用一张普通态图片。现有切图渲染器支持整组渲染，图层树、画布直选和资源枚举仍会访问组内各层。

## 交互与数据

- 在切图属性的导出设置中，PSD 组可勾选「合成图片」。勾选时同时标记该组为切图，之后可独立调整导出开关。
- 合成组在切图树中显示为图片。画布直选命中组内像素时选中该组，双击遵循图片行为。父组中的其他状态和按钮文案继续独立显示。
- 勾选「合成图片」后，该组的图层行在眼睛按钮左侧显示叠图图标，悬停提示「合成图片」。切换「标记为切图」时保留此标记，取消合成后移除。撤销、重做或重开配置时按当前合成状态显示。
- 原型状态绑定、PSD 同步、资源预览和 PNG 导出只使用合成组的公开层级。组内已勾选的子切图暂停单独导出。整组沿用现有图层身份、名称、渲染、区域与九宫格逻辑。
- 可选布尔字段 `SliceConfig.composite` 随草稿、同名配置和 PSD 元数据副本保存。默认关闭。保存时保留物理图层和子切图配置，取消勾选恢复子层及各自设置。

## 实现与验收

1. 在共享模型中区分切图层级和原始 PSD 层级，覆盖嵌套、导出及状态绑定。
2. 接入切图面板、画布和同步界面，验证组的选择、撤销重做及重开恢复。
3. 用含描边和高光的状态组验证整组像素、唯一输出、兄弟节点和配置往返，运行共享测试及生产构建。

## 验证结果

- Chrome 打开包含 `Start / @normal / 描边、高光` 的 PSD。勾选后点击高光命中状态组，保存重开和撤销重做均保留预期层级，解除合成后高光仍保有原切图标记。读取已保存配置并导出，得到一张 40 × 20 的普通态 PNG，两处取样分别匹配描边和高光。
- 本机 PhotoCraft CLI 渲染带 3 像素 Photoshop 外描边和独立高光的状态组。逐像素抽查确认外描边、高光、底色符合源颜色，组外文案位置透明。
- 工作区缺少已从样例目录删除的星海登录原型 JSON。在临时副本内补齐版本库样例后，413 项共享测试、类型检查和生产构建通过。
