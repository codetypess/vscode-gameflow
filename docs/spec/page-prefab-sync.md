# 原型与 Laya 预制体同步

Status: Done

首版实施（2026-11-23）：沿用工作台现有文档保存与撤销，将独立的预制体同步基线放在页面的 `prefabSync` 字段。提交时复核目标文件摘要与原型工作副本，按已选字段补丁修改实际 .lh。预制体使用静态控件预览；复杂脚本和引擎组件作为只读详情。首次配对使用节点身份，独立新增使用稳定映射。

日期　2026-11-20

## 场景与入口

策划和开发从一次页面导出开始协作。策划给登录页加「帮助」按钮，开发在 Laya 里加「公告」按钮、给登录按钮挂防连点脚本，还把登录文案改了。同步后应能在两边看到两个新按钮，游戏仍能运行原有脚本。双方改过的同一处文案由人选定。

当前画布底部「导出」图标按当前页面生成整份 `.lh`，同时处理图片、导入元数据及来源清单；页面有 Prefab 目标关联后图标切换为「同步」。节点和页面 ID 已写入 `_$id`。底部「预制体」资源模式使用原型节点树和磁盘图片。同步审阅需直接读取实际目标 `.lh`。[导出实现](../../shared/prefab-export.ts) · [现有资源模式](11-prototype-ui-layout.md)

入口位于画布底部「更多」左侧。首次生成时沿用现有导出并记录共同版本；目标已存在时进入「同步预制体」。初次遇到无同步记录的同名文件时先审阅关联。页名、导出名或目录变化时同时显示已关联路径和拟用路径，由用户确认继续关联、重新定位或生成独立文件。明确选择当前页后方能操作。

## 页面与操作

沿用正在实施的 PSD 同步窗。页面名与目标相对路径位于标题栏，左侧为完整节点树，中间为使用切图棋盘背景的原型与目标双画板，右侧为属性差异和只读组件详情，底部为「待决定 / 已选」和「预演应用」。窗口不显示独立缩放按钮，鼠标移到任一边缘或角落后直接拖动调整宽高；边缘通过指针捕获跟随鼠标，拖动结束保存尺寸并在重开时恢复。切换节点、打开明细时外框稳定，内部滚动，底部操作始终可见。窄屏时节点树、双画板和详情依次纵向排列。[PSD 同步方案](page-psd-sync.md) · [当前同步窗](../../webview/editor/page-sync-dialog.tsx)

1. **定位节点。** 用上次同步、当前原型和目标文件的节点并集形成完整树。树中显示名称与变量名，变更分支默认展开，未改节点可选中。双画板的原型与预制体预览都可直接点击控件区域选中同一节点；重叠时按当前绘制顺序选最上层，已删除节点仍可点击原位置的虚线框定位。新增绿「+」、删除红「−」、修改黄「~」。树和双画板使用相同标记，缺失的已删除节点在原位置显示虚线框。只更新了脚本时，仍能展开整棵树，待同步为零。
2. **切换「当前 / 同步后」。** 当前画面分别取原型工作副本与磁盘 `.lh`。原型用内置资源，预制体预览按目标自己的层级、布局和资源引用绘制可识别的静态 UI。脚本显示在所属节点下，选中时定位预制体的挂载对象并显示参数。动画和未知组件列出类型、挂载点及引用。资源缺失显示占位和路径。
3. **逐项采纳。** 右侧详情栏显示上次值与双方当前值。单边新增给出目标建议，双方改同一字段时可选择来源或「本轮跳过」。除结构、文案和基础几何外，原型属性面板中具有明确 Laya 往返表达的页面尺寸、变量、可见性、变换、透明度、布局约束、容器布局、文字样式和控件设置都逐字段参与比较与双向应用。选择后自动进入「同步后」，两幅画面按本轮所有决定一起更新，随时可切回「当前」。整棵新增子树计为一项，展开或点选其文案均指向同一决定。
4. **预演与提交。** 待决定项全部处理或明确跳过后，可打开「本轮应用明细」。分别列出原型编辑、实际目标 `.lh` 和随附资源的写入、受影响的引擎组件及跳过项。可返回调整，确认时才提交。跳过项在下次比较继续出现。[登录页交互稿](../design/page-prefab-sync.html)

**属性审阅。** 每项属性标出变动来源。「原型已改」和「预制体已改」展示上次同步值到当前值的变化，预选写入另一侧。「双方已改」同时列出上次同步值与双方现值，由用户决定。首次对照、旧记录缺少该字段或该字段从未达成一致时，显示「上次同步值　未记录」并等待选择。上次同步值取自当前页面针对目标文件的 `prefabSync` 记录，已记录的关闭、零、空文本和未设置值均有各自的显示。本轮选择器直接写明接收方和将写入的值，也可选「本轮跳过」。结构项说明新增、删除或仅存于哪侧，沿用子树决定与组件影响提示。

每个属性的「本轮」直接列出互斥的单选项，选项可点击文字或用方向键切换。已有建议的选项预选并标注「推荐」，改选后标记仍跟随原建议。冲突或缺少上次值的属性初始留空，新增结构项仅列出可执行的补入与跳过操作。

验收覆盖两种单边修改的预选方向、双方修改、旧记录缺少自动换行值、按属性独立的键盘改选与跳过、双预览以及确认提交后的重新比较。

实现时从现有同步窗提取窗体尺寸、树、选中框、预览切换、逐项决定与明细展示。保留 PSD 与预制体各自的读取器、可同步字段、预览生成及提交流程。预制体由实际 `.lh` 生成静态预览，按路径修改同一关联文件并保留引擎字段。页面与预制体有独立同步记录，同一页面的 PSD 同步进度单独保存。

## 合并规则

| 相对于上次同步发生的变化 | 默认建议及实际写入 |
| --- | --- |
| 原型新增「帮助」，预制体新增可识别的「公告」 | 两项分别建议写入对方。父级已配对、身份唯一且顺序相容时可以一起应用。每个带文案的新增按钮按一棵子树计一次。 |
| 同一节点的不同字段分别被修改 | 独立合并。例如原型改宽度、预制体改文案，两项可同时采纳。双方把同一字段改成同一个值时直接记为一致。 |
| 双方将同一字段改成不同值 | 并列展示三个值。例如「登录」分别变成「进入游戏」和「开始冒险」。选一个值写入另一侧，或跳过该字段。 |
| 预制体添加脚本、动画、材质、特效、未知组件或属性 | 原样保留在现有预制体对象和子树中，显示「仅预制体」，不计入待处理。原型独有的交互、备注和编辑状态同理保留在原型。 |
| 删除、移动及重排 | 单边删除列为待确认，列明所有受影响子孙、组件和已知引用。删除遇到另一侧修改或独有后代时默认保留并待决定，可跳过或先迁移子项与引用。同一节点被移动到不同父级、位置约束互斥时显示冲突。 |
| 独立新增同名、重号或身份不明 | 稳定 ID 与映射确定对象；名称和路径用于定位。两个不同 ID 的同名控件可并存，若变量名等约束冲突则先改名或跳过。重复 ID 提示具体位置并暂停相关子树。 |

同步属性映射与 Prefab 导出契约保持一致，不另建一份只覆盖文案和坐标的白名单。具有确定双向语义的字段包括页面设计宽高与根约束、变量、可见性、锚点/缩放/倾斜/旋转、透明度、节点约束和容器布局、文字字号/颜色/粗斜体/下划线/删除线/对齐，以及控件状态、范围、输入、选项、文字排版和节点引用。字段采用原型属性路径作为稳定身份，缺省值与显式值按目标语义归一后比较；只应用用户选中的字段，其他原型与引擎属性保持不变。控件改型仍要求重新确认关联；无法反解的外部皮肤 UUID、图片内容、动画、业务脚本与其他引擎专属字段继续由目标工程管理。预制体新控件使用原型默认内置外观，首次推入所需资源沿用现有导出策略。

属性缺失必须按所属一侧的真实运行时语义归一，不能把原型默认值直接当作 Laya 默认值。例如 GameFlow UILabel 未设置 `wordWrap` 时按开启显示，而 Laya `Text.wordWrap` 缺失时运行时默认为 `false`；同步读取缺失字段应显示“否”。从原型导出时若原型有效值为开启，则必须显式写入 `wordWrap: true`，确保导出产物与原型预览一致。

双画板必须使用同一个原型设计画布宽高计算缩放，即使 Laya 根节点宽高已变化也保持相同屏幕尺度，并把根宽高差异单独列入右侧。这样同一坐标和尺寸在两侧占用相同像素，字体、变换与布局差异不会被独立缩放掩盖。

## 同步记录与写入

- 页面字段 `prefabSync` 以文档 ID、页面 ID 和目标相对路径区分关联，保存节点映射、上次协调的字段值、父级与相对顺序。首次生成成功才记录起点。旧项目首次接入按 ID 对应，同值建立基线，不同值或单侧存在的对象由用户决定。整页复制时清除副本的关联。
- 新增控件跨侧导入时尽量保留目标合法且未占用的身份，否则分配目标 ID 并记录映射。同批父子和控件引用一起重映射，目标模型验证后才可提交。以稳定同级节点为位置锚点保留原有的引擎子节点顺序；同一空隙的独立新增须使用双方一致、可预览的顺序。
- 预制体从磁盘读入完整对象树，针对已选路径编辑。脚本属性、未知组件及专属子树直接沿用原对象，保留既有 `_$id`、`_$ref` 及资源 UUID。删除会损坏已知引用时要求先解决依赖。引擎专用内容只作为上下文浏览，不反复提示。
- 原型编辑走现有宿主文档与历史机制。提交复核工作副本版本、两根目录及目标文件摘要，检查未保存的目标文件。审阅期间外部保存后可点「重新比较」，重新选择发生冲突的字段。
- 导出事务暂存本轮文件改动，完成写入并再次检查原型后，将原型编辑和同步记录作为一次工作台修改。用户按普通保存流程持久化原型。写入失败时按内容复核并恢复，外部随后写入的数据留给用户检查。工作台撤销原型修改后可再次比较。扩展进程意外退出时，重新读取实际文件与已保存基线再审阅。

## 实施与验收

| 阶段 | 验收场景 |
| --- | --- |
| 只读比较与首次关联 | 用首次生成、已有同名文件、目标改路径、复制页面四种情况验证身份；审阅及取消后所有文件摘要相同。 |
| 与 PSD 预览一致 | 两种窗口用相同操作定位未改节点、新增文案子节点及已删节点；分别点击左右预览的不同控件，节点树、选中框和属性详情必须同步切换。采纳、跳过后逐侧核对「当前 / 同步后」、颜色符号、计数与应用明细。拖动调整后重开保留尺寸，展开树和打开明细时外框稳定。只有脚本变化时，仍可查看挂载点和参数，待同步为零。 |
| 双向合并与引擎保留 | 同步「帮助」与「公告」后，两侧各有这两个按钮且每个只有一份。原有防连点脚本、参数、未知字段、子树顺序及资源引用在 Laya 中可用。 |
| 冲突与重复同步 | 逐字段覆盖同值、不同字段、不同值、删除与修改、重排和重号。应用后重开，仅跳过项仍待处理；处理完再次同步为零项。 |
| 提交与恢复 | 覆盖预览后外部改写、原型未保存、第二个文件写入失败、中断恢复和重试。用真实 Laya 工程保存、重开并运行登录页验证引擎对象保真。 |

2026-11-23 已接入 VS Code 与浏览器工作台。原型保留默认控件外观，预制体侧展示可识别的静态 UI、磁盘贴图与只读引擎组件。同步记录现使用稳定原型属性路径保存页面根、变换、布局、文字和控件字段；缺省值先按双方语义归一，再逐字段比较和应用。引擎侧动画、脚本、未知字段及无法反解的外部资源继续保留。缺少资源映射时可查看引用。

验证覆盖真实磁盘目标、导入 UUID、两侧独立新增、冲突跳过、旧快照拒绝及失败恢复。新增回归同时修改页面根宽高/约束、字号、旋转、节点约束、文字排版、变量和显隐，分别验证 Laya → 原型、原型 → Laya 及应用后零差异。377 项共享测试、类型检查和生产构建通过。

2026-11-23 双预览直选回归的根因是共享 `SyncPreview` 只绘制节点与选中框，未接收或上报选中事件，因此唯一能更新选中状态的入口是左侧节点树。修复后，原型和 Prefab 渲染面按实际 DOM 节点命中，PSD 图片及已删占位按同步节点框命中，共同写入原有单一选中状态。Edge 用例已分别从 Prefab 双侧和原型 / PSD 双侧点击不同节点，验证标题、节点树、选中框和详情共用同一选中结果。

Edge 通过正常工作台入口写出登录页并重新打开，两侧各有一个「帮助」和「公告」。测试把 Laya 根尺寸从 320×240 改为 360×260、字号从 32 改为 33，右侧分别出现页面尺寸和字号差异；两块 `.sync-surface` 仍使用相同屏幕宽高，采纳后原型保存对应值并在重开时归零。窄屏下可从节点树展开防连点脚本并查看参数。使用 xq-client 的 Laya 引擎及实际 UI 类实例化该合并产物，校验按钮类型、文案和测试脚本的 500 ms 参数。Laya IDE 人工编辑、保存与重开仍待验证。

`wordWrap` 缺省值回归已修复：Laya Prefab 未写该字段时按运行时默认 `false` 读取，不再虚构“预制体：是”；GameFlow 原型未显式设置时的有效默认值仍为 `true`，导出会明确写入 `wordWrap: true`。针对性回归、378 项共享测试、生产构建和 Edge 预制体同步流程通过。
