# Prototype Layout Controls

Status: Done
Date: 2026-11-13
Scope: 参考 Laya 检查器的约束图、紧凑 Padding 与对齐图标

## Context and Goals

用户连续提供 Laya 属性面板示例，红框分别指向布局约束示意、U/R/D/L Padding 和对齐按钮。原型已有相同布局数据，但六个空文本框、长内边距标签及对齐下拉框不够直观；本轮调整呈现与输入方式，适配 280px 面板。

## Behavior and Design

- 约束以示意图及六个 checkbox 表示：横向左/X/右，纵向上/Y/下。X/Y 的完整说明为水平/垂直居中；已启用的引导线高亮。
- 示意线框采用细线：普通线 0.75px、启用线 1px，并使用 non-scaling-stroke 避免拉伸变粗。
- 勾选新增约束写 0，取消写 null；只有启用的约束显示数值偏移输入，单位沿用像素/百分比并保留既有单位转换。0 是启用值，缺省/null 是关闭。双边拉伸及居中优先仍沿用当前解算规则。
- 宽度来源/高度来源只读显示解算得到的显式尺寸、内容尺寸或双边拉伸，替代可编辑的尺寸模式下拉框。约束单位仍可编辑；已有 widthMode/heightMode 文档字段保持兼容。
- 锁定节点或自动排布管理的轴禁用对应 checkbox/偏移输入，不允许配置无效主轴约束。父容器说明继续保留。
- Padding 单标签配两行输入框，顺序 U 上/R 右、D 下/L 左；方向字符位于输入框内左侧，无障碍名称保持“内边距上/右/下/左”。值的范围与保存规则不变。
- 流式容器的对齐下拉框改为带中文 tooltip、aria-label、aria-pressed 的图标按钮；水平左/中/右，垂直上/中/下，HBox 加水平两端分布，VBox 加垂直两端分布。UIBox 自由布局沿用现有手动位置，不额外引入新的对齐语义。
- 不变更数据格式、布局解算或 Prefab 能力。原型属性外壳继续使用 VS Code 主题。
- 属性面板不再放图层顺序、上移/下移、复制/删除按钮。选中页面或控件后使用 Ctrl+D 复制（macOS 为 Cmd+D），输入字段编辑时不触发整节点复制；Delete/Backspace 和树右键菜单继续负责删除，树拖动负责层级调整。

## Implementation and Acceptance

1. 提取约束/内边距/对齐视图组件，复用现有 Field、Button、Tooltip 与提交回调。
2. 构建和现有布局测试通过；这些视图变化不新增镜像实现的测试。
3. 浏览器验证约束启停、0 值、偏移输入、禁用轴、Padding 数值及顺序、对齐按钮选态和实际几何变化，撤销保持有效。
4. 在 280px 面板检查排版、滚动和键盘可操作性，并同步布局基线。

## Risks and Rollback

启用 0 偏移可能使控件贴边或居中，界面提示此规则并允许撤销；图示只表达配置，不作为额外数据权威。回退视图组件可恢复原输入形式，保存的数据无需迁移。
