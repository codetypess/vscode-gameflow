## 行为与设计
图层右键增加「原型组件」子菜单，提供「解除当前等级的原型组件绑定」和「解除全部（包含嵌套）原型组件绑定」。仅单个可编辑的页面直属本地引用根可操作（实例内部的附加引用暂不开放）。当前等级保留嵌套引用，全部将整个实例展开为普通节点。保留当前呈现、根身份、局部覆盖及附加节点；新实体节点分配持久 ID 并重映射控件引用。源缺失或存在失效编辑时拒绝操作以免丢失数据。操作为一次可撤销文档编辑，不修改源。
