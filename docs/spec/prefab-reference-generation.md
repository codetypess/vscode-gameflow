# Prefab 引用生成

Status: Done
Date: 2026-11-24
Scope: 画布引用节点进入 Laya Prefab 导出时的结构表示

## 1. Context

工作台为了编辑和预览会把画布引用临时展开。Prefab 导出目前直接消费这棵组合树，因此引用节点被写成普通控件并带上展开后的子节点。这样破坏了 Laya Prefab 的独立资源边界，也让同一引用的多个使用点失去共享身份。

## 2. Goals

- 画布引用节点在页面 `.lh` 中使用 Laya `_$prefab` UUID 表示，不写入展开后的源子树。
- 被引用的画布仍作为独立 `.lh` 文件生成或复用已有文件 UUID。
- UIList 的 `cellPrefab` 现有 `{ _$uuid, _$type: "Prefab" }` 契约保持不变。
- 预览和编辑继续可以使用临时展开树；本次只改变 Prefab 产物的结构边界。

## 3. Non-Goals

- 不改变画布引用在编辑器中的展开、选择、覆盖或附加节点交互。
- 不在本次实现 Laya Prefab 变体/覆盖数据的完整序列化；带实例局部编辑的引用暂时明确阻止导出。
- 不改变 PSD 产物的静态展开语义。

## 4. Current Behavior

`composeCanvasPage` 返回的组合页会把 `prefab` 引用根及其源节点放进同一扁平节点数组。`planPrefabExport` 递归这些节点并生成普通 `_$type` / `_$child` 记录，导致引用模板内容复制到页面 Prefab 中。

## 5. Proposed Behavior

对没有本地实例编辑的画布引用，页面记录保留实例节点的稳定 ID、名称、几何与实例级布局字段，并写入：

```json
{
  "_$id": "instance-id",
  "_$prefab": "template-meta-uuid",
  "x": 148,
  "y": 197,
  "width": 378,
  "height": 40
}
```

记录不含源模板的 `_$child`，也不把引用根伪装成普通 `_$type` 节点。模板文件按已有列表项依赖规划输出，页面和模板通过同一 UUID 关联。

## 6. Design

- Prefab 规划器接收可选的画布引用 UUID 解析器；解析成功时优先生成 `_$prefab` 记录并停止该节点的子树递归。
- 列表项依赖规划同时遍历 `cellPrefab` 与普通 `prefab` 画布引用，按引用身份去重、检测循环和目标路径冲突，并为每个缺失模板生成独立 `.lh`。
- 现有组合页仍用于同步预览和差异展示；导出规划使用同一页面的权威引用身份，避免把临时投影 ID 写入磁盘。
- 模板内的嵌套画布引用也遵循同一规则；资源图片继续由现有资源解析器处理。

## 7. Implementation Plan

1. 扩展共享 Prefab 规划器，支持引用 UUID 和引用节点短路递归。
2. 扩展列表项依赖闭包，输出普通画布引用的模板文件并把 UUID 回填到页面记录。
3. 让工作台导出规划使用权威页面节点，保留组合页用于预览/同步。
4. 增加共享回归测试并运行类型检查、完整测试和生产构建。

## 8. Testing Plan

- 规划一个含普通画布引用和 `cellPrefab` 的页面，断言页面引用记录只含 `_$prefab`、不含 `_$child`，且模板出现在 `batch.cells`。
- 断言模板 UUID 来自 `.meta`，重复规划不复制同一依赖。
- 保持现有列表项导出、同步和 Laya 运行时加载测试通过。

## 9. Acceptance Criteria

- `服务器列表项` 这类画布引用在页面 `.lh` 中以 `_$prefab` UUID 生成，不再展开为子节点。
- 对应模板 `.lh` 仍可独立生成，页面引用 UUID 与模板 `.meta` 一致。
- UIList `cellPrefab` 输出格式和现有同步行为不回归。
- 共享测试、类型检查和生产构建通过。

## 10. Risks and Rollback

已有展开式 Prefab 可能在首次比较时显示结构差异；保留当前读取与合并逻辑，若目标文件无法以引用形式加载，可回退到本工作项前的规划器实现。实例局部覆盖/附加节点的完整 Laya 覆盖编码留作后续工作项。

## 11. Validation Results

- `npm test`：385 项共享测试通过。新增用例覆盖引用 UUID、独立模板批次、页面无展开子树、引用记录读取，以及旧展开产物只生成一项原子差异并同步转换为 `_$prefab`；错误的反向采用按跳过处理，不把展开子树写回原型，替换后再次比较为零差异。
- `npm run check` 与 `npm run build` 通过；生产构建保留既有的大 chunk 提示。
- `test/list-cell-browser.cjs` 使用桌面环境自带 Playwright 和无头 Edge 通过。仓库自带 Laya 引擎同时实例化 UIList `cellPrefab` 和普通 `_$prefab` UUID 引用，两者读取同一独立模板内容且无解析错误。
- 带局部属性覆盖或附加节点的画布实例目前明确阻止引用式导出，避免静默丢失实例差异；其 Laya override 编码属于后续工作。

## 12. Legacy Expanded Comparison Regression

旧版本已经把引用实例生成为普通 `_$type` 节点及其完整 `_$child`。新版本重新比较时，这不是根属性和每个子节点各自发生的业务修改，而是同一稳定实例从“展开表示”迁移为“Prefab 引用表示”。

根因是 Prefab 读取先按原型稳定 ID/控件类型把旧普通根和新引用根归一为同一个同步节点；`_$type` / `_$prefab` 的表示身份没有进入通用树比较，因此比较器只能产生根属性修改和子节点删除。

修复后的同步模型在 Prefab 边界识别这一迁移，并生成一项原子“Prefab 引用结构”差异：

- 该项包含旧展开根及其完整旧子树，但节点树只显示并选择引用根，不逐项列出子节点差异。
- 可选择“把预制体替换为 Prefab 引用”或“本轮跳过”；不提供把展开子树反向写入原型的选项。
- 应用替换时一次移除旧展开子树并把根记录改为 `_$prefab`，不能留下普通 `_$type`、`scriptPath` 或展开 `_$child`。
- 其他普通结构、属性和 UIList `cellPrefab` 差异继续使用现有逐项比较。

回归验收要求旧展开 fixture 只产生这一项替换差异；预演和提交后的主页面记录为 UUID 引用，独立模板及真实 Laya 加载保持通过。
