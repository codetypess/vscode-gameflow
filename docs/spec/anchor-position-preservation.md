# Anchor Editing Preserves Visual Position

Status: Done
Date: 2026-11-16
Scope: 原型属性锚点编辑的坐标换算与布局补偿

## Context and Goals

原实现直接 patch transform.anchorX/Y，矩阵平移为 position−linear×pivot，因此锚点变化后画布原点移动。用户明确要求编辑锚点时保持实际位置不变；此规则替代 prototype-node-transforms 中“保持 x/y 不变”的编辑策略，文档的 Laya 锚点语义不变。

## Behavior and Design

- 共享 setNodeAnchor 从当前解算尺寸计算 Δpivot，再用节点自身线性矩阵换算父空间 Δposition，保证节点与后代的页面矩阵、尺寸及裁剪不变。空心圆移动到新锚点，属性中的解算 X/Y 随之更新。锚点与坐标补偿为同一事务，ID 不变，可撤销、保存重载。
- 无约束自由轴且父同轴非内容测量时，补偿写入原始 frame 坐标，保留精度。不得经过直接几何编辑的整数取整路径。
- 自动排布、约束或父内容测量管理的轴，新增可选 v2 layout.positionOffsetX/Y（有限数，默认 0），在布局位置解算/回退后相加；不参与内容尺寸测量与流式占位。补偿等于目标锚点坐标减新锚点的解算坐标，因此处理约束取整、非均匀缩放、镜像、旋转、倾斜、零缩放和父滚动，无需逆矩阵。
- 位置补偿在属性界面不单独暴露。之后拖动、尺寸调整及约束切换的逆向换算扣除补偿，避免重复累加。换父级、根粘贴、改变父排布时，已固化的局部坐标吸收旧补偿并清除该覆盖；复制保留其独立副本。
- 底层数据直接设置锚点仍遵循引擎语义；只有编辑器锚点操作保持视觉位置。原有缩放/倾斜/旋转操作不增加位置保持策略。缺失、锁定节点、无变化及非法锚点输入不提交。

## Non-Goals

不新增拖动锚点手柄或属性项，不改页面根、PSD 或 Prefab 导出；不对已有文档补算/批量改写。

## Verification and Acceptance

- 共享测试比较变更前后全部四角和页面矩阵，覆盖自由/嵌套/镜像/零缩放、约束/百分比/拉伸、小数尺寸、HBox/VBox/Grid、父内容测量、后续移动/缩放/约束切换/换父级/粘贴和保存历史。补偿字段验证与 schema 同步。
- 浏览器独立样例检查更改锚点前后控件及后代无跳动、X/Y 与空心圆更新、撤销重做及保存重载；保留当前用户预览数据。
- 类型检查、全部共享测试、生产构建、diff 检查通过；基线记录新规则。

## Risks and Rollback

自动布局覆盖 authored frame，约束坐标会取整，父内容尺寸又可能依赖 frame；仅修改 frame/偏移不能覆盖全部场景。内部位置补偿只作用布局后的位置，不改测量依赖。后续新增几何编辑路径必须沿用共享逆向换算并正确吸收补偿。
