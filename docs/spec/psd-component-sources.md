# 组件源 PSD 与页面智能对象

Status: Done
日期　2026-11-25

## 目标

组件原型拥有自己的 PSD 文件。生成引用它的页面 PSD 时复用已绑定的组件 PSD，并为未绑定组件生成文件。父 PSD 的智能对象携带该文件的内嵌副本。

## 生成

从实际画布引用解析组件来源。每个源画板生成一份 PSD。同一 GameFlow 文件中生成的组件与父页在同一次原型编辑中绑定。跨文件引用在所属画布的工作副本建立绑定。组件文件与所属画布相邻，文件名冲突时使用可用名称。父页保存取消时保留原有绑定。组件 PSD 内容由组件画板或已绑定的美术稿决定，父页实例负责置入位置、尺寸和变换。

内嵌 PSD 文件名和自动生成的独立组件 PSD 默认文件名取被引用的原型页名称。外层图层使用实例名称，已有源文件沿用绑定的磁盘路径。命名回归覆盖原型页名称、实例名称、预制体导出名称和绑定文件名各不相同的情况。此前自动生成使用预制体导出名称，已绑定时使用磁盘文件名，未绑定的同步路径使用实例名称。

生成组件源 PSD 时，画板本身代表 `componentRootId` 声明的根，根下的可编辑子图层直接写在文件顶层。登录页等引用者仍嵌入该 PSD 的完整文件。同步通过顶层子图层的 GameFlow 元数据恢复逻辑容器，原型布局和层级以原有根为准。旧版 PSD 的实际根组仍可以按原层级同步。

## 同步

智能对象元数据记录组件画布、组件画板、源 PSD ID，以及上次确认的源和内嵌文件指纹。同步重新读取组件 PSD，源有变化时显示「更新智能对象」。内嵌内容同时有独立修改时提供更新或保留当前内容的选择。写入时复核源文件，沿用外层图层 ID 和置入四角，嵌入原始 PSD 字节，并用其保存的合成图生成外层像素。已有智能对象在首次关联已绑定的组件 PSD 时提供显式确认。

浏览器预览将生成的 PSD 下载到本机，并在同一会话使用文件快照。跨文件画布绑定由 VS Code 工作副本负责。

## 验收

- 在星海登录页生成父 PSD 和组件源 PSD，核对自动绑定与内嵌字节。
- 复用已有组件 PSD。修改源后预览并应用，保留外层身份和变换，再次比较没有对应更新项。
- 同时修改内嵌内容，核对冲突选择、保留后再次比较和源再次修改时的行为。
- 验证现有普通 PSD 同步及原型新增图层流程。

## 验证

Chrome 验证首次生成、复用源文件、合成预览更新、外层 ID 和置入变换、冲突保留和替换、再次同步，以及旧版智能对象同步。宿主测试覆盖保存取消、同名文件保护和来源变化后的过期写入。真实 VS Code 宿主验证在同一个绑定上读取 Photoshop 格式文件的两次保存。398 项共享测试、生产构建和差异检查通过。Photoshop 应用内打开、编辑和另存尚未验证。

命名回归在修复前读出 `laya-server-list.psd`。修复后 Chrome 从导出及同步产物读回 `服务器列表项.psd`，覆盖自定义实例名、已有美术稿、普通组转换、无独立源文件时新增实例和列表项导出。398 项共享测试和生产构建通过。

组件根回归验证登录页生成的源 PSD 与内嵌字节一致，文件顶层直接包含「图片」和「服务器名称」。新旧结构均通过独立文案同步。星海样例的组件源和登录页内嵌文件已更新，原合成像素、外层图层身份与置入变换通过比对。
