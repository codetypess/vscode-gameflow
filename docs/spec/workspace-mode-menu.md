# Workspace Mode Menu

Status: Done
Date: 2026-11-24
Scope: 将顶栏中央的三模式按钮收拢为顶栏最左侧的工作模式菜单。

## 1. Context

原型、PSD 合并和 PSD 切图目前以三个纯图标按钮固定在顶栏中央，工作台名称则单独占用顶栏最左侧。模式入口与其他顶栏操作相距较远，也占据了中央文档标题区域。

## 2. Goals

- 在顶栏最左侧显示当前工作模式，并作为切换菜单入口。
- 菜单提供原型、PSD 合并、PSD 切图三个现有模式及对应图标。
- 保留现有模式切换、会话状态和 PSD 切图忙碌禁用规则。
- 在窄窗口中仍可看到并操作模式入口，菜单保持在视口内。

## 3. Non-Goals

- 不改变工作模式的数据模型、持久化或宿主协议。
- 不改变各模式内部工具和布局。
- 不新增、删除或重命名工作模式。

## 4. Current Behavior

顶栏最左侧固定显示“工作台”，三个模式按钮绝对定位在顶栏中央；当前按钮通过背景高亮和 `aria-pressed` 表示选择状态。

## 5. Proposed Behavior

顶栏最左侧改为带当前模式图标、名称和展开箭头的按钮。点击后在按钮下方打开菜单，菜单中逐项列出三个模式并用勾选标识当前模式。选择其他项目后沿用现有切换函数更新工作区。

## 6. Design

- 复用现有 Radix DropdownMenu 和工作台菜单样式，菜单左对齐入口并启用碰撞约束。
- 入口无障碍名称包含当前模式，例如“工作台模式：原型”；菜单使用“工作模式”名称。
- PSD 切图项继续在原型页面已有 PSD 且页面动作忙碌时禁用。
- 移除仅服务于中央按钮组的定位、按钮尺寸和响应式样式。

## 7. Implementation Plan

1. 更新产品工作台基线和工作项索引。
2. 将模式定义集中复用，替换顶栏静态标题和中央按钮组。
3. 更新模式切换浏览器测试，并补充菜单结构、选择状态与窄窗口可用性断言。

## 8. Testing Plan

- 运行 TypeScript 检查、共享测试和生产构建。
- 运行 PSD 工作台启动与页面 PSD 浏览器回归。
- 浏览器检查桌面及窄窗口下的入口位置、菜单内容、当前项和切换结果。

## 9. Acceptance Criteria

- [x] 顶栏中央不再显示三模式按钮组。
- [x] 顶栏最左侧显示当前模式入口，菜单恰好包含三个模式。
- [x] 菜单标识当前模式，切换三个模式继续使用原有行为。
- [x] PSD 切图忙碌禁用规则保持不变。
- [x] 520px 和 360px 宽度下入口可见且菜单不超出视口。
- [x] 类型检查、共享测试、生产构建和相关浏览器回归通过。

## Results

- `npm run check` 和 `npm run build` 通过。
- `npm test` 通过，共 385 项共享测试。
- `psd-workspace-startup-browser.cjs` 与 `page-psd-browser.cjs` 在 Edge 通过，覆盖三项菜单、当前模式、PSD 会话切换及 520px/360px 视口边界。
- 浏览器实测顶栏最左侧显示当前模式，菜单图标、文字与勾选状态正常，中央不再保留模式按钮组。

## 10. Risks and Rollback

主要风险是测试仍依赖旧的导航按钮角色，或窄窗口隐藏了新入口。通过稳定的入口无障碍名称和菜单角色覆盖回归。回滚只需恢复旧顶栏 JSX 与 `.mode-switcher` 样式，不涉及数据迁移。
