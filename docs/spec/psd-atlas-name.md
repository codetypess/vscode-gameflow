# PSD 图集名

Status: Done
Date: 2026-11-18
Scope: PSD 切图属性、文件级图集名、默认导出名称。

## Context and goals

此前非共享切图使用 PSD 文件名作为默认命名的一部分，且无法独立调整；共享切图省略文件名。新增文件级图集名，使同一 PSD 内各图层共用可编辑的命名前缀。图集名只参与资源命名，不生成图集纹理，也不自动移动或删除旧 PNG。

## Behavior and design

- 在切图属性最顶部“文档配置”中放置文件级“图集名”和独立目录设置；导出名称属于所选图层，放入下方“导出设置”，两种输入沿用同样的标签与输入列布局。默认输入值为空，仅 placeholder 显示规范化的 PSD 文件名（去掉 `.psd`）；只有自定义输入才保存覆盖值，清空恢复默认。
- 图集名统一为小写英文字母、保留数字和下划线：中文转拼音首字母，空格、连字符等分隔符合并为下划线，去掉首尾下划线。默认 placeholder、自定义值、持久化与最终导出共用同一规范；读取旧配置中的大写/中文值时自动规范化。输入期间保留可编辑原文以支持中文输入法及连续输入下划线，非组合输入同步生成规范名；失焦或回车显示规范名。清空或输入无可用字符时恢复默认。
- 非共享资源的默认导出名称为 `{btn 或 img}_{图集名}_{图层名}`，继续按图层名是否含“按钮”选前缀，两段名称沿用既有拼音首字母、ASCII 和小写规范。共享资源的默认名称为 `{btn 或 img}_{图层名}`，不包含图集名或文件名；切换共享即时更新 placeholder、PNG 名称和运行预览路径，取消共享恢复当前图集名。共享开关不清除文件级图集设置，并继续控制同名覆盖和来源登记。手填导出名优先，清空恢复默认。
- 可选的 `atlasName` 覆盖值属于 PSD 文档，进入现有编辑、历史、草稿和配置保存流程。PSD 副本通过已有 GameFlow 图层元数据携带覆盖值（保存时同步各层、清空时移除旧镜像值），读取到互相冲突的图集名会拒绝读取；旧数据缺省时按文件名推导。图层切换不会改变图集名。
- 属性 placeholder、重名检查、PNG 输出与运行预览共用命名规则；切图生成缓存以图集名参与版本判定。

- 切图属性顶部“文档配置”集中放图集名和独立目录选项，导出名称位于所选图层的导出设置中。规范化图集名不能为 builtin、shared、unclassified，手填与持久化边界一致校验；文件名默认值命中时提示修改。具体目录路由见 [PSD 独立目录](psd-independent-directory.md)。

## Implementation and verification

1. 扩展共享元数据、配置及草稿验证与回读。
2. 统一名称生成，接入属性输入，并同步运行预览。
3. 验证默认与自定义名称、共享导出、清空、覆盖值的历史和保存往返，并检查真实 PSD 面板布局。

## Acceptance

- `登录页面.psd` 的“按钮底图”默认导出 `btn_dlym_andt.png`；图集名输入 `Common` 后显示为 `common`，导出名变为 `btn_common_andt.png`，其他非共享图层使用同一图集名；勾选共享后为 `btn_andt.png`，取消共享恢复 `btn_common_andt.png`。
- `Common UI` 输入完成后显示并保存 `common_ui`，`公共资源` 为 `ggzy`，`登录页面.psd` 的默认 placeholder 为 `dlym`，输入值仍为空。
- 保存/重开、草稿恢复、PSD 副本及撤销/重做保留文件级设置；清空后重新按文件名推导。
- 自定义导出名优先，切换共享不会改写手填值；清空时按当前共享状态恢复默认。
- 两个不同文件名、不同图集名的 PSD 共享同名图层时输出同一文件并按原有共享规则更新来源。
- 非共享图层的图集名变更能刷新实际输出和预览资源路径；共享图层的默认名称不受图集名变化影响。

## Risks

已有共享图层的默认路径会变化。需要沿用旧路径的资源可继续手填导出名；旧输出文件和绑定不会被自动改写。
