# Prototype UI and Layout Baseline

Date: 2026-11-14
Status: Implemented prototype subset

## Components

底部添加菜单和层级树右键提供 15 种原型节点：自由容器、横排、竖排、网格、面板容器、文字、图片、按钮、输入框、列表、复选框、单选框、进度条、滑块、下拉框。旧矩形节点继续兼容读写和渲染。菜单显示中文名与括号内的 LayaUI 类名，底部菜单不显示快捷键列。`shared/ui-components.ts` 定义类型、中文名、目标 LayaUI 类及能否包含子节点。新按钮使用独立文字子节点，旧按钮的 text 原样显示。

画布根类型包括堆叠界面 (UIStack)、顶层界面 (UITop)、场景界面 (UIScene)，以及组件画板 (UIBox，初始 320×240)。添加菜单上方“添加到画布”包含四种根类；下方控件区另保留自由容器，仅在页面内启用并添加子容器。UIBox 画板可用于 ItemRender 设计，双击编辑内部节点。UIView 是基础类，不作为可选根类型；默认新建 UIStack。页面属性可改根类型，与 screen/modal 页面形式独立；改类型保留 ID、内容和几何，复制保留类型并生成新 ID。层级树根和属性身份显示实际根类。运行时层级管理、ItemRender 绑定与 Prefab 导出仍为后续工作。

控件状态通过属性面板编辑，包括勾选/禁用、数值范围、方向、输入占位/密码/字数、下拉选项、文字换行/溢出/垂直对齐及图片填充方式。它们是低保真预览，不执行游戏事件、数据绑定或真实皮肤引用。UIList 是可编辑静态子项的网格，不是运行时虚拟列表。

底部添加菜单将页面根和控件分别以紧凑双列展示，正常宽 440px，常用视口不需要滚动即可看到全部选项。保留中文名称、类名和图标；窄视口回退单列，菜单按实际可用高度限位并仅在必要时滚动。

## Geometry

- `shared/ui-layout.ts` 按父局部坐标解析显式尺寸、内容测量和双边拉伸。所有视图及编辑操作使用同一算法；计算后的矩形、尺寸来源和裁剪范围不写盘。
- 六项约束使用 null/缺省关闭，0 有效；单位 absolute 或 percent，10 代表 10%。位置优先 center、leading、trailing、原位置；双边独立决定拉伸尺寸。约束位置四舍五入，尺寸和流布局位置保留小数；无约束旧坐标保留。
- 父内容区扣除四边 padding。HBox 禁止子节点水平约束，VBox 禁止垂直约束；交叉轴的显式约束优先于对齐。justify 均分空间并忽略 gap。Grid 按最大子项宽高确定格子、支持横/纵优先与 wrapCount。隐藏节点仍参与布局，负间隔合法但测量结果不得为负。
- HBox/VBox 子节点的可选 `layout.crossAxisMode` 缺省或 `aligned` 时，无约束交叉轴遵循父容器对齐；`explicit` 时使用当前局部 frame 坐标。取消最后一个交叉轴约束写入 `explicit` 并保留坐标，重新启用约束清除该覆盖。主轴始终自动排布。换父级、根粘贴或切换父容器布局类型时清除覆盖，以沿用新父级的排布规则。
- 内容尺寸按子项计算，按轴检查父子测量依赖。非法约束、负拉伸和过大 padding 显示节点诊断，失败轴用原始 frame 回退，文档仍可编辑。
- 文字尺寸采用确定性的低保真估算；图片未接入引擎自然尺寸测量，内容模式沿用保存的 frame 尺寸。当前坐标范围为 scale=1、pivot=0，无旋转。完整字体、变换、九宫格和引擎测量须另行接入。
- 容器裁剪使用祖先边界交集；panel 默认裁剪，list 工厂默认开启裁剪。scrollX/Y 表达静态预览偏移，隐藏的像素不响应画布选中。
- 不跨调用缓存可变页面对象；单次画布渲染复用其解析结果，以兼容现有操作的原地坐标更新。

## Editing

属性面板只呈现属性，不放图层顺序、上移/下移和复制/删除操作。选中页面或控件后 Ctrl+D（macOS Cmd+D）生成副本，Delete/Backspace 删除；页面内 Ctrl/Cmd+C/V 复制/粘贴子树，图层树 F2 行内重命名。焦点位于输入字段时不触发节点快捷键。右键一级菜单集中编辑操作；新增与转换类型各用二级菜单承载 15 种控件，不再提供冗余的矩形选项。旧 rectangle 类型继续读写和渲染，新建列表的静态子项使用 panel。

属性顶部身份信息合并成一行，左侧为中文类型及括号类名（如 `横排容器(UIHBox)`），右侧为稳定 ID，去掉独立的“控件”字样；页面同样显示 `页面(UIStack)` 等类型与 ID。窄面板优先保留完整 ID，左侧超长时省略并提供完整提示。

控件显示名称的字段名为“名称”，其下“变量”编辑独立的可选 v2 `variableName`。变量使用便于 JS/TS 代码生成的 ASCII 标识符：以字母、`_` 或 `$` 开头，后续允许数字；禁用 ECMAScript/严格模式保留字、字面量及 `eval`/`arguments`。同页变量名区分大小写且不可重复，不同页面可相同。输入去除首尾空白，留空删除该字段；非法/重名草稿显示内联提示并阻止提交。Enter/失焦提交有效值，Escape 恢复已保存值；锁定节点禁用。名称、变量和 ID 相互独立，普通编辑、类型转换及身份迁移保留变量。复制/粘贴子树在目标页面给冲突变量追加 `2`、`3` 等后缀；复制整页保留变量名。旧节点不自动生成变量；页面属性不增加此字段。

图层树搜索只影响当前页树视图：名称、已保存的变量名、稳定 ID、中文/内部组件类型及 Laya 类名按去除首尾空白后的子串匹配，忽略大小写，隐藏/锁定节点也参与。变量缺省时仍按其他字段匹配，变量搜索不改变变量本身区分大小写的命名/唯一性规则。匹配节点及其祖先保留原顺序和缩进；搜索折叠状态与普通树分开维护，清空恢复原折叠状态。搜索不改变文档、历史或当前选择，搜索期间禁用树拖动，保留其他节点操作。输入框中的 Escape 仅清空搜索，不触发画布取消选择。

图层树在节点名称旁以紧凑等宽字体标签显示已保存的变量名；无变量时不占位。名称/变量过长时在行内省略，悬停可查看完整文本。变量编辑、清空和撤销/重做后标签随文档状态同步更新，点击变量标签同样选中节点。

原型图层树行的基础左留白为 8px，每级缩进 10px，普通树和搜索结果沿用同一缩进规则。行尾隐藏与锁定按钮紧邻排列，按钮之间不额外留白。

画布直接选中控件时，图层树展开该节点的全部祖先，并以最小纵向滚动让对应行完整可见；重复点击同一控件也会重新定位，已可见则不滚动。若当前搜索排除了目标，先清除搜索；目标仍在结果中则保留搜索并展开路径。定位只响应画布选中请求，不因普通重渲染、手动滚动或折叠持续追踪；不抢焦点、不改变画布视角或文档历史。缩放手柄和抓手平移不触发定位。

节点复制捕获独立子树快照，剪贴板仅限当前编辑会话，可跨页粘贴。粘贴目标与新增一致；根节点使用复制时解算的局部 frame 加 16px 偏移，清除六项旧父约束并固化尺寸，子节点保持局部数据，全部身份重新分配。空剪贴板和锁定目标禁用粘贴。重命名提交去除首尾空白的非空名称，Enter/失焦提交、Escape 取消。类型转换保留 ID、名称、层级、样式、内容及子节点，复用容器切换的约束规范化；仅在缺省时补上目标文字/widget 默认值。有子节点不能转为叶子类型，存在锁定直属子节点时也不能转换。替换预制体当前禁用并显示未接入状态。

属性面板的六项约束用 checkbox 和方位示意图表达。勾选/取消时从当前解算几何换算同轴全部有效偏移，保持位置与尺寸；取消的字段写 null，最后一个约束取消后保留当前局部坐标，解除双边拉伸后固化当前尺寸为显式尺寸。父容器内容区与 Padding、像素/百分比单位都参与换算；自动排布管理的轴和锁定节点禁用。只为启用项显示数值偏移输入：上/垂直居中/下位于图示右侧，左/水平居中/右位于图示下方，输入框中心对齐对应引导线并使用固定方向槽位；保留完整无障碍名称和悬停说明。正常 280px 面板完整显示，过窄时图示局部横向滚动。宽度来源/高度来源只读，约束单位仍可编辑。Padding 使用 U/R、D/L 两行紧凑数字框。流式容器对齐使用水平/垂直图标组；两端分布仅出现在 HBox 水平轴和 VBox 垂直轴。

位置、尺寸、六项约束偏移、Padding、间距与静态滚动数值使用整数显示，直接输入提交时四舍五入；节点/页面拖动、缩放和方向键编辑的变化坐标/尺寸取整。图示、单位和逆向偏移换算保留必要内部精度，以保持百分比定位与布局几何；旧文档不批量重写，未修改的输入失焦不将内部精度覆盖为显示整数。布局解算仍允许自动排布及旧文档产生的小数几何。

自由节点拖动写 x/y；有约束时写对应偏移，拉伸缩放更新边距。主轴拖动重排兄弟，主轴方向键逐项排序；交叉轴有约束时更新约束，显式交叉轴更新局部 frame。切换布局清除新排布禁止的约束，并固化原拉伸尺寸。锁定节点不可直接编辑。

换父级先解析视觉位置与尺寸，移除旧约束，固化尺寸；自由父级保持视觉位置（含滚动），流式父级遵循新顺序。子树复制深拷贝 layout/widget，生成新 ID 并重写内部 parentId。所有变化继续经过宿主文档事务及 undo/redo。

## Persistence and Sample

新文件使用 schemaVersion 2；v1 读取和无编辑往返保留原字段/版本/ID，首次有效编辑在同一事务升级到 v2，可撤销。可选 page.rootType 接收 UIStack/UITop/UIScene/UIBox，缺省按 UIStack 显示但不在解析时补写字段。v1 不接收 rootType、新增节点类型及 layout/widget/variableName；v2 校验新增字段和取值。变量语法、保留字及版本限制在 JSON Schema 与共享校验中保持一致；共享校验额外拒绝同页变量重名，包含两个字段位置。变量通过现有宿主事务保存及撤销，不新增消息类型。

页面根与所有控件在整份文档内共享唯一 ID 空间，包括独立 UIBox 画板。v1/v2 均在共享运行时校验中拒绝跨页面、根与控件、同页控件重号，错误包含 ID 和两个位置；解析/序列化/协议校验不自动分配或修复歧义身份，名字相同不构成冲突。新身份采用 8 位小写字母/数字 Nano ID，首位允许数字。未带 `elementIdScheme: "nanoid-8"` 的旧文档首次进入编辑会话时，独立迁移事务统一重分配页面/控件 ID、更新引用并记录标记；v1 在同一事务升级，可撤销。迁移完成后普通编辑及保存保持 ID，详见 [nanoid-element-ids.md](nanoid-element-ids.md)。

`sample/ui-components.gameflow.json` 包含自适应背包和游戏设置；浏览器 `?sample=ui-components` 使用独立 localStorage key，避免覆盖原有预览文档。实际 Prefab 生成、资源/PSD 绑定仍由后续方案负责。
