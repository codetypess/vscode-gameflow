# Prototype UI and Layout Baseline

Date: 2026-11-13
Status: Implemented prototype subset

## Components

底部添加菜单和层级树右键提供 16 种原型节点：自由容器、横排、竖排、网格、面板容器、矩形、文字、图片、按钮、输入框、列表、复选框、单选框、进度条、滑块、下拉框。菜单显示中文名与括号内的 LayaUI 类名，底部菜单不显示快捷键列。`shared/ui-components.ts` 定义类型、中文名、目标 LayaUI 类及能否包含子节点。新按钮使用独立文字子节点，旧按钮的 text 原样显示。

画布根类型包括堆叠界面 (UIStack)、顶层界面 (UITop)、场景界面 (UIScene)，以及组件画板 (UIBox，初始 320×240)。添加菜单上方“添加到画布”包含四种根类；下方控件区另保留自由容器，仅在页面内启用并添加子容器。UIBox 画板可用于 ItemRender 设计，双击编辑内部节点。UIView 是基础类，不作为可选根类型；默认新建 UIStack。页面属性可改根类型，与 screen/modal 页面形式独立；改类型保留 ID、内容和几何，复制保留类型并生成新 ID。层级树根和属性身份显示实际根类。运行时层级管理、ItemRender 绑定与 Prefab 导出仍为后续工作。

控件状态通过属性面板编辑，包括勾选/禁用、数值范围、方向、输入占位/密码/字数、下拉选项、文字换行/溢出/垂直对齐及图片填充方式。它们是低保真预览，不执行游戏事件、数据绑定或真实皮肤引用。UIList 是可编辑静态子项的网格，不是运行时虚拟列表。

底部添加菜单将页面根和控件分别以紧凑双列展示，正常宽 440px，常用视口不需要滚动即可看到全部选项。保留中文名称、类名和图标；窄视口回退单列，菜单按实际可用高度限位并仅在必要时滚动。

## Geometry

- `shared/ui-layout.ts` 按父局部坐标解析显式尺寸、内容测量和双边拉伸。所有视图及编辑操作使用同一算法；计算后的矩形、尺寸来源和裁剪范围不写盘。
- 六项约束使用 null/缺省关闭，0 有效；单位 absolute 或 percent，10 代表 10%。位置优先 center、leading、trailing、原位置；双边独立决定拉伸尺寸。约束位置四舍五入，尺寸和流布局位置保留小数；无约束旧坐标保留。
- 父内容区扣除四边 padding。HBox 禁止子节点水平约束，VBox 禁止垂直约束；交叉轴的显式约束优先于对齐。justify 均分空间并忽略 gap。Grid 按最大子项宽高确定格子、支持横/纵优先与 wrapCount。隐藏节点仍参与布局，负间隔合法但测量结果不得为负。
- 内容尺寸按子项计算，按轴检查父子测量依赖。非法约束、负拉伸和过大 padding 显示节点诊断，失败轴用原始 frame 回退，文档仍可编辑。
- 文字尺寸采用确定性的低保真估算；图片未接入引擎自然尺寸测量，内容模式沿用保存的 frame 尺寸。当前坐标范围为 scale=1、pivot=0，无旋转。完整字体、变换、九宫格和引擎测量须另行接入。
- 容器裁剪使用祖先边界交集；panel 默认裁剪，list 工厂默认开启裁剪。scrollX/Y 表达静态预览偏移，隐藏的像素不响应画布选中。
- 不跨调用缓存可变页面对象；单次画布渲染复用其解析结果，以兼容现有操作的原地坐标更新。

## Editing

属性面板只呈现属性，不放图层顺序、上移/下移和复制/删除操作。选中页面或控件后 Ctrl+D（macOS Cmd+D）复制，Delete/Backspace 删除；层级树支持拖动排序及右键删除。焦点位于输入字段时不触发节点复制/删除快捷键。

属性面板的六项约束用 checkbox 和方位示意图表达，启用写 0、取消写 null，只为启用项显示数值偏移输入；自动排布管理的轴和锁定节点禁用。宽度来源/高度来源只读显示解算结果（显式尺寸/内容尺寸/双边拉伸），约束单位仍可编辑。Padding 使用 U/R、D/L 两行紧凑数字框。流式容器对齐使用水平/垂直图标组，选态高亮并提供中文 tooltip；两端分布仅出现在 HBox 水平轴和 VBox 垂直轴。所有输入沿用当前数据字段和解算规则。

自由节点拖动写 x/y；有约束时写对应偏移，拉伸缩放更新边距。主轴拖动重排兄弟，主轴方向键逐项排序；交叉轴有约束时更新约束。切换布局清除新排布禁止的约束，并固化原拉伸尺寸。锁定节点不可直接编辑。

换父级先解析视觉位置与尺寸，移除旧约束，固化尺寸；自由父级保持视觉位置（含滚动），流式父级遵循新顺序。子树复制深拷贝 layout/widget，生成新 ID 并重写内部 parentId。所有变化继续经过宿主文档事务及 undo/redo。

## Persistence and Sample

新文件使用 schemaVersion 2；v1 读取和无编辑往返保留原字段/版本/ID，首次有效编辑在同一事务升级到 v2，可撤销。可选 page.rootType 接收 UIStack/UITop/UIScene/UIBox，缺省按 UIStack 显示但不在解析时补写字段。v1 不接收 rootType、新增节点类型及 layout/widget；v2 校验新增字段和取值。JSON Schema 与运行时校验共同维护。

页面根与所有控件在整份文档内共享唯一 ID 空间，包括独立 UIBox 画板。v1/v2 均在共享运行时校验中拒绝跨页面、根与控件、同页控件重号，错误包含 ID 和两个位置；读取/保存/协议不自动分配或修复旧身份。唯一的旧长 ID 与可读 ID 保留，名字相同不构成冲突。

`sample/ui-components.gameflow.json` 包含自适应背包和游戏设置；浏览器 `?sample=ui-components` 使用独立 localStorage key，避免覆盖原有预览文档。实际 Prefab 生成、资源/PSD 绑定仍由后续方案负责。
