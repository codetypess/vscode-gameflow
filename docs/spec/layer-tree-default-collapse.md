# Layer Tree Default Collapse

Status: Done
Date: 2026-11-16
Scope: 原型层级树普通视图的默认展开状态。

## 1. Context

用户要求层级树默认不展开。当前 LayerTree 用空 collapsed 集合初始化，缺省含义是所有节点展开；仅把初始页面 ID 填入 collapsed 又无法覆盖后续新建、复制、粘贴的容器。

## 2. Behavior and Design

- 进入页面时只显示页面直属节点；有子节点的行默认收起。
- 普通视图改为记录显式展开的 ID，初始为空；从当前页面派生 collapsed 集合，继续复用绘制和 Shift 范围顺序。新出现或由叶子转为容器的节点默认收起，用户之前主动展开的节点保留当前会话状态。
- 手动点击箭头开合；画布选中内部节点仍只展开祖先路径，不展开所选容器自身或无关分支。
- 搜索继续使用独立 searchCollapsed 状态，默认展开匹配路径；清除搜索恢复普通树的展开状态。
- 在收起容器内主动新增/粘贴/拖入时，沿用展开目标容器的显式行为，以显示操作结果。新建复合控件及其内部容器本身默认收起。
- 切页、离开再进入或刷新后恢复默认收起。状态不写文档，不增加撤销步骤；属性面板的分区展开规则独立。

## 3. Verification

此修改为可逆的视图状态调整，不新增镜像实现的测试。使用真实浏览器验证初始层数、手动开合、新建/复制容器、画布选中内部节点展开路径、搜索及清除恢复、Shift 可见范围与重新进入。运行生产构建/类型检查、共享回归和差异空白检查。

## 4. Acceptance

- [x] 首次进入/重新进入只显示直属节点，容器均收起。
- [x] 手动开合有效，新出现容器默认收起，主动操作目标展开。
- [x] 画布选中内部节点只展开祖先，搜索展开匹配路径且清除恢复。
- [x] 共享测试、生产构建、差异空白检查通过。

验收记录：175 项共享测试、类型检查、生产构建及差异空白检查通过。隔离示例页共 12 个节点，进入时只显示“游戏设置”和收起的“设置竖排”两行；Shift 连选仅选中这两行。手动展开显示 11 行，“保存设置”内部文字仍收起；搜索“保存设置文字”展开两个祖先，清除后准确恢复原来的 11 行与展开状态。画布逐层选到内部文字时展开两个祖先并选中对应行。根上新增滑块及 Ctrl+D 副本均 aria-expanded=false；对收起的设置容器主动添加文字后父容器展开、结果可见。验收编辑均撤销，重新进入恢复 2 行且无展开节点；控制台无 error/warn。截图 layer-tree-default-collapse.jpg 记录恢复后的默认显示。

## 5. Risks and Rollback

普通展开记录与搜索折叠记录含义相反，开合和定位必须分别更新正确集合。回退普通视图状态即可，不涉及文档迁移。
