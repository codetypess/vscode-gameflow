# 保存已从磁盘删除的画布

Status: Done

工作台打开的画布被外部删除后，保存前的内容比对会在读取原文件时失败，内存里的修改因此无法写回。

在原目录仍存在时，原生保存应把当前画布写回原路径。保存已有文件时继续检查外部修改。若其他程序抢先重建同名文件，应保留该文件和工作台草稿。读写失败时保留错误与草稿，成功写入后更新保存基线。

验收时在 VS Code 中修改画布，删除磁盘文件，再通过普通保存检查原路径的内容和标签的未保存标记。随后编辑并保存一次，确认新基线生效。用外部写入的同名文件验证冲突保护。

2026-11-26 在隔离测试目录补齐仓库示例后，生产构建、411 项共享测试和 60 项 VS Code 宿主检查通过。宿主回归确认原生保存重建文件、清除未保存标记，之后的编辑可以再次保存，遇到外部修改时保留双方内容。
