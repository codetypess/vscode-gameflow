# 新建原型画布

Status: Done
Date: 2026-11-27

## 使用流程

现有的「新建策划画布」会生成背包示例。命令面板新增「原型工作台: 新建原型画布」，用于从空白画布开始设计。

1. 用户选择保存位置和文件名，宿主补齐 `.gameflow.json` 后缀。
2. 宿主创建当前格式的文档，分配新的文档 ID，以文件名作为标题，需求、页面及跳转列表初始为空。
3. 文件写入成功后由原型编辑器打开，用户可通过已有的「添加页面」入口创建首个页面。

## 实现与验收

- 两个命令共用宿主的保存对话框、序列化和编辑器打开流程，各自决定初始文档内容。
- 宿主测试检查新命令的初始数据、文件名与编辑器目标，并检查策划画布仍有示例页面。
- 取消时不产生文件或打开编辑器。自动补齐后缀遇到已有目标时保留原文件。
- 421 项共享测试及扩展生产构建通过，其中 3 项宿主适配器测试覆盖原型和策划画布的创建、取消及文件名冲突。
