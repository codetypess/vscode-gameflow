# UIList 列表项模板

Status: Done

## 范围与目标

原型现有列表依赖手工子节点，Laya 编辑器使用 cellPrefab 铺满内容视口。新建列表采用后者的编辑语义，游戏数据和滚动复用由 Laya 运行时负责。

## 行为与设计

- 列表属性可从当前文件或其他 GameFlow 的 UIBox 画板选择、替换、清除 CellPrefab。引用沿用相对来源、文档 ID、画板 ID，参与保存、撤销和源更新。
- 属性面板的“渲染项”使用 Laya 式单行资源引用框，显示 Prefab 图标、模板名及右侧拾取图标。点击打开选择器并定位已绑定的来源，支持在选择器清空绑定或聚焦引用框后按 Delete / Backspace 清空。
- 模板使用自然尺寸，按滚动方向、wrapCount 和水平/垂直间距从内容视口起点逐行或逐列重复。预览项归列表所有，不进入层级、文档、Prefab 子树或同步差异。
- Laya 默认纵向、每行一项、零间距，None 采用纵向铺排并允许溢出。旧列表显式子节点保留可编辑性。选择模板时提示将替换的节点数量，替换可撤销。
- 导出引用独立模板 .lh 的导入 UUID。同步分别呈现原型模板与对应磁盘模板；无法解析的绑定保留身份并显示诊断。

## 实施与验收

1. 接通文档校验、依赖加载、选择器与预览，验证同文件、跨文件、失效来源和横纵铺排。
2. 接通模板资源输出与双向同步，验证已有 UUID、切换模板、空绑定、重新读取以及预览节点隔离。
3. 运行共享测试、类型检查和生产构建，核对编辑器交互。旧文档继续读取，打开文件不隐式迁移已有节点。

## 验证记录

381 项共享测试通过。Edge 端到端覆盖本文件选择、导入外部 GameFlow、横纵铺排、Prefab 导出与双侧同步预览。项目自带的 Laya 引擎加载导出结果后，为 20 条数据绑定列表项，实例尺寸、第二项位置和视口外条目符合预期。
