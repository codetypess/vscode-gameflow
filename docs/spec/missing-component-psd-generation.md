# 页面与缺失组件 PSD 一起生成

Status: Done

## 复现与根因

将星海登录样例的画布 JSON 单独放入空目录，打开登录页并选择「生成 PSD」。两个画板都保留文件绑定。生成器看到组件的绑定后直接读取「服务器列表项.psd」，文件缺失的异常在请求保存父页之前终止生成。已有的组件写入逻辑也只接受尚未绑定的画板。

## 生成与验收

- 显式生成页面时，宿主确认已绑定的组件源文件缺失后，按当前组件画板生成独立 PSD，将同一份字节嵌入页面。已有可读的源文件继续复用。
- 缺失来源沿用新组件的命名和存放规则。保存时校验原绑定和磁盘状态，确认两份文件成功后采用实际绑定，刷新组件预览。取消、绑定变更、源文件重新出现或写入失败时保留已有文件和绑定。
- 权限、身份和解析错误继续报告给用户。同步按原有规则读取美术源文件。浏览器显式生成时使用本次会话里的组件文件，缺少快照的组件随页面一起下载。
- 用宿主回归覆盖保留绑定且两个文件均缺失、文件恢复和取消。用星海样例从「生成 PSD」入口读回产物，核对组件绑定和智能对象字节。

## 验证结果

修复前的宿主用例在读取组件时返回「文件不存在」。修复后 407 项共享测试和生产构建通过。Windows VS Code 宿主验证了缺失文件和损坏文件的独立处理。Edge 从两个画板均显示预览错误的状态生成两份文件，两个预览均恢复，父 PSD 中的智能对象与独立组件文件逐字节相同。后续复用已有组件美术稿的回归也通过。
