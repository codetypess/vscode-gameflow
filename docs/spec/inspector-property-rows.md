# 属性面板行与列统一

Status: Done
Date: 2026-11-17
Scope: 原型属性面板的普通属性单行、标签列及操作区对齐。

## Context and Goal

用户指出文字对齐按钮和语法开关没有对齐其它字段，并要求检查其它属性，除特殊组合外一个属性一行。当前普通字段使用 60px 标签列/7px 间距，文字行使用 48px/8px，数值组合及容器对齐也有不同列宽；最小值/最大值、描边宽度/圆角分别被放进双列网格。

## Behavior and Design

- 普通独立属性各占一行：拆开最小值/最大值及描边宽度/圆角。
- 普通行、布尔行、文字按钮行、数值组合、滑块、padding 及容器对齐共用 60px 标签列和 7px 列间距。
- 布尔属性标签在左、复选框位于输入列，与普通字段一致。
- 位置/尺寸/变换/滚动的轴分量、padding 四边、布局约束图、文字样式按钮、两轴对齐和语法开关属于有明确语义的组合控件，保持组合展示；窄面板允许按钮组换行。
- 不改变字段值、校验、锁定、覆盖标记、历史或保存协议。

## Verification and Acceptance

- 浏览器实测文字内容、字号、行距、样式、对齐、语法及布尔输入的操作区左边界一致。
- 描边宽度、圆角与最小值、最大值分别独占一行。
- 数值向量、padding、滑块和容器对齐采用同一标签列，窄窗口没有横向溢出。
- 运行已有测试和生产构建；此变化为呈现调整，不新增镜像 CSS 的测试。

## Risks and Rollback

面板纵向占用增加，沿用现有滚动。撤回行结构与 CSS 列宽即可恢复原布局，文档无迁移。
