# Canvas Context Menu

Status: Done
Date: 2026-11-17
Scope: 原型画板、节点及空白区域的编辑器右键菜单

## 1. Context

图层树已有节点编辑菜单，属性面板已有覆盖菜单；原型画板尚未接入，用户要求画板也可右键操作。复用现有命令和保护规则，避免产生另一套编辑语义。

## 2. Goals

- 页内右键节点显示与图层树一致的复制、粘贴、重命名、副本、删除、新增、转换及源组件操作。
- 右键已选节点保留多选；普通模式遵循当前编辑层，直选模式命中实际子节点。右键不启动放置、拖动或缩放。
- 页内空白菜单面向当前编辑层，提供粘贴、新增、适应画布及返回；新增位置使用右键的页面坐标，正确换算父变换及滚动。
- 总览右键画板提供进入编辑、重命名、生成副本、删除；空白提供新建四种画板和适应全部。
- 锁定、继承结构保护、撤销和文档事务沿用已有边界；默认浏览器菜单不干扰自定义菜单。

## 3. Non-Goals

- 不改变 PSD 工作区，不增加跨应用剪贴板，不增加新持久化字段。
- 不新增画板结构能力或绕过引用、控件绑定及锁定保护。

## 4. Current Behavior

`App` 的画布只处理 pointer/double-click，`LayerMenu` 仅由图层树持有。右键需要共享菜单呈现与既有命令；页面总览使用画板级操作。

## 5. Proposed Behavior

节点菜单沿用图层项及禁用原因，空白粘贴目的地为当前编辑容器。节点菜单的新增目的地仍按容器子级/叶子同级确定，位置来自右键点。右键空白清空节点选择但保留当前层。多选中任一可见成员的右键保留整组。

总览菜单始终以命中的画板为目标；空白不操作上一次选中的画板。重命名用带 Enter/Escape 的独立对话框，提交去除首尾空白并拒绝空名。菜单关闭后恢复画布键盘焦点，不移动视角；Escape 和外部点击可关闭。菜单遵循现有主题和视口碰撞避让。Shift+F10/菜单键可在画布上打开当前选择的菜单。

## 6. Design

- `LayerMenu` 增加可选背景父节点、菜单名称及附加视图操作插槽；图层调用默认行为保持一致。
- 画布在会话中保存命中节点/画板、坐标、背景层级及指针位置。复用 `canvasHitNode`、`pickSelection` 和已有文档命令，中央编辑事务继续验证引用所有权。
- 纯目标解析辅助函数覆盖逐层、直选、多选保留与背景父级；`placeCanvasComponent` 支持可选排序锚点，复用逆变换放置。
- 总览菜单独立呈现画板操作及新建类型；不将画板伪装为普通控件。
- 面板、工具条、字段及对话框不冒泡触发画布菜单；模式/页面/层级切换或目标删除后清理过时菜单。

## 7. Implementation Plan

1. 补充目标解析与共享菜单接口，接入页内和总览。
2. 补齐重命名、右键坐标放置和焦点/键盘行为。
3. 验证保护、历史及视口避让，同步编号基线与索引。

## 8. Testing Plan

- 共享纯测试：普通/直选命中、已选多选成员、空白保留层级、变换/滚动下新增及同级顺序。
- 浏览器：总览画板/空白菜单，进入/重命名/副本/删除及撤销；页内节点复制/粘贴、新增、重命名和多选；引用删除禁用、锁定禁用；背景当前层新增；Escape/键盘菜单、边缘及窄窗口避让，面板菜单回归。
- `npm test`、`npm run build`，记录实际覆盖与限制。

## 9. Acceptance Criteria

- 节点、页内空白、总览画板、总览空白均显示对应编辑器菜单，命令作用于可见目标。
- 右键无误放置/移动、无误删继承结构，多选保留；新增正确换算坐标与层级。
- 修改可撤销/重做，重命名可取消，菜单关闭后快捷键仍作用于画布。
- 检查、构建与实际交互结果记录后标记 Done。

## 10. Risks and Rollback

主要风险为右键目标与渲染选择不同、菜单导致旧输入未提交、当前层空白被误作页根、变换下放置坐标错误。读取最新文档并集中解析目标，复用现有命令及布局换算。变更只含会话交互，无格式迁移。

## 11. Validation

- `npm test`：244 项共享测试通过。新增覆盖逐层/直选右键目标、多选成员保留、空白父级/组件根，以及缩放滚动父级下的点击坐标、同级插入顺序与锁定拒绝。
- `npm run build`：扩展和 Webview 类型检查、生产构建通过，保留 Vite 现有大包体提示。
- 浏览器总览：画板右键进入编辑、重命名 Enter 提交、撤销、生成副本、删除指定副本及撤销；空白菜单不操作先前选中画板，新建 UIBox 画板及撤销通过，四种根类型均在子菜单中显示。
- 浏览器页内：普通模式命中引用根，直选命中继承文案；继承删除禁用。附加节点重命名并去除首尾空格、撤销、复制/当前层空白粘贴、粘贴撤销、页根空白按右键点新增文案及撤销通过。多选右键保留两个选框，混合继承选择禁用删除和重命名；锁定附加节点的删除和重命名禁用。
- Shift+F10 打开节点菜单；重命名对话框 Shift+Tab 循环及 Escape 取消不写名称。关闭后焦点返回画布。图层菜单与属性覆盖菜单保持独立，不误开画布菜单。
- 900×700 右下角主菜单与新建子菜单均完整位于视口内，随后恢复默认窗口。截图：忽略的 `dist/canvas-context-menu.jpg`、`dist/canvas-overview-menu.jpg`。
- 未逐一人工点击每个转换/新增类型；这些命令复用已有图层菜单和共享编辑逻辑。本次未修改持久化或宿主协议，未重复跨文件原生宿主验收。
