# Infinite Canvas Prototype

Status: Done
Date: 2026-11-12
Scope: 更新对话中的交互概念原型与产品规格；不实现或安装 VS Code 扩展。

## 1. Context

用户明确要求将一份策划文档涉及的所有界面放在同一无限画布，每个界面作为一组自由拖动，双击进入该界面的内部编辑。当前原型默认只展示一个页面，需要调整主要交互模型。

## 2. Goals

- 同时呈现文档内全部页面与弹窗，支持画布平移、缩放和适配全部。
- 总览时以页面组为选择和拖动单位，保持内部控件相对位置。
- 双击进入页面编辑，退出时恢复总览视角；内部修改实时反映到总览。
- 保留已有手动属性、层级、撤销和 AI 保护示例。

## 3. Non-Goals

本次不接入真实 Agent、不实现 VS Code 文件保存、不增加多人协同或完整游戏运行逻辑。页面间连线仅表达已有示例关系，不增加连线创作工具。

## 4. Current Behavior

原型提供需求分析、单页线框和单独页面关系三个视图；页面列表切换当前页面；所有页面无法一起自由摆放。

## 5. Proposed Behavior

- 默认进入所有界面的画布总览。单击选择页面组，拖动整组。
- 拖动空白平移画布；滚轮围绕指针缩放；提供缩放按钮和适配操作。
- 双击页面组进入内部编辑。保留同一画布，上下文页面减淡；操作范围切换到当前页控件。
- “返回总览”或 Escape 退出编辑并恢复进入前的相机位置与比例。
- 页面标题与页面列表可通过键盘选择，并提供明确的“编辑此界面”按钮。
- 页面关系作为同一画布上的可切换连线。

## 6. Design

页面增加世界坐标 `canvasX/canvasY`，与内部父级相对坐标分离。相机保存 `x/y/zoom`；编辑范围保存 overview/page 与 activePageId。

总览拖动只更新页面世界坐标；内部拖动只更新节点局部坐标。平移、缩放和进入/退出编辑不产生内容撤销事务。一次完整拖动对应一个撤销事务。取消手势恢复拖动前状态。

界面缩略内容与内部编辑读取同一页面数据。旧版示例状态迁移时补充页面世界位置，并默认进入总览。保存状态时忽略本地写入的回显，防止清空撤销记录。

采用页面内编辑范围而非打开另一个独立编辑器，以保留用户在同一画布上的空间上下文。

## 7. Implementation Plan

1. 建立本规格与最小产品基线；明确坐标与编辑范围。
2. 将单页画布改为多页面世界场景，实现平移、缩放、页面拖动及编辑范围切换。
3. 接回属性、层级、撤销和 AI 保护；更新产品方案。
4. 验证用户路径与数据不变性，记录结果。

## 8. Testing Plan

通过本地浏览器交互检查：初始所有页面可见；缩放后的组拖动；空白平移；双击编辑；编辑后退出；视角恢复；撤销/重做；保护状态；窄窗口和深浅主题。

检查拖动前后页面内控件坐标未变化；内部控件修改不改变页面世界位置；零移动点击不写撤销；点击或拖动不误入编辑；取消手势不留下部分变更。校验脚本运行错误与文档差异。

### Verification Results

2026-11-12：使用本地 Edge 无头浏览器与 Playwright 完成了全部交互检查。初始三个页面均位于可视区域；组移动的屏幕位移按缩放比例正确转换，内部节点数据保持不变；支持负世界坐标；空白平移只改变相机；双击进入、局部编辑、返回及 Escape 均正常，退出后恢复原总览相机。

另验证取消拖动恢复原文档、相机操作不占撤销步、重做恢复编辑、手动修改的 AI 保护、关系连线开关以及 390/320 像素窗口无非预期横向溢出。浏览器未报告脚本运行错误。已检查浅色总览、页面编辑与深色窄窗口截图，`git diff --check` 通过。

上述验证针对对话内概念原型；不代表 VS Code 扩展安装、项目文件保存或真实 Agent 已被验证。

## 9. Acceptance Criteria

- [x] 默认总览同时显示示例的三个界面，并可适配全部。
- [x] 页面组可以自由拖动，包括负世界坐标；内容相对位置保持不变。
- [x] 画布可平移、缩放，缩放后的拖动距离正确。
- [x] 双击进入指定页面编辑；总览单击或拖动不会编辑内部控件。
- [x] 内部文案与控件位置修改在退出后保留。
- [x] 返回总览恢复先前视角，页面位置保留，支持 Escape。
- [x] 页面拖动与节点修改可撤销、重做；相机导航不占撤销步。
- [x] 窄窗口无非预期横向溢出；深浅主题下标题与操作清晰。
- [x] 产品方案、编号基线和规格索引一致，说明仅完成概念原型。

## 10. Risks and Rollback

主要风险是世界坐标与节点局部坐标混用、缩放后的拖动误差，以及双击前两次单击导致 DOM 被重建从而丢失双击事件。使用独立坐标模型、屏幕位移除以相机缩放、手势结束时提交事务以及稳定的点击目标。

回退可恢复上一版可视化源文件与产品文档；不触及用户业务数据或安装环境。
