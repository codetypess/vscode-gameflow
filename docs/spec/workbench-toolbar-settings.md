# 工作台顶部操作与本机导出设置

Status: Done
Date: 2026-11-17
Scope: PSD 操作收拢到工作台顶部，统一保存、独立导出按钮，以及工作区本地资源/预制体目录设置面板。

后续规则更新：[文件导出目录](file-export-directory.md) 将本机两个路径明确为“根目录”，并增加随当前 GameFlow 文件保存的相对导出目录；输出组合为 root/dir。本规格的顶栏与本机存储规则保留，原“全部设置仅本机”的说明只适用于根目录。

## 1. Context

用户逐项确认：打开 PSD 仅图标；移除读取配置入口，仅自动读取 PSD 同目录同名 sidecar；保存采用顶部统一图标和 Ctrl+S；带配置 PSD 副本收进更多菜单；配置路径仅保存图标悬停显示；取消多处保存状态/常驻新建说明；顶部独立“导出”按钮。统一齿轮打开设置面板，分别设置资源、预制体输出目录。不同成员 checkout 同一 SVN 仓库到不同本机路径，目录存入 VS Code 本地存储，不能随项目提交。

## 2. Goals / Non-Goals

切图画布不再被操作条、路径条、备份/新建说明和导出目录条挤占。顶部保持一个打开入口、一个保存入口、更多菜单、独立导出按钮和齿轮。错误仍明确显示，导出冲突继续定位图层树。此项不接通 Prefab 导出或整页运行预览，不更改资源命名/来源契约。

## 3. Behavior and Design

- 原型与切图复用最上方工具栏；切图操作通过 React portal 投射到顶部，业务状态仍归切图工作区。独立 PSD 编辑器沿用相同操作。切换模式保留会话。
- 移除切图里的手动配置输入、完整路径及普通保存/备份状态。打开错误、保存失败、配置不兼容等诊断保留；原生标签圆点承担未保存提示。
- 顶部“导出”含文字，与齿轮和更多菜单独立。输出所有标记图层到资源目录；无产物时禁用。缺资源目录时打开设置面板并定位对应字段，不另起目录设置入口。
- 设置面板有两个只读路径框与文件夹选择按钮：资源导出目录、预制体导出目录。由宿主原生选择器选目录后即时保存到 extension workspaceState，不修改 .gameflow.json、.meta.json 或 .vscode/settings.json。预制体目录仅为配置，不宣称导出功能已实现。
- 宿主统一设置存储复用此前 gameflow.psdExportDirectory 已选目录，已有导出控制器每次导出重新读取，避免设置更换后仍写旧目录。其他已开工作台收到设置更新。
- Webview 只能发送固定目录字段和 read/choose/clear 动作，不能传任意文件路径。选择取消不修改现有值，校验失败在设置面板显示。
- 浏览器预览保持独立的会话目录句柄，与宿主路径存储分开，不宣称浏览器拥有本机任意路径或可持久化 VS Code 设置。

## 4. Verification Plan

共享契约覆盖字段/消息限制与旧目录采用；真实宿主验证 workspaceState 持久化、两个目录独立、取消保留、跨编辑器设置刷新与最新资源目录输出。浏览器验证打开真实 PSD 后顶部单行、更多菜单、设置面板、切换模式保留内容和窄窗口。原有共享测试、类型检查、生产构建、PSD/工作台宿主集成必须通过。

## 5. Acceptance Criteria

- PSD 打开/保存/更多/导出/设置在顶部，原四条辅助操作和状态行消失。
- 导出是独立文字按钮，配置导入入口消失，保存路径在悬停提示。
- 两个本机目录独立记忆，设置更换后下一次导出使用新目录；取消无副作用，原文档内容不变。
- 设置仅在 VS Code 工作区本地存储；不同工作区/成员无需修改共享 SVN 文件。

## 6. Risks

浏览器目录选择需要 File System Access 支持；明确会话边界。窄窗口缩减标题和低频历史按钮，不让顶部模式选择与主要动作重叠。设置持久化失败不显示成功，不更新导出路径为未保存值。

## 7. Verification

- `npm test`：280 项共享测试通过；新增旧目录采用/显式清空不复活、存储字段校验及严格消息边界覆盖。
- `npm run build`：双端类型检查和生产构建通过。保留既有 Vite 大包体提示。
- `npm run test:psd-host`：29 项真实 VS Code 检查通过，其中 6 项验证两个目录独立、已有导出器切换后输出真实 PNG 与来源清单、缺目录拒绝且不改源文档、memento 控制器重建与旧设置采用、注入选择器取消无副作用与面板广播、非法目录拒绝及清空后不恢复旧值。持久化接口使用 workspaceState；控制器重建与取消分支使用确定性 memento/选择器。
- 浏览器真实 PSD 验收：顶部单行、无旧切图操作/目录条、更多菜单副本入口、独立导出；缺目录打开设置并聚焦资源选择；设置两个只读路径字段、完成关闭；切回原型无遗留 PSD portal，回切保留 PSD；520px 窄窗口按钮/设置面板正常。浏览器未端到端选择真实导出目录，实际文件输出由宿主集成覆盖。
- 此项不补做先前中断的原生 × 对话框逐按钮点击，不将现有 dirty/save/revert 集成证据表述为该人工验收已完成。
