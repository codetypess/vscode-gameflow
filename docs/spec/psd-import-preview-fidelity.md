# 导入原型的 PSD 合成预览

Status: Done

在原型工作区打开从 `6.psd` 导入的 66 节点画板时，导入器将宽 1292 px 的剪贴花纹与按钮底图分别作为普通图片绘制。原 PSD 标明该花纹受宽 278 px 的底层轮廓裁切。标题纹理也依赖剪贴和混合。已绑定页面的美术资源模式在没有切图槽位时仍会显示这些基础像素。

导入复杂 PSD 时保存原文件的合成外观及导入时控件的视觉指纹。保留可编辑控件和命中区域。与导入内容相符的画板显示合成图，透明画布使用棋盘格。旧的已绑定导入页通过绑定源文件和导入内容比对恢复合成预览。修改控件外观或布局后立即按实际控件绘制，采用了切图的美术槽位继续显示实时切图。验收使用真实 6.psd 的完整导入页、旧绑定页、节点选择、视觉修改和还原。

在图片控件中按 PSD 文档坐标应用可读取的像素蒙版和剪贴底层的透明度，保留原控件边界。旧控件通过绑定 PSD 中的原始像素匹配剪贴修正图。复杂混合和图层效果在编辑后的逐控件绘制中仍有近似。

使用 1500 × 1334 的 `6.psd` 在 Chrome 原型工作台中验证了新导入、旧版 66 节点画板以及修改和还原“前往领取”文字。原始状态显示的图像与文件内合成图一致，文字修改后剪贴花纹在按钮外的像素透明。生产构建、403 项共享测试和 PSD 导入浏览器回归通过。
