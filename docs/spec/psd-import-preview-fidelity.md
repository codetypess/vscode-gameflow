# PSD 导入页的组件绘制

Status: Done

### 原型图层显隐

在原型树隐藏「组 1651」会修改节点的 `hidden` 字段，旧的整页外观比较便会退回基础控件绘制，标题、道具框和独立文字同时丢失效果。原型和美术 PSD 模式统一由组件树绘制。普通图片、文本、剪贴关系和混合样式归属各自的控件，桌面导入时可用 PhotoCraft 为带额外效果的独立像素层生成透明素材。分组描边和阴影应用在可见子节点的组合上，组外文字独立编辑。保存的整图只作为来源对照。切图槽位、九宫格和编辑区域继续由对应控件渲染。验证隐藏及恢复组、组内子层和独立文本，以及保存重开。

在 Chrome 中验证仓库 750 × 1334 的《获取途径》旧画板，实际点击「组 1651」的眼睛可隐藏并恢复按钮底图，组外文字仍显示。1500 × 1334 样本的截图回归验证按钮区域以外的像素差异为零，同时覆盖子层显隐、文本编辑、美术切图和新文档重开。生产构建和 403 项共享测试通过。
