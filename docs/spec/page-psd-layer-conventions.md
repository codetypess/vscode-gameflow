# 页面 PSD 图层约定与图片属性

Status: Done
Date: 2026-11-20

## 交互

- 页面进入美术 PSD 或预制体预览时都需要可读取的绑定 PSD。总览、页内画布和运行预览共用生成、绑定、加载与恢复提示。
- 原型属性编辑内置图。另两种模式只读显示图片的实际导出名称，悬停显示完整 PNG 路径。未提供的状态留空。移除逐槽位绑定入口。
- 按钮的公开组名对应控件名，直接子层或组 `@normal`、`@selected`、`@disabled` 对应三态。UIImage 可使用同名切图或同名组下的 `@image`。普通 PSD 可按这些标记直接使用。多义的映射报告相关图层，旧文件的稳定身份继续支持已有映射。
- 切图属性有「变量名称」和只读「导出名称」两行。清空手填变量后，默认按可见 PSD 图层名生成拼音首字母，保留英文及数字，并略去末尾的 UI 类型标注。PSD 切图变量属于图层配置。
- 导出名称为 `{图集名}_{变量名}`，共享资源也包含图集名。图集缺省取 PSD 文件名。手填变量遵循文件名字符规则并在导出时转小写。
- 按钮状态子层的变量由父组变量追加状态后缀，`@image` 沿用父组变量。状态子层的变量随父组更新。星海示例的父组变量 `start` 使 `@normal` 导出为 `login_start_normal.png`。
- 旧配置的自定义导出名称作为变量读取。旧按钮组值去掉此前用于存储的 `btn_` 开头，手填的新变量按原有字母和下划线生成。切图预览、PNG 导出和页面资源引用共用最终名称。
- PSD 装载或内容更新后，重新按当前页面结构解析。原型生成保持可读图层名，Prefab 模式在 PSD 就绪后读取磁盘像素。

## 本次变量与导出名称拆分

- 新增可选 `SliceConfig.variableName`，仅保存用户手填的变量；只读导出名始终即时计算，不持久化派生值。显式清空的新字段覆盖旧 `exportName`，恢复公开图层名的默认缩写。
- 只读导出名与状态子层的派生变量沿用「尺寸来源 / 显示尺寸」的灰色文字、小字号与紧凑内边距，聚焦时不显示编辑高亮，仍可选择复制。可编辑变量维持正常输入样式。
- 普通切图、按钮父组和图片父组共用变量规则。默认名移除末尾 UI 类型标注，不读取原型变量；新的手填变量保留用户输入的 `btn_`、`img_` 等字符，不添加类型前缀。
- 保留旧 `exportName` 的读取兼容；旧按钮组的 `btn_` 存储标记仅在旧字段回退中去除。共享开关只改变目录与覆盖规则，完整名称仍含当前图集。
- 验收：共享测试覆盖默认/自定义/清空/旧配置/状态继承及持久化；浏览器使用真实星海 PSD 验证两行、只读、图集切换、共享和实际 PNG 输出；生产构建与宿主测试通过。

## 历史验收记录

父组的默认导出字段原来直接显示按钮段，少了前缀和图集名。验收要求父组显示完整名称，状态层显示追加状态后的名称并保持只读。验证完整名编辑、清空、图集切换、已有简写及实际 PNG 路径。

原型变量和 PSD 公开组名是两个可独立变化的名称。上一版生成的 `btn_start` 由隐藏的 `startButton` 派生，图层树与切图配置不足以解释结果。回归使用与公开组名不同的旧变量元数据，验证清空自定义和父组改名后均按公开组名计算。浏览器打开实际示例，验证父组可见的 `start`、只读的切图文件名和清空后的回退。
