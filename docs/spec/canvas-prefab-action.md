# 画布预览与 Prefab 动作归位

Status: Done
Date: 2026-11-23
Scope: 移除独立运行预览，将 Prefab 同步/导出入口放入画布底部工具栏。

## 1. Context

原型工作台同时提供画布内的原型 / 美术 PSD / 预制体资源模式，以及右上角打开独立“运行预览”弹窗的 Play 按钮。两套入口重复，右上角还常驻带文字的 Prefab 同步按钮，挤占主工具栏。画布本身已经能承担当前资源与布局预览。

## 2. Goals

- 移除右上角 Play 按钮及独立运行预览弹窗。
- 保留画布上的三种资源模式，继续复用共享布局、绘制、切图和磁盘资源装载。
- 将 Prefab 动作以图标按钮放到画布底部“更多”按钮左侧。
- 页面已有 `prefabSync.target` 时按钮名称与图标表示“同步”；没有目标关联时表示“导出”。

## 3. Non-Goals

- 不改变 Prefab 生成、双向审阅、资源写入、缺失目标恢复或目标路径选择流程。
- 不改变 PSD 生成、绑定、切图或“更多”菜单内容。
- 不把资源模式或按钮状态写成新的文档字段。

## 4. Current Behavior

右上角依次显示带文字的 Prefab 动作、Play 预览和设置。Play 打开拥有独立页面、临时尺寸与控件状态的弹窗。底部工具栏的末尾只有“更多”。

## 5. Proposed Behavior

右上角不再出现 Prefab 动作或 Play 预览，仅保留适用于工作台顶部的设置及切图投射动作。底部工具栏在末尾分隔线后依次显示 Prefab 图标动作和“更多”。图标按钮通过 tooltip 和可访问名称显示“同步”或“导出”，不显示常驻文字。

按钮根据当前页面已保存的 Prefab 目标关联切换状态。已关联但磁盘目标丢失时，仍由既有“关联的预制体已移走或删除”流程确认是否重新生成；本次不新增后台磁盘轮询。

## 6. Design

- `CanvasExportActions` 继续拥有 Prefab 计划、审阅和提交状态，只把触发器改为底栏图标按钮。
- 同步使用循环箭头图标，导出使用包裹图标；处理中禁用按钮且提示处理中。
- 删除 App 对独立 `RuntimePreview` 的状态和渲染依赖，并移除只服务该弹窗的组件、样式与临时控件会话代码。
- 像素、九宫格、资源来源和画布资源模式继续由现有共享实现及画布回归覆盖。

## 7. Implementation Plan

1. 更新基线和入口规格。
2. 移动并精简 Prefab 动作，移除独立运行预览。
3. 调整浏览器与共享测试，验证底栏顺序、状态切换及画布预览。

## 8. Testing Plan

- 类型检查与生产构建。
- 共享测试确认删除临时预览会话后资源、九宫格与导出逻辑不回退。
- Prefab 浏览器回归确认“导出”位于“更多”左侧、导出后重开显示“同步”，并继续完成双向同步。
- 资源模式与页面 PSD 浏览器回归确认画布三种模式、像素隔离、圆形进度及切图诊断仍工作，且不再存在“运行预览”按钮。

## 9. Acceptance Criteria

- 原型工作台右上角没有运行预览和 Prefab 文字按钮。
- 画布底部“更多”左侧只有一个 Prefab 图标按钮；无关联显示“导出”，有关联显示“同步”。
- 既有首次导出、同步审阅、目标缺失恢复和资源缺失确认行为不变。
- 画布原型 / 美术 PSD / 预制体资源模式继续可用。
- 相关测试与生产构建通过。

## 10. Risks and Rollback

删除独立预览会减少临时尺寸、临时控件状态及 PSD 原图叠加检查入口；这些是本次明确移除的重复功能，不迁移到画布。若共享资源绘制回归，可恢复组件接线而不回滚 Prefab 写入格式或文档数据。

## 11. Verification

- `npm test`：376 项共享测试通过。
- `npm run build`：双端类型检查、扩展构建与 Webview 生产构建通过；保留既有 Vite 大包体提示。
- Edge `prefab-sync-browser.cjs`：底栏“导出”图标位于“更多”左侧且无文字，导出后重开显示“同步”；独立新增、文字冲突、脚本保留、导入元数据及零差异复查通过。
- Edge `resource-modes-browser.cjs` 与 `page-psd-browser.cjs`：三种画布资源模式、同名路径页面隔离、圆形进度像素、缺失资源确认、PSD 绑定/重载及无“运行预览”入口通过。
- 截图检查：右上仅保留设置，画布底栏动作与“更多”相邻，页面、浮动面板和底栏无重叠。
