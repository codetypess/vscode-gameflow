# PSD 复杂切图与原型预览

Status: Done

ag-psd 读取整页合成图、图层树和基础像素。桌面宿主按当前 PSD 快照调用 PhotoCraft CLI，渲染复杂图层、整组以及用户明确加入的其他图层。普通独立像素和内置素材沿用已有路径。浏览器独立运行时提示需要桌面宿主。

每张切图以主图层的 GameFlow ID 标识，附加图层也使用持久 ID。组包含其可见后代。组外文字默认独立。源图只读，临时渲染只产生透明像素和在 PSD 画布中的位置。渲染配置变更与源版本变化都应更新结果。

编辑区域、九宫格、资源清单及原型引用使用同一份渲染像素。整页美术对照显示 PSD 保存的合成图。区域可裁剪或向透明区扩展，已保存的区域位置可在重开时复原。导出失败显示具体原因，允许重试。

## 验证

- 在 Chrome 工作台和 PhotoCraft CLI 0.23.1 上运行 `node test/psd-photocraft-browser.cjs`。使用 `sample/6.psd` 的「组 1651」得到 301 × 73 的无字按钮，在属性面板显式加入图层 64 后显示「前往领取」。与 PSD 保存的整图同位置比较，17,922 个完全不透明像素的 RGB 各通道最大差值为 1（取值范围 0–255）。
- 四周增加 8 px 后导出 317 × 89 PNG。工作台「美术 PSD」画布与用相同九宫格拉伸到 421 × 89 的导出图逐像素相等。覆盖旁车配置重开、不同文件的同内容副本隔离、同一文件草稿刷新、缺少 CLI 的错误及恢复后重试。
- `npm run build`、403 项共享测试和 `npm run test:psd-host` 通过。原生宿主用例校验页面预览释放干净的 PSD 编辑会话后，仍可按快照读取渲染源。
