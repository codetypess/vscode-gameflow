# PSD 复杂切图与原型预览

Status: Done

ag-psd 读取整页合成图、图层树和基础像素。桌面宿主按当前 PSD 快照调用 PhotoCraft CLI，渲染选中的复杂图层或组。普通独立像素和内置素材沿用已有路径。浏览器独立运行时提示需要桌面宿主。

每张切图对应一个 PSD 图层或组，组的切图包含其可见后代。要把文字导出到按钮 PNG，美术把文字层放进按钮组。切图属性面板移除「合成来源」，读取旧切图配置时忽略附加图层。源图只读，临时渲染只产生透明像素和在 PSD 画布中的位置。

编辑区域、九宫格、资源清单及原型引用使用同一份渲染像素。整页美术对照显示 PSD 保存的合成图。区域可裁剪或向透明区扩展，已保存的区域位置可在重开时复原。导出失败显示具体原因，允许重试。

## 验证

- 在 Chrome 工作台和 PhotoCraft CLI 上运行 `node test/psd-photocraft-browser.cjs`。使用 1500 × 1334 测试样本的「组 1651」验证 301 × 73 的无字按钮、旧配置的组外图层引用，以及包含文字的父组导出。
- 四周增加 8 px 后导出 317 × 89 PNG。工作台「美术 PSD」画布与用相同九宫格拉伸到 421 × 89 的导出图逐像素相等。覆盖旁车配置重开、不同文件的同内容副本隔离、同一文件草稿刷新、缺少 CLI 的错误及恢复后重试。
- `npm run build`、403 项共享测试和 `npm run test:psd-host` 通过。原生宿主用例校验页面预览释放干净的 PSD 编辑会话后，仍可按快照读取渲染源。
