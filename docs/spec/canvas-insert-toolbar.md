# Canvas Insert Toolbar

Status: Done
Date: 2026-11-12
Scope: 在现有底部画布工具条加入向上展开的新增菜单，并支持页面与基础 UI 节点的真实插入。

## 1. Context

扩展脚手架已有底部工具条、页面总览和页面内部视图，但工具条只能选择、平移和缩放，无法创建策划界面内容。用户提供的参考是从底部向上展开的绘图工具菜单，并明确要求可以添加页面、矩形、文字、按钮和图片。

## 2. Goals

- 在底部工具条提供清晰的新增入口，菜单向上展开。
- 菜单使用现有 shadcn/ui 组件、Lucide 图标与 VS Code 主题 token。
- “页面”直接创建一个新的页面组并写入文档。
- “矩形、文字、按钮、图片”进入当前页面的放置模式；点击页面内部画布后创建对应节点并写入文档。
- 插入后的页面或节点可被现有总览、节点层级与 JSON 保存链路观察到。

## 3. Non-Goals

- 不实现铅笔、直线、箭头、椭圆、多边形、星形和自由路径。
- 不实现节点缩放、旋转、层级拖拽、富文本编辑或图片文件选择。
- 不改变宿主权威、全量候选文档协议或撤销模型。

## 4. Current Behavior

底部工具条仅有选择、平移、缩放、适合画布和不可用的 AI 生成按钮。页面与节点只能来自默认文档，页面内部视图只读。

## 5. Proposed Behavior

底部工具条新增一个带加号的按钮。点击后弹出位于按钮上方的菜单，按图标与文本列出页面、矩形、文字、按钮和图片。

选择“页面”后，在页面网格的下一可用位置创建空页面并选中。选择基础控件后，若当前不在页面内部视图，则自动进入已选页面；显示待放置工具提示。点击页面内部画布后，在点击位置附近创建默认尺寸节点，随后回到选择工具。2026-11-13 指针样式调整：放置与悬停时保持普通箭头，移除十字准星和常驻四向移动指针；实际拖动时才显示抓取状态。

## 6. Design

- 使用 Radix Popover 的 shadcn/ui 本地封装承载工具菜单，`side="top"`。
- 文档模型新增显式 `rectangle` 节点类型，避免用含义不明确的 `container` 冒充策划矩形。
- 页面和节点 ID 在 Webview 使用 `crypto.randomUUID()` 生成；无该能力时使用时间戳回退。
- 新页面采用三列世界坐标网格放置；节点坐标是页面局部坐标并被限制在页面范围内。
- 插入沿用 `replaceDocument` 消息与宿主 `WorkspaceEdit`，因此进入原生 dirty、保存与撤销链路。

## 7. Implementation Plan

1. 扩展模型、JSON Schema 与测试，加入 `rectangle`。
2. 加入 shadcn/ui Popover 组件和向上展开的工具菜单。
3. 实现页面创建、控件放置、状态提示和新增节点视觉。
4. 运行类型检查、测试、构建和桌面/窄屏视觉验证。

## 8. Testing Plan

- 共享测试验证 `rectangle` 被接受、未知节点类型被拒绝。
- `npm run build` 覆盖宿主与 Webview 类型检查和生产打包。
- 浏览器预览验证菜单向上展开且不会被工具条或视口裁切。
- 交互验证新增页面后页面数增加；添加四类节点后右侧层级与画布同时更新。

## 9. Acceptance Criteria

- [x] 底部新增按钮可打开向上展开的 shadcn/ui 工具菜单。
- [x] 菜单包含页面、矩形、文字、按钮和图片，并使用 Lucide 图标。
- [x] 新增页面会进入 `pages[]`，具备稳定 ID、默认尺寸和世界坐标。
- [x] 四类基础控件可通过页面内点击写入 `nodes[]`，坐标相对当前页面。
- [x] `rectangle` 同步到 TypeScript 模型、运行时校验和 JSON Schema。
- [x] `npm run build`、`npm test` 与 `git diff --check` 通过。
- [x] 桌面和窄屏工具菜单无重叠、裁切或文本溢出。

## 10. Risks and Rollback

当前控件使用默认尺寸且为单击放置，尚不是完整的矢量绘图体验。后续若引入拖拽绘制和节点选区，应单独定义编辑事务与命中测试。回退可删除 Popover、新增工具状态和 `rectangle` 类型；既有文档与宿主协议不受影响。
