# PSD File Drop

Status: Verifying
Date: 2026-11-16
Scope: PSD 切图及手动合并来源的拖入打开入口。

## 1. Context and Goals

当前切图和合并只能点击按钮选择 PSD；用户要求支持从文件管理器拖入打开。拖入应复用已有读取、错误报告与未保存配置保护。

## 2. Behavior

- 切图工作区的空态、已打开画布及面板均可接收单个 PSD；拖入时显示“松开以打开 PSD”。
- 合并来源 A/B 分别接收文件，包含标题、图层树和预览；提示明确标出目标来源。已有来源可拖入替换，读取成功后沿用现有规则清空采用选择。
- 每次只接收一个 .psd（后缀忽略大小写）；多文件、非 PSD 或空文件列表报明确提示，不读取、不替换。实际格式、大小及解码仍由 openPsd 校验；读取失败保留原会话。
- 切图未保存时沿用现有继续打开/取消弹窗；取消保留配置及历史。忙碌、九宫格编辑或确认弹窗打开时不接收新拖入。
- 合并区拖到来源以外不猜测目标，阻止浏览器直接打开文件并提示拖到 A/B。非文件拖动不触发打开；拖动经过子元素不闪烁，离开、取消、隐藏模式后清理提示。
- 保留点击选文件入口，原型文档及源 PSD 不被改写。

## 3. Design and Non-Goals

共享文件拖放 hook 处理原生 React drag 事件、拖入深度和提示状态；共用单文件判定。切图将 File 交给 readFile；合并 load 接收显式来源参数，避免沿用上次文件选择框目标。两条路径复用 openPsd Worker，加载期间互斥。

不增加多文件自动分配、配置文件拖入、跨会话恢复、PSD 输出或宿主文件路径协议。

## 4. Implementation and Verification

1. 增加共享拖放处理、空态文案及目标覆盖提示，接入切图和 A/B 来源。
2. 同步产品/架构基线。测试单文件判定、混合/多文件拒绝、非文件拖动；执行共享测试、类型检查及生产构建。
3. 浏览器检查两个模式的入口、真实样例读取、未保存保护及来源路由；若工具不能模拟操作系统文件拖动，明确记录实际验证边界。

## 5. Acceptance

- [x] 已接入切图空态与已载入区域，复用未保存确认及失败保留，并设置忙碌/弹窗保护。
- [x] 已接入显式 A/B 来源，阻止来源以外的文件导航；共用单文件校验及拖放提示清理。
- [x] 测试、类型检查、构建及差异检查通过，记录浏览器验证范围。
- [ ] 操作系统文件管理器实际拖入，包含跨子元素/区域、取消、忙碌和弹窗期间的手势验收。

验证记录：177 项共享测试通过，其中新增 2 项覆盖单文件、大小写后缀、空列表、多文件/混合文件及非文件拖动判断。类型检查、生产构建、差异空白检查通过，保留原有 bundle 大小提示。隔离浏览器页通过原文件选择入口读取真实 PSD（15 层）：修改切图名后替换会弹出确认；取消保留原 A 文件及修改，继续打开切换到 B 并清理未保存状态。损坏 PSD 读取报错且保留 B。合并先读取 B 时 A 保持空，再读取 A 后两边各 15 层；A 选中“开始按钮”得到 2 个结果层，B 读取失败保留两个来源及选择，B 重新读取成功清空选择。切回切图仍保留 B 及 15 层；控制台无 error/warn。截图 psd-drop-targets.jpg 记录两个来源区的拖入提示。

当前浏览器接口提供文件选择框上传，没有操作系统文件拖放接口，且只读 evaluate 禁止注入拖放事件。因此实际外部拖入手势、覆盖层出现/消失及 drop 事件路由尚未端到端执行，不将文件选择框验收算作拖入验收；状态保持 Verifying。

## 6. Risks and Rollback

外部文件拖入时浏览器在 dragover 阶段可能隐藏文件名，故悬停提示仅说明目标，后缀校验在 drop 时执行。保留原文件选择入口；回退拖放 hook、事件绑定和提示即可，无数据迁移。
