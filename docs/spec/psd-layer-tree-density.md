# PSD 图层缩进与共享导出标记

Status: Done
Date: 2026-11-18
Scope: PSD 图层树的层级缩进和共享导出状态显示。

## Behavior and design

- PSD 切图列表与原型图层列表按相同顺序显示，同一父级下从上到下依次为底层至前景。父组在子层之前，智能对象内部的只读图层沿用相同规则。

- 图层树每层缩进从 15px 收紧为 10px，保留 6px 根级边距与现有行高、字号及选择操作。
- 已勾选导出且标记为共享的非分组图层，在名称右侧显示 12px 白色分享图标，悬停提示“共享导出”，提供包含图层名的可访问说明。
- 取消共享或取消勾选导出后即时移除图标；普通图层和分组不显示该标记。状态直接读取已有配置，不新增持久字段。
- 分享图标与现有九宫格、冲突标记并列，不取代已有提示；窄面板中状态图标保持尺寸，图层长名称省略。

## Acceptance and verification

1. 使用真实 PSD 检查父子缩进为 10px；折叠、展开、勾选和选中仍正常。
2. 检查共享且勾选导出的图层显示图标；切换共享/导出状态后标记即时更新，九宫格图标同时可见。
3. 验证普通视口及窄视口布局，运行生产构建和 diff 检查。此变更仅涉及展示，使用浏览器验收，不增加镜像实现的单元测试。

## Verification results

- `npm run build` 通过，包含宿主与 Webview 类型检查；保留已有 Vite 产物体积提示。`git diff --check` 通过。
- 真实 PSD 的根级、子级、孙级内边距分别为 6/16/26px，每层缩进 10px。折叠/展开分组及图层选择、checkbox 操作正常。
- 按钮底图共享且导出时显示 12px 分享图标，悬停文字为“共享导出”，与九宫格图标同时可见；取消共享、取消勾选导出和折叠祖先时标记不可见，重新启用及展开后恢复。冲突标记保留独立渲染分支，经代码检查未被分享标记取代。
- 520×760 视口中图层行宽 238px，分享和九宫格图标均保持 12px 并完整位于行内；测试后恢复默认视口。控制台无 error。
