# Text Formatting Controls

Status: Done
Date: 2026-11-16
Scope: 属性面板文字样式、六项对齐、画布渲染与持久化。

## 1. Context

文字区只有水平三项对齐，UILabel 垂直对齐另放在组件设置的下拉框。用户要求集中呈现左/中/右和上/中/下六个图标，并用 B/I/U/S 四个开关取代字重下拉框。

## 2. Goals and Behavior

- 文字区提供“样式”行：加粗、斜体、下划线、删除线可独立开关，支持组合；四个按钮间隔 1px 紧凑排列，不再显示字重下拉框。
- “对齐”行提供水平三项与垂直三项，分为两组；每组独立选中一项，互不覆盖，并有选中高亮与悬停提示。
- 沿用所有已显示文字区的节点范围。UILabel 默认左/上，其余节点沿用已有水平及垂直默认值；移除重复的垂直对齐下拉框。
- 控件锁定及继承锁定时禁用全部样式/对齐按钮。每次有效点击沿用一次现有文档编辑，可撤销、重做及保存重开。

## 3. Design and Non-Goals

水平沿用 style.textAlign，垂直沿用 widget.valign。B 沿用 fontWeight，>=600 显示选中，开启写 700、关闭写 400；保留已有文档数值的读取，不提供数字字重选择。新增可选布尔 style.italic/underline/strikethrough，缺省 false，JSON Schema 与共享校验同步。CSS font-style 与 text-decoration-line 显示组合样式；输入文字继承节点水平对齐，避免原有固定 left 覆盖。

不增加字体、语法、材质或其他文字特效，不改节点布局/测量规则，不增加协议或文档版本。

## 4. Implementation Plan

1. 扩展样式类型、默认值、验证与 Schema，补充布尔类型及组合往返覆盖。
2. 添加紧凑图标行，替换字重/水平旧入口，移除垂直重复入口，连接画布样式。
3. 类型检查、生产构建和共享测试；隔离示例页验收按钮组合、对齐、历史、保存刷新和锁定。

- [x] 新样式组合可往返保存，非法布尔值在文档/消息边界拒绝。
- [x] B/I/U/S 四个开关和六项对齐正确显示，去掉字重和重复垂直下拉框。
- [x] 画布显示组合样式及水平/垂直对齐，点击只修改目标属性；锁定禁用。
- [x] Undo/Redo、保存刷新保留样式与对齐。

验收记录：新增 2 项边界测试，累计 175 项通过；16 种样式组合与 9 种对齐组合往返保留，非法布尔值在解析、验证、消息入口拒绝。隔离示例页用临时文字副本验证四个开关全部启用/关闭、下划线单独关闭时删除线保留、一次撤销/重做完整恢复装饰线，以及六项对齐的两轴互不覆盖。锁定父容器后 10 个按钮全部禁用，解锁恢复。保存刷新后保持 700/italic/underline line-through/right/flex-end。按钮宽 25px，四个样式按钮之间实测均为 1px。临时副本已删除，控制台无 error/warn；截图 text-formatting-controls.jpg 记录组合样式、右/底对齐和紧凑间距。

## 6. Risks and Rollback

保留旧 fontWeight 值，直到用户明确切换 B。装饰线可以同时开启，不互相清除。回退新增图标组件及可选样式字段即可；现有对齐字段与宿主事务保持兼容。
