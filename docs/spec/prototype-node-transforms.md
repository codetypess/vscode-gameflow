# Prototype Node Transforms and Numeric Property Rows

Status: Done
Date: 2026-11-16
Scope: 原型控件的锚点、缩放、倾斜和旋转，及可复用的紧凑数值属性行

## Context and Goals

用户希望引入 Laya 属性中的 Anchor、Scale、Rotation，并将截图中双轴数值框提取成常用属性控件。当前布局只支持无变换矩形，渲染、选框和拖动均直接相加坐标，需要在共享几何边界统一变换。

## Behavior and Design

- v2 节点新增可选 transform：anchorX/Y 默认 0、scaleX/Y 默认 1、skewX/Y 与 rotation 默认 0。Anchor 为 0～1；其余为有限数，角度单位为度，允许负缩放和零缩放。缺省字段不在读取时补写；v1 不接收 transform，正常首次编辑沿用现有升级事务。
- 沿用目标引擎 Sprite 的矩阵：X 轴角为 rotation+skewY，Y 轴角为 rotation-skewX；pivot=anchor×当前解算尺寸。x/y 表示父局部坐标中的锚点位置，子节点仍以左上角为局部原点。
- 约束尺寸按目标 UI 库使用缩放后的长度：双边拉伸除以 scale（零用 .01 回退），约束位置补 pivot×scale。HBox/VBox 使用有符号缩放长度，Grid 使用绝对长度并补偿锚点/镜像；旋转/倾斜不改变布局占位。错误尺寸继续给出布局诊断。
- 共享矩阵和裁剪多边形驱动画布预览、DOM 命中、选框及局部拖动。父变换与滚动叠加；选框沿变换后四边，手柄维持屏幕像素大小。拖动用父矩阵逆变换，缩放用节点矩阵逆变换并保持对边位置。零/退化矩阵隐藏画布像素并禁用画布尺寸手柄，可在树与属性中恢复。
- 换父级通过相对矩阵分解保留视觉形状，必要时用 skewX 表达非均匀缩放和旋转叠加；进入流式容器仍服从排布位置。不可逆的新父级拒绝换父级。复制、类型转换、撤销及保存保留变换；复制身份仍重新分配。
- 提取 NumericPropertyRow：左侧名称，右侧 1～2 个带轴前缀的数值框，支持独立禁用/最值/步长/整数规则、Enter 提交、Escape 还原及完整中文 aria-label。位置(X/Y)、尺寸(W/H)、锚点(X/Y)、缩放(X/Y)、倾斜(X/Y)、旋转(度)复用；间距和静态滚动也复用双轴行。沿用 VS Code 主题，在 280px 面板完整排布。
- Anchor/Scale/Skew/Rotation 最多显示两位小数，不补尾零（0、1、0.5、1.25），步长 .01，直接输入提交最多保留两位；内部矩阵和自动换算保留精度，未编辑失焦不覆盖原值。锚点编辑的坐标保持策略已由 [anchor-position-preservation.md](anchor-position-preservation.md) 更新为换算 X/Y 与布局补偿以保持视觉位置；底层矩阵仍遵循引擎语义。页面根仍只编辑画板位置/尺寸。
- 锚点仅用空心圆标记，无填充或十字线；圆形保持屏幕像素大小，不受节点缩放或倾斜影响，不拦截鼠标操作。
- 移除属性面板的父容器下拉框，父子层级通过树拖动调整。
- 数值输入聚焦全选，允许直接替换显示值，避免在旧值已有小数点时追加第二个小数点被浏览器拦截；选框改用 outline 绘边，避免 border 将子级手柄中心相对几何顶点推偏 1px。树拖动在换父级被拒绝后立即退出，不再继续排序。

## Non-Goals

不引入引擎运行时、Prefab 导出、旋转拖拽手柄、吸附或 PSD 图层变换编辑；不改动已有节点 ID。

## Risks and Rollback

旋转包围盒不能替代节点局部尺寸，因此保持 local/frame 和 world/absolute 明确分离。凸多边形裁剪处理旋转容器。零缩放不可逆，保留属性恢复路径。撤销/回退时保留新增字段与数据，不能静默丢弃。
