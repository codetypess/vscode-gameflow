# 原型与切图面板宽度

Status: Done
Date: 2026-11-27

## 范围与现状

原型总览的页面属性、页内图层和属性，以及 PSD 切图的图层和属性共用跟随画板的定位规则。原型两侧默认各 280px，切图两侧各 278px，窗口过窄时按比例收窄。

## 交互与存储

- 拖动任一面板的左、右边缘，实时改变该面板的宽度。正常窗口的最小值等于该模式原来的默认值。
- 拖动期间固定对侧边缘。松手后立即使用新宽度重新贴靠当前画板，图层面板在左、属性面板在右，空间足够时保持 16px 间距。空间受限时沿用视口限位和两面板避让规则。
- 拖动时对侧面板保有自身宽度，两侧保持间距。窗口不足以容纳偏好宽度时优先收回增宽部分，恢复窗口后使用原偏好。
- 宽度属于本机界面偏好。VS Code 使用扩展 globalState，浏览器预览使用 localStorage。按原型、切图及左右侧分别存储，打开其他页面、独立 PSD 或重新加载工作台时复用。拖动只影响界面布局。
- 画布平移、缩放和适应窗口使用新的宽度。面板内部滚动、选择及折叠继续使用现有交互。

## 实施与验收

1. 扩展共享布局计算，验证宽屏、窄屏和单面板的可见宽度及边界。
2. 两个工作台接入相同的边缘拖动和本机设置，验证四个面板可独立调宽、缩回下限，拖动期间画布保持原位。
3. 使用浏览器切换模式并重新加载，核对恢复的宽度；运行共享测试和生产构建。

## 验证结果

生产构建及 422 项共享测试通过。Chrome 交互测试覆盖左右边缘拖动、拖动下限、双面板窄屏恢复、总览属性、模式切换及重载。VS Code PSD 宿主回归覆盖本机宽度读写、非法宽度过滤和设置控制器重建。

先前松手时仍保留拖动定位。Chrome 复现中图层面板应停在视口左侧 12px，实际停在 54px。修复后临时定位仅在拖动期间生效。浏览器回归验证了页内图层加宽、总览属性从左向右收窄及 PSD 属性收窄后的停靠位置，并验证独立宽度重载。
