# 三模式工作区与 PSD 九宫格配置

Status: Done
Date: 2026-11-13
Scope: 顶部原型/PSD 合并/PSD 切图模式、真实 PSD 读取及图层切图配置、九宫格编辑、同名元数据与 PSD 副本输出。图片导出格式及 Laya 配套规则由用户明确保留待定。

## 1. Context and Goals

用户希望在顶栏中央切换三种工作模式。PSD 切图模式选择图层图片，参考 Laya 拖动四条虚线或输入上/右/下/左边距，配置可保存在 `登录.psd` 同目录的 `登录.meta.json`，也能内嵌于 PSD。原型编辑及未保存状态在切换时保留。

最新 UI 调整：模式切换仅保留图标（LayoutPanelTop / GitMerge / Scissors），按钮 30×22px，外框约 26px 高，保留悬停提示和无障碍名称。

## 2. Scope

- 原型沿用现有编辑器，模式切换后原型快捷键不影响 PSD 工作区。
- PSD 切图读取用户选择的标准 8 位 RGB PSD，显示真实图层树、已保存整图和选中图层；每层可标记切图、命名、设置九宫格。
- 九宫格以图层像素边界为基准，四个整数边距，repeat 标志；虚线拖动/数字同步，滚轮缩放、右键平移、拉伸预览、确认/取消。
- PSD 合并模式提供两个来源树/预览及选择结果预览的手动工作区；无 Base 时明确手动选择。生产三方自动比较与完整 PSD 合并写出继续遵循既有 Draft，不因有入口而宣称完成。
- 图片及 Laya `.meta` 导出待定，本轮不定义最终切图目录或目标引擎格式。

## 3. Persistence and Identity

- 项目配置命名为 PSD basename + `.meta.json`，版本化记录文档谱系、源文件指纹、图层 ID、原生 ID、切图标记和九宫格；不嵌入图像。
- 有效的图层元数据提供身份；缺失身份分配新 ID，重复 ID 提示用户选择副本并作为新节点，不按内容推断原件。无效/不支持版本报错。
- 源文件指纹完全一致时，显式导入配置可按记录位置及原生 ID 恢复新分配或已修正的身份；源文件变化后仅按元数据身份匹配。导入结果不得出现重复 ID 或混合文档谱系。
- 读取 PSD 时以嵌入数据初始化；显式导入 sidecar 表示采用该配置，校验谱系和图层映射，发现源指纹不同须明确确认。未知字段保留。刷新/切换不自动修改 PSD。
- “保存配置”输出 `.meta.json`；“写入 PSD 副本”输出当前源 PSD 的元数据补丁版本。两种操作各自报告成功，不把一个成功当作两者都同步。
- PSD 内只修改图层 `shmd/gflw`，保留其他元数据、图层像素、文字、资源和合成数据的原始字节；不用普通库全量重建美术 PSD。未知二进制结构不支持时阻止写出。
- 输出重复 ID 或不合法九宫格时阻止保存；取消编辑不改变配置。

## 4. Architecture

- 原型文档仍由宿主 TextDocument 管理；PSD 配置为独立导入/输出会话，不污染原型模型。
- Webview 仅通过用户选择的 File 获取 PSD/sidecar；PSD 解码在 Worker 内执行，限制尺寸、文件大小、图层数和累计解码像素。浏览器预览下载文件；VS Code 由宿主验证输出名称/类型/大小并通过保存对话框写文件，Webview 不指定目标路径。
- Webview 使用本地 shadcn/ui Button/Input 和 VS Code 颜色。Worker 单独打包并以 blob 运行，CSP 仅开放对应本地资源/Worker。
- 图层直接预览只承诺基础像素/文字的保存栅格；蒙版、剪贴、效果等需要依赖合成的层标出限制，整图仍可参考 PSD 自带合成图。
- 合并结果保留选中图层的祖先层级，并继承父分组的隐藏状态。代码审查发现仅读取图层自身隐藏标志会错误显示隐藏分组的子图层；在解码边界统一计算有效可见性，以嵌套分组回归用例验证。

## 5. Acceptance and Verification

- 切换三模式保留原型和已载入 PSD，PSD 模式下 Delete/Undo 等不修改隐藏的原型。
- 样例 PSD 能打开，图层可选，九宫格四线与数字同步；范围约束保证至少1像素中心；输入和拖动/取消/重复模式有对应验证。
- 配置导出/重新导入恢复选层配置，重复 ID 和不同谱系不可被静默覆盖。
- PSD 元数据补丁输出由独立解析器回读；像素、非 GameFlow 附加项及合成数据保持原字节；真实样例九宫格写回可验证。
- 运行类型检查、构建、共享测试，并执行可用的浏览器交互检查；真实 Extension Host 或 Photoshop 未执行时明确记录。

## 6. Risks and Rollback

首版是受限 PSD 读取与元数据工具，不能宣称高级 PSD 合并或 Laya 导出完整。源文件只读、保存副本，读写能力失败保持源文件和配置。代码与新数据模型独立于原型 v1，可回退新模式而保留原型编辑。
