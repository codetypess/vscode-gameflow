# 画布直选模式

Status: Done
Date: 2026-11-16
Scope: 原型底部工具条与页内画布命中选择。

## 1. 目标与范围

用户要求在底部工具条左端、虚线框按钮之前加入默认关闭的“直选模式”。开启后直接选择容器内实际命中的子节点，关闭后沿用当前层直属子节点的逐层选择规则。此项只改变 Webview 会话视图，不改变文档格式、宿主协议、PSD 或总览整页操作。

## 2. 行为与设计

- 以带点击射线的鼠标指针图标（Lucide `MousePointerClick`）显示开关，中文提示“直选模式”，高亮和 `aria-pressed` 同步表达状态。按钮控件统一改用圆角矩形内带三点的 `RectangleEllipsis`，底部快捷入口、添加菜单及图层菜单共用图标配置。新会话/刷新默认关闭，切页、总览和工作模式切换保留当前会话值；不写入文档或浏览器存储，不产生撤销步骤。
- 页内开启时使用 DOM 实际命中的可见节点，不将后代替换成容器；容器自身可见背景仍可选容器，页面/画布空白清空选择。可连续跨容器分支选择，隐藏节点和隐藏祖先下的节点不可选；锁定节点沿用可查看、不可修改的保护。
- 选择仍复用现有选择集合：父层路径、图层树定位、属性和选框随目标同步。Ctrl/Cmd 可增减不同分支节点；Shift 范围按目标直接父容器的直属节点顺序，跨父级无有效锚点时只选目标。拖动与手柄沿用原有坐标解算及保护。
- 直选时页面按原始绘制顺序呈现，停用当前编辑层的背景压暗和前景提升，使所有分支都可按实际层叠命中。路径继续表示选择的父级，新增/粘贴仍使用现有当前层规则。
- 单击及双击使用同一命中模式：开启时双击实际命中的容器进入其子层，双击文字/输入聚焦文字属性；关闭后恢复原有逐层规则。切换开关本身保留选择、编辑层、相机与当前工具。

## 3. 实施与验证

1. 扩展共享画布命中纯函数，默认参数保持逐层选择；测试深层复合部件、跨分支、容器背景、空白、隐藏与锁定节点。
2. 接入默认关闭的会话状态与底部按钮，统一单击/双击路径；直选时保持全页正常绘制，复用现有多选与拖动。
3. 浏览器以星海远征样例核对：默认点击按钮文案选择按钮，开启后选择 UILabel；可跨分支选择、关闭恢复逐层选择、空白/多选/拖动/双击行为正常；切页/模式保留状态、刷新重置且不修改文档。
4. 运行 `npm test`、`npm run build` 和 `git diff --check`；更新产品与布局基线。

## 4. 验收与风险

- [x] 指定位置存在默认关闭的开关，状态与提示正确。
- [x] 开启选择实际子节点、关闭恢复逐层选择，树/属性/路径一致。
- [x] 直选跨分支、隐藏/锁定保护、多选和编辑手势通过验证。
- [x] 开关不改变文档/历史，保留会话状态且刷新默认关闭。
- [x] 测试、构建和浏览器验收通过。

主要风险是选中深层节点后自动进入其父层，使下一次命中受旧范围或前景提升影响；直选命中覆盖整个当前页面，渲染关闭范围遮罩和前景提升，避免这一限制。回退只需恢复命中参数和移除开关，不需要数据迁移。
