# 原型复合控件与可选按钮文字

Status: Done
Date: 2026-11-16
Scope: 落实用户确认的容器控件结构：UIButton 可选 UILabel；Slider、CheckBox、Radio 显式子节点皮肤；RadioGroup 显式成员关系。对应资产协作总方案的第一阶段。

## 1. Context

用户在确认 [控件资产协作方案](laya-control-asset-bindings.md) 后要求先实现。当前控件允许子节点，但 Slider/CheckBox/Radio 视觉由 DOM 占位生成，无法编辑部件；按钮删除文字后又显示名称。已有布局、变换、宿主事务和 PSD 会话保留。

## 2. Goals

- UIButton 默认创建独立按钮根，UILabel 可按需添加、删除；无文字时不显示节点名。
- 新 Slider 创建轨道 UIImage、滑块 UIImage、说明 UILabel，skin 引用滑块；CheckBox/Radio 创建底框、选中标记、说明。
- 明确选择皮肤节点，按目标规则预览状态和滑块位置，真实子节点可编辑。
- 加入 RadioGroup 容器及有序成员引用；复制、删除、换父级和保存重开保持合法关系。

## 3. Non-Goals

本轮不输出 PSD 图片、接入 Prefab、改写 xq-client 或实现游戏事件/交互运行模式。现有 PSD 会话独立。UIProgressBar 的节点皮肤与 UIButton 的状态图片资产另行接入。

## 4. Current Behavior

`makeComponent` 默认创建按钮文字；`NodeView` 对无子节点按钮回退到名称。选择控件和 Slider 的占位图没有独立身份，复制操作只重映射父关系。当前文档版本为 2。

## 5. Proposed Behavior

- 新建按钮仅包含根；通过已有添加子节点操作创建 UILabel。旧明确保存的根 text 继续显示，但无 text 时不补名字。
- 新复合控件的图片占位为真实 UIImage，可替换图片；说明为独立 UILabel。节点名不决定部件身份。
- 属性面板提供“滑块节点 / 选中标记”选择，限直接子节点，允许清空。Slider 皮肤禁止相对约束，位置由 value 与 direction 派生；尺寸和变换仍可编辑。
- 所有支持子节点的控件，其“容器布局”属性分区默认展开，允许手动收起；不按控件类型区别默认展开状态。
- CheckBox/Radio 的 skin 显隐取决于 selected；隐藏标记仍参与测量，disabled 不附加变灰效果。
- RadioGroup 使用有序引用，允许空槽及 -1；显示树顺序和父级不决定成员关系，同一 Radio 不可重复或同时加入两个组。属性面板可增删、排序及选择成员。
- 删除或将皮肤移出控件时，在同一撤销事务清除其引用；删除组成员保留空槽，删除当前选中项清空选择。UI 提示该引用行为。复制只重映射副本范围内部引用，外部引用清空，避免第二个组隐式接管原成员。
- 旧无部件字段的低保真节点继续读取，并提供显式建立默认部件的操作；创建部件保留根 ID、已有子节点及设计状态，旧文案转为新 UILabel。

## 6. Design

- schema v3 新增 `widget.skinNodeId: string | null`，仅限 checkbox/radio/slider；`radioGroup` 类型及 `widget.optionNodeIds: (string | null)[]`，选中索引沿用 selectedIndex。
- 接受 v1/v2 文档；普通读取不改数据，第一次有效编辑通过现有事务升级为 v3。旧版本拒绝 v3 字段/类型。旧文本与低保真节点不自动转换。
- 共享控件模块负责引用校验、状态投影、皮肤关系和引用重映射。PSD 资源引用以后独立建模，不占用 skinNodeId。
- Slider 位置以滑块经变换的矩形跨度计算，纵向从上到下增长；派生坐标不写回 frame。控件自身测量排除滑块移动带来的位置反馈。
- 皮肤受控位置禁用直接拖动/坐标编辑和相对约束；尺寸与变换变化重新计算。状态可见性用于渲染和画布命中，层级树仍可选择隐藏部件进行编辑。
- RadioGroup 选择统一由组派生，组成员的 selected 属性面板改为组选择操作，解除关联后保持当时的选中状态。

## 7. Implementation Plan

1. 更新模型、JSON Schema、引用校验和版本；实现模板与引用生命周期。
2. 更新共享几何、可见性与控件属性面板，增加 RadioGroup 工具入口。
3. 运行覆盖复制/删除/转换/状态/几何/持久化的测试，构建并在浏览器验证交互。
4. 同步架构和原型布局基线，记录验证结果。

## 8. Testing Plan

- 空按钮及可选文字、三个控件真实子节点与皮肤引用。
- 非直接子节点、失效引用、非法控件字段、重复/跨组 Radio 及旧版本拒绝。
- 子树/整页复制、剪贴板粘贴、身份迁移、删除/换父级/转换后的引用和选择。
- Slider 双方向端点、中间值、缩放/旋转/锚点、零行程、测量与受控编辑。
- CheckBox/Radio 派生可见性与组选择、空槽、排序及保存重开。
- 全部共享测试、生产构建，浏览器实际创建、绑定、编辑、删除文案、复制与撤销。

## 9. Acceptance Criteria

新按钮没有必需文案；新控件部件在树内可见且可编辑；改变值和状态只影响目标部件；引用在常规编辑后合法且可撤销；v1/v2 内容可读取并在编辑时升级；完整测试及构建通过。PSD/Prefab 管线仍明确为后续能力。

## 10. Risks and Rollback

新增引用必须覆盖所有 ID 变更路径。既有低保真节点按字段是否存在区分，用户显式转换；不在读取时猜测已有子节点角色。v3 文档需使用支持该版本的编辑器，旧版本应拒绝读取。

- 最终 140 项共享测试、类型检查与生产构建通过，包含分组类型转换及复合皮肤显示规则。构建保留既有大包提示；差异空白检查通过。
