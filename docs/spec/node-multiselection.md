# Node Multiselection and Tree Keyboard Focus

Status: Done
Date: 2026-11-16
Scope: 原型层级树/画布的节点多选与选中后的键盘操作。

## 1. Context and Root Cause

用户希望树选中节点后直接用键盘操作，不出现额外焦点框，并通过 Ctrl 自由多选、Shift 连续多选。当前仅维护 selectedNodeId；树名称按钮 pointerdown 和 click 重复执行单选，并由默认 pointerdown 获取焦点。浏览器现场确认 activeElement 为 layer-name layer-draggable 且 :focus-visible=true，与截图额外边框一致；选中背景自身正常。此前只修复了画布点击后的焦点移交，未覆盖直接树选中。

## 2. Goals

- 单击替换选择；Ctrl/Cmd 点击增减任意节点；Shift 点击按当前可见树行连续选择，Ctrl/Cmd+Shift 追加区间。
- 树与画布共享选择集合和范围锚点，画布显示全部选中节点；选中即可方向键移动、Delete/Backspace 删除。
- 鼠标树选中不让名称按钮获得焦点框；键盘 Tab 访问按钮仍保留可见焦点。

## 3. Non-Goals

不实现多选统一缩放/旋转、属性批量赋值、框选或跨页面多选。不修改文档及协议格式。

## 4. Proposed Behavior

- Shift 只包含当前展开且满足搜索路径的树行；折叠/筛选不可见行不加入区间。锚点不在当前列表时退化为点击目标。重复 Shift 点击以同一锚点调整区间。画布 Ctrl/Cmd 增减当前层节点，Shift 按当前层直属子节点绘制顺序选区间。
- 多选时点击已选节点可直接拖动整组，轻点则收为单选；修饰点击只改变选择、不启动拖动。空白/Escape 清空，导航/钻入重置选择。
- 树可跨父级自由多选，编辑层级为所选节点父路径的最近公共容器；单选仍直接打开目标父层。结构编辑/撤销后清理失效 ID，不改变相机。
- 多选显示每个节点选框、数量及名称摘要；多选属性面板不提供易误解的单节点属性。隐藏/锁定节点仍能从树选择。
- 方向键、画布拖动、Delete、复制/粘贴、副本和树拖动作用于选择集合，以一次文档事务提交。父子同时选中时只操作最上层已选根，避免后代重复移动/复制。复合控件引用在同批复制时跨根重映射。
- 保护操作的原子性：涉及锁定根、不可逆父空间或受控 Slider 滑块的移动时不部分修改；流式容器仍遵循原有布局/重排规则。复制允许只读快照。
- 树鼠标选择 preventDefault 后聚焦树面板（不滚动、不绘制外框），键盘继续走已有编辑快捷键；避免 pointerdown/click 造成 Ctrl 反复切换。右键已选行保留集合，菜单复制/副本/删除按集合执行。

## 5. Design

Webview 会话状态保存 ids、primaryId、anchorId，纯函数管理替换/切换/区间/失效清理及公共作用域。模型批量操作复用共享布局、编辑事务与引用校正；复制森林共用一张 ID 映射，保留内部跨根引用。多选不进入文档历史，内容批量编辑进入一次历史。

## 6. Implementation Plan

3. 验证键盘/拖动/保护/撤销和单选层级回归，同步基线。

## 7. Testing Plan

选择规则覆盖 Ctrl 增减、双向/重复 Shift、追加区间、缺失锚点、折叠/搜索、父子去重、结构变化和公共路径。批量操作覆盖移动、约束/变换、删除清引用、复制跨根引用、粘贴和锁定原子性。执行 npm test、npm run build、git diff --check。当前无 DOM 组件运行器，浏览器验收真实焦点伪类、修饰点击、选框/摘要、方向键/Delete/撤销、拖动及菜单；剪贴板快捷键若被浏览器工具拦截，以菜单和共享纯函数验证内容逻辑。

- [x] 树、画布、层级和多选摘要一致，单选/导航/空白/搜索行为正常。

## 9. Risks and Rollback

重点防止重复事件切换、拖动把多选收为单选、父子重复编辑和复制内部引用丢失。可整体回退 Webview 多选及批量辅助函数，不涉及文档迁移。
