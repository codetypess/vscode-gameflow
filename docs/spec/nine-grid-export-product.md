# 九宫格切图产物与导出参数

Status: Done
Date: 2026-11-18
Scope: 单层及区域切图的九宫格无损缩减、最终边距和布局尺寸。

用户确认九宫格中段默认尝试缩减，并要求导出参数随实际产物计算。当前批次从 PSD 配置重新取得尺寸和边距；引入缩减后，PNG 与这组源数据不再处于同一尺寸。

先生成裁切后的区域，再独立检查横纵中段。拉伸区只缩减像素完全等价的行或列，最多保留 8 px；重复区保留从原起点开始的完整周期，要求原长度是周期的整数倍。验证包含沿该轴延伸的边条。无法确认不改变像素则保留该轴原长。四边固定区不参与缩减。

以输出坐标计算四边厚度并验证。`width` / `height` 为 PNG 像素尺寸；例如宽 490、左右各 20，保留 8 px 后，右分界从 470 移到 28，离右缘仍为 20。仅缩减时添加可选 `logicalSize` 保存原区域尺寸，用于自然布局；旧清单继续按 PNG 尺寸使用。最终描述随 Canvas 进入预览、正式批次和清单。原图对照仍使用原区域尺寸。

验收：固定边、单轴缩减、保留渐变、完整重复周期、原尺寸和变尺寸还原、导出与重新加载的 PNG 及参数一致、旧清单仍可读取。不改写 PSD 标记、组渲染、外部自动刷新和引擎专用文件。

浏览器回归：把裁切后的 31px 纹理横向缩到 15px 后，再恢复原尺寸，直接缩放分块会在中段起点采到分块外的红色固定边（期望 `0,32,64,255`，实际 `95,20,40,255`）。缩放使用隔离的分块像素，维持分界两侧独立取样。

验证：322 项共享测试、37 项 VS Code 宿主检查、7 项 Edge 浏览器像素验收和生产构建通过。浏览器覆盖原尺寸、拉宽、透明边、固定边、渐变和 PNG 解码往返；共享测试覆盖短周期、沿轴边条细节、无效参数及来源清单读取。
