# PSD 图层元数据交接样例

Status: Done
Date: 2026-11-13
Scope: 独立 PSD 实验样例、元数据对照清单和美术测试说明；不接入扩展，不确立生产 PSD 格式。

## 1. Context and Goals

用户需要真实 PSD 文件，交给美术验证图层自定义属性。制作一个游戏登录页面，包含命名分组、独立视觉图层，以及写入 PSD 内部的 GameFlow 图层 ID / role / state。PSD 原生数字图层 ID 与 GameFlow 的 8 位字符串 ID 分开。

## 2. Design

- 在 `examples/psd-metadata/` 交付 PSD、PNG 预览、可读元数据对照和中文测试说明。
- 选择有实际读写支持的 PSD 图层元数据载体，记录准确块名/命名空间；不以外部 JSON 代替内嵌数据。
- 提供可重建样例和回读验证的脚本；实验依赖安装在临时目录，不修改扩展依赖。
- 随包交付离线 HTML 检查器，选择实际 PSD 后回读元数据，与随包原始对照比较，标出缺失/重复 ID；只读文件，可导出 JSON 检查报告。
- 保留供美术使用的自然图层名称，稳定身份不依赖名称。
- 读取实际输出 PSD 检查图层树、唯一 ID、元数据内容及预览。可用时通过 Photoshop 验证打开/保存，再回读；未完成的外部验证明确记录。

## 3. Non-Goals

不实现生产导出器、PSD 合并或元数据编辑插件，不宣称支持所有 Photoshop 特性或其他工具的无损保存。生成样例不改变现有原型文档/Prefab。

## 4. Acceptance and Testing

- PSD 是可解析的 RGB 分层文件，包含分组和独立标题/按钮/背景。
- 元数据从 PSD 本身回读，节点 ID 唯一且符合 `[a-z][a-z0-9]{7}`。
- 核对生成图像与预览，记录解析器版本和验证边界。
- 说明指导美术另存副本并测试重命名、移动、复制与新增图层；复制时重复自定义 ID 是待检测情况，不能假定 Photoshop 自动分配新 ID。
- 源样例和测试副本分开，收回副本后可读取/比较元数据。

## 5. Risks and Rollback

Photoshop 或其他 PSD 工具可能改写/删除附加信息；本次样例用于验证该风险。外部测试结果不预先写成通过。样例、脚本和说明可整体移除，无运行时依赖。

## 6. Delivery and Verification

- 交付 `examples/psd-metadata/GameFlow-PSD-Metadata-Sample.psd`：960×640、8 位 RGB，5 个分组、10 个内容层（其中 5 个文字层），15 个内嵌身份。
- 实验载体为图层 Additional Layer Information → `shmd` → `8BIM:gflw`，内容是带 `com.codetypes.gameflow` 命名空间、版本和 documentId 的 UTF-8 JSON。未确立生产协议，也未声称注册了该 key。
- `ag-psd@34.2.0` 写入；独立边界读取器回读全部字段并与输入逐项比较，ID 唯一，文字层数及像素层数符合预期。
- `psd-tools@1.10.9` 独立解析出同一层级与全部 15 份元数据；保存合成图与 PNG 逐像素一致；绕过保存合成图重新合成图层，最大通道差异为 1（舍入），图像检查通过。
- 检查器 JavaScript 语法和本地依赖齐全性通过，实际 PSD 读取代码已运行。内置浏览器安全策略拒绝 `file:` URL，因此没有完成浏览器交互验收；没有绕过该限制。
- Photoshop 打开/保存、改名/移动/复制/新建的验证交给美术，说明与 `verification.json` 均明确尚未实测 Photoshop。样例交付完成不等于 Photoshop 保留性已通过。
- 本次未变更扩展运行时、模型和依赖；无新的长期基线规则。源码、独立验证和交接 ZIP 均可追溯到同一 PSD。
