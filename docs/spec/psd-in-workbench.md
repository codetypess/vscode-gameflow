# 工作台内 PSD 会话与关闭保护

Status: Verifying
Date: 2026-11-17
Scope: PSD 在当前工作台内打开；原型与 PSD 由一个原生工作台文档管理保存、撤销、关闭确认和恢复。

## 1. Context / Root Cause

用户明确不希望“打开 PSD”再新增 VS Code 标签，并要求点击工作台标签 × 时提示保存。当前入口发送 openPsdEditor，宿主执行 vscode.openWith 打开 gameflow.psdEditor，故必定新增标签。独立 PSD 文档解决了原生关闭保护，却改变了用户确认的统一工作台体验。原工作台为 CustomTextEditorProvider，仅原型 TextDocument 能影响该标签 dirty，不能承载独立 PSD 未保存状态。

## 2. Goals

- 工作台“打开 PSD”在同一 Webview 切图区域装载；切换原型/PSD 保留会话。
- 任意原型或 PSD 配置未保存均使工作台标签 dirty；× 使用 VS Code 原生保存/不保存/取消。取消不关闭；保存全部完成后才关闭；失败保留标签与草稿。
- Ctrl+S 和原生保存统一保存工作台内已修改文档；PSD 仍保存相邻 .meta.json，源 PSD 不改写，原型 JSON 不嵌入 PSD 配置。
- 保留同名配置自动读取、源/配置冲突检测、草稿恢复及 PSD 副本操作。

## 3. Non-Goals

不实施整页运行预览，不修改元数据格式、资源命名或控件布局。Explorer 单独打开 PSD 的配置编辑器保留。

## 4. Design

工作台改为 CustomEditorProvider，自有文档保存原型内存快照、版本和保存基线，聚合关联 PSD 会话。复用 PSD 宿主文档模型/备份/保存和 Webview 候选同步；PSD 编辑事件转发为所属工作台原生编辑事件，避免临时修改原型 JSON 来伪造 dirty。原型编辑仍以完整候选和版本确认进入同一原生历史。

CanvasReferenceController 通过受限文档访问接口适配工作台内存文档，继续校验源版本和指纹；原有 TextDocument 调用保留。跨文件采用的源变更与实例覆盖清理作为同一事务撤销，保存/外部变化仍明确归属相应文件。

更换 PSD 前同步候选并提示保存/放弃/取消；历史仍可能引用旧 PSD，因此所有历史关联会话保留到工作台关闭，保存/恢复涵盖其未保存修改。当前 PSD 路径记在扩展工作区状态而非原型 JSON；正常重开可自动读取原 PSD 与配置。原生备份记录工作台和 PSD 恢复文件，自动检查点用于异常中断恢复。

## 5. Implementation / Testing Plan

1. 建立统一工作台文档生命周期和引用访问接口。
2. 复用 PSD 会话在当前 Webview 挂载，接入原型/PSD 模式切换及文件打开。
3. 类型检查、共享回归、真实 VS Code 集成：无新增 PSD 标签、PSD 修改令工作台 dirty、原生保存/撤销重做、保存失败、备份恢复、放弃与源不变。
4. 手工检查原生 × 对话框及模式切换；工具不可见时明确记录缺口。

## 6. Acceptance Criteria

- 从工作台打开 PSD 后 VS Code 标签数量不增加，原型和 PSD 均在原工作台可用。
- PSD 修改驱动工作台原生 dirty；保存写正确 sidecar 且不改写原型或 PSD 源。
- 原生保存、放弃、撤销/重做与恢复覆盖聚合会话；失败保持 dirty。
- 已有画布引用及原型编辑不回退；测试/构建通过并记录人工验收范围。

## 7. Risks and Rollback

从 TextDocument 转为 CustomDocument 后须显式维护原型保存/外部变更、备份与跨文件事务。外部并发更新通过版本/内容基线拒绝覆盖。可恢复旧独立 PSD 编辑器，但不把它作为工作台打开动作的默认实现。

## 8. Verification Progress

实现已经接通。263 项共享测试通过；初次完整类型检查及生产构建通过。真实 VS Code 集成通过原有 13 项 PSD 检查和新增 10 项工作台检查：不增加 PSD 标签、PSD 驱动工作台 dirty、保存不改原型/PSD 源、两类编辑的原生历史、聚合保存、原生放弃与清理草稿、备份恢复、重开当前 PSD、保存冲突保留 dirty。

原型保存期间使用 workspace.fs.rename 替换当前资源，会触发 VS Code 文件移动参与者，销毁并从旧备份重建工作台；已通过原生实例 disposed/replaced 证据确认。当前原型本地保存改为文件系统原子替换，避免工作台文件移动通知；对应集成回归通过。

2026-11-17 逐按钮 UI 验收启动后，电脑控制被用户按实体 Escape 停止，取消/保存/不保存的实际点击验收尚未完成。

随顶部操作/设置交付完成基线同步、完整构建复核和 280 项共享回归；隔离真实宿主的原有 13 项 PSD、10 项工作台检查及新增 6 项目录设置检查全部通过。浏览器真实 PSD 验证切换模式保留内容、顶部独立导出、设置与更多菜单及 520px 窄窗口。关闭对话框逐按钮点击仍为单独人工验收缺口，未声称已覆盖。
