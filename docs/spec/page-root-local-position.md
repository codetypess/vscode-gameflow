# Page Root Local Position

Status: Done
Date: 2026-11-16
Scope: 页面根属性在总览和页内编辑之间的坐标语义

## Root Cause and Expected Behavior

用户在进入页面后选中根节点，位置仍显示总览摆放坐标（例如 -628/-463）。`App` 已用 editingId 区分作用域，页内画板绘制位置为 0/0；但 Inspector 没有接收作用域，在 node 为空时始终使用 page.frame，导致显示/编辑的坐标系与画布不一致。根约束配置不参与预览布局，与本问题无关。

- 总览页面属性 X/Y 显示并编辑 page.frame.x/y，即无限画布摆放坐标。
- 页内根节点 X/Y 显示局部原点 0/0，只读；局部原点不可移动。子控件继续显示并编辑解算后的父局部坐标。
- 两种作用域的 W/H 都编辑设计尺寸。页内改尺寸不得把显示的 0/0 写回总览坐标；返回总览恢复原摆放坐标。
- Inspector 显式接收页内编辑标记；页面 frame 按编辑的单一键更新，页内 X/Y 写入有作用域保护。复用 Field/NumericPropertyRow 的 readonly 能力，保留无障碍名称及 Enter/失焦/Escape 行为。
- 作用域变化仅改变投影，不新增文档字段、迁移或历史事务；稳定 ID、根约束、内容及其他属性保持。总览拖动/改坐标、页内尺寸变更仍走现有保存与 undo/redo。

## Verification and Acceptance

1. 独立样例中从总览选择偏移页面，记下 X/Y，进入页面后根显示只读 0/0；返回总览值不变。
2. 页内改 W/H、保存重载、undo/redo 均保留原总览 X/Y。只读输入无法覆盖原点或触发页面移动。
3. 总览 X/Y 仍可编辑，重新进入后为 0/0。子控件位置仍可编辑且符合原有约束规则。
4. 类型检查、现有共享测试及构建通过；记录浏览器实际交互。仓库无 DOM 组件测试运行器，本问题位于 App/Inspector 的作用域传递及字段提交，不增加纯显示函数或 CSS 镜像测试。
