# PSD 画布与跟随面板

Status: Done
Date: 2026-11-13
Scope: PSD 切图画布的缩放平移、图层树及切图属性跟随定位。

## Context and Goals

当前切图模式将图层树、属性面板固定到视口两侧；PSD 只有自动适应大小预览。用户要求两块面板贴近 PSD 左右边缘，缩放和拖动时跟随，且始终留在可见区域。

## Behavior and Design

- 切图画布保存独立的屏幕相机 `{x,y,zoom}`。滚轮围绕鼠标所在点缩放；拖动 PSD 或画布空白平移。普通指针在拖动时变抓手，鼠标中/右键也可平移。提供缩放、100% 和适应窗口按钮。
- 图层树位于 PSD 左侧，属性位于右侧，默认间隔 16px、顶部对齐 PSD。面板文字和控件不随 PSD 缩放。
- 两面板采用相同宽度，正常窗口均为 278px；窄窗口同步缩窄，仍保持同宽。
- 根据实际视口尺寸、PSD 屏幕边界和面板高度定位。临近边缘时钳制位置；两面板保持左右顺序、不互相覆盖。视口太窄时等比例压缩面板宽度，太矮时限制高度并内部滚动。
- 面板上的点击、输入、树滚动、九宫格编辑不触发画布手势。切换模式保留相机；隐藏模式产生的零尺寸测量不覆盖有效视图。调整窗口保持相机中心并重新限制面板位置。
- 新源 PSD 首次适应窗口时预留两侧面板空间。配置或选层变化仅更新面板尺寸，不重置相机。相机及面板布局不写入 PSD、sidecar 或撤销历史。
- 本轮仅改切图工作区，不扩展合并逻辑和文件输出格式。

## Acceptance and Verification

1. 数学测试验证鼠标定点缩放、初始适应、平移跟随、极端缩放与四边越界时面板保持在视口内且互不覆盖。
2. 浏览器实际载入 PSD，验证滚轮缩放、拖动、面板保持固定尺寸且跟随、窗口变化、模式切换及属性操作不驱动画布。
3. 类型检查、构建、共享测试和 diff 检查通过；记录实际执行与未执行的验证。

## Risks and Rollback

极窄窗口或 PSD 放大越过视口时，面板可能覆盖 PSD 的一部分，以保持面板可见和可操作为优先；适应窗口可恢复完整构图。布局逻辑独立于 PSD 数据读写，回退仅影响视图。
