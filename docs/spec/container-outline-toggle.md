# Container Outline Toggle

Status: Done
Date: 2026-11-16
Scope: 原型底部工具条与容器边界辅助显示。

## 1. Context

用户要求移除底部工具条的“选择”和“抓手”两个按钮，以默认不选中的“虚线框”开关替代，开启时显示容器组件的虚线边界。

## 2. Goals

- 用一个虚线方框图标开关替代两个按钮，并提供“虚线框”提示和按下状态。
- 新会话默认关闭，开启时显示所有可包含子节点组件的辅助边界。
- 关闭后恢复原预览；切换不修改文档或撤销历史。

## 3. Non-Goals

不移除 V/H/空格快捷键，不改变原有选择、平移、插入、节点边框样式或持久化格式。

## 4. Current Behavior

底部提供独立选择与抓手按钮；节点只绘制文档样式中的实线边框，没有容器边界辅助显示开关。

## 5. Proposed Behavior

底部最左侧显示“虚线框”按钮，初始 aria-pressed=false，无选中背景。点击切换高亮与 aria-pressed；开启后在总览和页内编辑中，为 COMPONENTS.children=true 的可见节点显示虚线辅助框，包含复合控件及兼容的旧矩形。文字、图片、输入和下拉等叶子不显示。显示遵循节点变换、显隐和祖先裁剪；辅助框不接收指针。切页和工作模式切换保留当前会话开关值，刷新后默认关闭。选择实线框和手柄保持原有行为。

## 6. Design

使用独立 React 布尔视图状态，不与当前编辑工具互斥，不调用文档编辑接口。复用 shared/ui-components.ts 的容器能力判定及现有节点解算几何，辅助框与文档样式分离，不占据布局空间。

## 7. Implementation Plan

1. 更新规格与产品基线。
2. 替换按钮并实现容器虚线辅助显示。
3. 运行类型检查、构建和现有测试，浏览器核对默认状态、切换、范围、变换与编辑手势。

## 8. Testing Plan

浏览器验证旧按钮移除、新按钮初始未选中、开启/关闭、容器与叶子的范围、隐藏/裁剪/变换、选择和键盘平移、会话切换、刷新默认值，以及开关不改变保存数据。运行 npm test 和 npm run build。

验证结果（2026-11-16）：当前代码的 166 项共享测试、类型检查和生产构建通过。浏览器确认旧按钮不存在，初始 aria-pressed=false 且无辅助层；开启后样例总览显示 29 个容器辅助框（12 个使用祖先裁剪），页内 22 个辅助框与可见容器数一致。切换前后全部 67 个可见节点的样式保持一致；关闭移除辅助层且保留选择。旋转与裁剪样例显示正确，辅助层 pointer-events=none，容器子层的背景/前景辅助框分别处于遮罩下/上。V/H、模式切换保留值及刷新关闭均通过。检查期间工作区曾短暂缺失 descendants 导入，导致进入子层白屏；当前导入已恢复，原操作复核和最终构建通过。效果图保存为本次会话的 container-outlines.jpg。

## 9. Acceptance Criteria

- [x] 旧选择/抓手按钮移除，虚线框按钮默认关闭并正确表达按下状态。
- [x] 开启仅为可见容器增加虚线辅助边界，关闭移除，显示跟随现有几何和裁剪。
- [x] 切换不更改文档、当前工具或选择，原有编辑与平移可用。
- [x] 类型检查、生产构建、现有测试与浏览器检查通过。

## 10. Risks and Rollback

辅助边界可能与现有边框或选框重叠，采用独立的无指针装饰层避免修改布局和命中。可仅回退本项的视图状态、按钮和辅助样式，文档格式无需迁移。
