# Prototype Page Root Types

Status: Done
Date: 2026-11-13
Scope: 页面/组件画板根类选择与添加菜单的 LayaUI 类型标注

## Context and Goals

用户希望添加菜单显示 UIBox、UIView 等类名，并新增 UIStack、UITop、UIScene 页面类型。当前页面仅有 screen/modal 形式，控件类名只在属性面板中可见。

## Behavior and Design

- 底部添加菜单提供堆叠界面 (UIStack)、顶层界面 (UITop)、场景界面 (UIScene)。UIView 作为基础类，不作为页面类型选项。快捷键 + 和空画布入口默认创建 UIStack。
- 上方“添加到画布”另放一份“自由容器 (UIBox)”，直接创建独立组件画板（初始 320×240），供 ItemRender 等复用组件设计；双击进入后按正常页面编辑层级。下方控件区域保留自由容器，进入页面后才启用，用于添加子容器；底部快捷工具与 F 也仅在页面内添加子容器。暂不接入列表 itemRenderer 绑定。
- 页面属性的“页面类型”可切换 UIStack/UITop/UIScene/UIBox 四个根类；原 screen/modal 改称“页面形式”，独立保留。类型切换保留 ID、名称、控件、位置和页面形式。
- 新增可选 page.rootType；缺省有效值为 UIStack，不在解析时补字段。v2 接收四个值，v1 拒绝显式 rootType；已有 v1/v2 无字段文件无编辑往返不变，首个有效编辑沿用事务升级机制。
- 页面属性身份与层级树根节点显示实际根类。底部和右键节点添加菜单显示中文名及括号内 LayaUI 类名；新节点名称保持原中文默认值。
- UIStack 中文名为“堆叠界面”，UIPanel 面板组件中文名为“面板容器”；矩形工具保留“矩形”名称。
- 底部添加菜单去掉右侧快捷键字母与 + 提示，快捷键行为保留。
- 页面复制保留根类并重新分配页面/节点 ID；保存、协议校验、撤销/重做沿用现有文档链路。
- 此轮实现原型根类配置，不接入 UIStack 管理器、UITop 层级管理、UIScene 生命周期或 Prefab 导出。

## Implementation and Verification

1. 扩展共享类型、映射、运行时校验及 JSON Schema；保持旧文档兼容。
2. 接入创建入口、属性选择、根节点标注和组件菜单类名；菜单在屏幕内滚动。
3. 测试四类往返/协议、缺省与非法值、复制和 v1 编辑升级；构建和现有测试通过。
4. 浏览器验证创建、类型修改、撤销重做、保存重载、菜单可读性及层级树显示。

## Acceptance Criteria

- 三种界面及 UIBox 组件画板均可创建、编辑并保存；切换类型不改变页面内容与 ID。
- 旧文件按 UIStack 显示且无编辑不被重写；非法类型和 v1 显式类型被拒绝。
- 底部及右键菜单显示组件类名，页面根类型与属性一致。
- 构建、测试和浏览器交互检查通过；同步产品及数据基线。

## Risks and Rollback

根类与页面形式不得混用，否则旧弹窗语义会丢失。可选字段避免强制迁移；回退前应保存含新字段的文件副本，旧版本可能不识别该字段。

## Verification Record

- 构建及 72 项共享测试通过（本项新增 5 项），覆盖四种根类的序列化/协议、旧文件缺省、非法值与 v1 拒绝、复制层级、编辑升级及撤销重做快照。
- 浏览器分别创建 UIStack、UITop、UIScene，并撤销恢复；UIBox 独立画板为 320×240，可双击进入并通过右键添加面板容器。
- UIBox 改成 UITop 后页面 ID 和内部节点保持，undo/redo 同步类型及层级根标注。保存重载后恢复 UIBox 和内部面板容器。
- 添加菜单上/下两份 UIBox 按画板/子控件分区，总览下方禁用；菜单没有快捷键列，面板容器及其他控件类名显示正确。
- 浏览器未发现 console error。未运行真实 Extension Host，此轮宿主边界由共享协议校验覆盖。
