# PSD 资源命名、共享与统一导出目录

Status: Done
Date: 2026-11-17
Scope: 切图属性的自定义导出名和共享标记，拼音首字母默认名，同 PSD 重名检查，以及统一目录 PNG/来源清单输出。

## 1. Context

用户明确所有导出图片放入同一目录，同名表示同一资源；目录维护来源元数据。PSD 中文图层名用于策划/美术，同名图层表示同一资源，两个同时勾选导出时报冲突。未共享资源与其他 PSD 的已有输出重名时报冲突。自定义导出名为空时仅以 placeholder 显示默认名：非共享为 `{前缀}_{PSD文件名拼音首字母}_{图层名拼音首字母}`，共享为 `{前缀}_{图层名拼音首字母}`；图层名包含“按钮”用 btn，其他用 img。

本规则替代 runtime-slice-preview.md 中按 assetId 自动命名文件的建议。PSD 文档/图层 ID 继续用于来源追踪，导出资源由统一目录内的名称识别。

## 2. Goals

- 中文图层名保持；默认导出名不写入输入值，清空自定义名即恢复默认。
- 保存、重开与 undo/redo 保留自定义名和共享标记。
- 同名图层多选、拼音缩写碰撞、显式名称碰撞、跨 PSD 非共享覆盖均明确报错。
- 同一选定目录输出 PNG 和 gameflow-resources.json，记录来源、尺寸、九宫格和版本。

## 3. Non-Goals

此次不接入整页运行预览、复杂 PSD 效果合成、导出组重建或九宫格中段缩减。输出沿用现有可切的独立像素层及其 PNG 数据，附带真实九宫格配置；目录来源清单不冒充已经接入 Laya 导入格式。

## 4. Current Behavior

当前 SliceConfig.name 为旧切图名称，默认填中文图层名，无合法文件名及冲突约束。工具仅保存 .meta.json / PSD 元数据副本，无 PNG 批量输出和目录来源清单。

## 5. Proposed Behavior

- UI 字段改为“导出名称”。新增可选 exportName，缺省/空字符串代表默认；旧 name 保留原样用于已有配置，不自动把中文旧值解释为新的导出名。新增 shared 布尔字段，缺省 false。
- 默认名前缀按图层名是否包含“按钮”选择 btn/img（PSD 文件名中的“按钮”不影响前缀）；去掉 PSD 扩展名，中文使用固定版本 pinyin-pro 3.29.5 按词组读音取每字拼音首字母，已有 ASCII 英文数字保留并转小写，分隔符合并为下划线。不以短 ID 或自动数字后缀消除重名。无法产生合法默认名时提示自定义。
- 标记为共享时默认名省略 PSD 文件名，跨 PSD 的同名图层得到同一默认资源名；取消共享恢复带 PSD 名的默认规则。placeholder、冲突检测及实际导出使用相同规则；自定义名不因切换共享而变化。
- 自定义名限定英文字母、数字、下划线，输出统一小写，扩展名由工具添加。禁止设备名、路径、空白和非法长度。
- 同 PSD 依据中文图层名（trim + NFC）检查多次导出；即使自定义名不同仍报冲突。不同图层最终输出名称相同也报冲突。未勾选副本不产生第二份输出。
- 用户选择一个导出目录，可主动切换；VS Code 保存在工作区状态，浏览器保留在当前页面会话。每次写入前重新读取目录与清单，整批检查通过后输出。不同 PSD 的占名冲突显示资源和原来源。
- 用户已确认“共享且要导出，就覆盖”：共享资源覆盖同名图片及九宫格，来源清单更新为当前生成 PSD；未标记导出的层不写入。目录没有该资源时首次生成并登记。非共享异源同名资源冲突。同 PSD 多图层同时导出仍冲突，不因共享放开。
- 已有但无来源记录的同名文件，未共享则冲突，显式共享可覆盖并建立来源记录；已有来源清单格式损坏则拒绝整批导出。来源用持久 documentId 识别，未嵌入身份的 PSD 需保存配置并在下次打开后读取以恢复身份。
- 冲突在图层树名称右侧显示警告图标；父分组标记后代冲突，收起后仍可见。悬停名称/图标及选中后的属性区显示原因。目录冲突在导出前读取目录后回传定位；修改配置后清理旧目录诊断，下次导出重新检查。局部命名冲突实时计算，阻止导出但不阻止取消勾选或修正配置。

## 6. Design

共享纯函数负责默认名、候选资源与目录冲突计划；宿主/浏览器只负责目录读写。目录清单记录规范化最终文件基名、生成 PSD 名、documentId、layerId、图层名、源 hash、图片 hash、尺寸、九宫格与共享开关。每个名称只有一个当前生成来源。写入前复核目标文件未在本次检查期间变化，防止使用过期检查结果。

VS Code 通过原生目录选择器获得输出目录；Webview 不能指定任意磁盘路径。浏览器使用 File System Access 的目录选择能力，缺失时明确提示使用 VS Code；不能将普通下载声称为目录导出成功。

预检完成后写图片，最后提交清单；写入失败尽力恢复已写文件并报告具体失败，不把半批次当作完成。宿主进程内同目录已有导出时拒绝第二个请求；独立进程同时修改目录仍需用户避免。PNG 批次最多 128 项 / 48 MB，清单限制 8 MB。

## 7. Implementation Plan

1. 命名与配置、冲突纯函数及来源清单验证。
2. 导出目录服务、宿主协议与浏览器目录适配。
3. 输入 placeholder、共享开关、即时冲突与目录导出 UI。
4. 更新方案和基线，执行类型检查、共享测试、构建及浏览器验收。

## 8. Testing Plan

覆盖中文/英文混合、数字、多音词、btn/img 前缀、自定义名、空值与非法文件名；同图层名双选、不同名缩写撞名、共享/非共享异源碰撞、同源更新、无清单文件、检查期间文件变化、写入失败恢复、来源记录与保存重开。浏览器检查真实 PSD 的 placeholder、清空、共享保存恢复及树行/折叠分组冲突显示。

复查发现目录扫描与目标读取之间可能出现同名新文件：计划仍使用旧文件名列表，而备份读取已经包含新文件，仅复核字节无法发现这一变化。共享目录服务在写入前还须复核相关文件名集合（包含大小写变体及清单），有变化则中止；回归覆盖扫描后新增未登记目标，确保零写入。

## 9. Acceptance Criteria

- 登录页面.psd / 按钮底图默认显示 btn_dlym_andt，输入值为空。
- 登录页面.psd / 服务器底板默认显示 img_dlym_fwqdb；自定义名不追加前缀。
- 标记共享后，上述两层默认显示 btn_andt / img_fwqdb；输入值仍为空。自定义名优先，取消共享恢复非共享默认名；不同 PSD 的共享同名层输出同一文件并更新来源。
- 中文名称无需修改即可输出 ASCII 文件名；自定义优先，清空恢复默认。
- 名称冲突阻止整批图片写入并给出可定位提示。
- 导出目录中只有一份对应资源文件和可追踪的清单记录；共享按确认规则处理。
- 类型检查、测试和构建通过，验证结果记录在本文。

## 10. Risks and Rollback

拼音首字母天然可能重名，必须显式改名。图层改名、切换共享状态或非共享 PSD 改名可能改变默认输出名；共享默认名不受 PSD 改名影响。工具展示当前有效名，不自动删除上次导出的旧文件。旧配置保持可读取，不自动重写旧 name 字段。未有内嵌身份时需保留配置恢复来源身份。
