# Compact Insert Menu

Status: Done
Date: 2026-11-13
Scope: 底部添加菜单的紧凑布局

## Context and Behavior

页面根和 16 种控件按单列显示，菜单高度超过常用窗口空间，需要滚动查找。用户要求尽量避免滚动。

- 页面根、控件各自用紧凑双列排列，保留中文名称、类名和图标；正常菜单宽 440px，行高约 28px。
- 菜单保持向上展开并限制在视口内；常用桌面尺寸一次显示全部选项。
- 窄窗口按可用宽度回退单列，极矮窗口允许内部滚动，确保所有条目可访问。
- 保持添加页面、选择控件放置工具、总览下控件禁用、键盘 Tab 和 Escape 的行为。
- 本轮只调整底部添加菜单，不变更右键菜单、文档或编辑事务。

## Acceptance and Verification

构建通过。浏览器在 1280×720、960×540 检查全部 20 项可见且无滚动；窄/矮视口检查菜单未越界、全部选项仍可访问；选择工具和 Escape 关闭有效。纯布局调整不新增镜像 CSS 的测试。

## Risks and Rollback

双列增加横向占用，由视口宽度约束和单列回退控制。回退菜单布局无需迁移数据。

## Verification Record

- 构建通过。在 1280×720 和 960×540 视口，20 个按钮完整显示，菜单宽 440px、高 355px，scrollHeight 与 clientHeight 均为 353，无滚动条。
- 360×420 视口回退单列，宽 336px，左右各留 12px，内部允许滚动且无横向溢出；末项可由键盘聚焦，Escape 正常关闭。
