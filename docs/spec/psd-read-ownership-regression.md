# PSD 读取会话占用回归

Status: Done
Date: 2026-11-24
Scope: 页面 PSD 宿主读取与重新生成

## 根因与目标

PagePsdController.ensure 将后台读取注册到 provider.documents 和 workbench.psds，直到工作台关闭才释放；generate 将所有注册项视为占用。因此生成后自动读取、或恢复页面预览，就足以使再次生成失败，并非操作系统文件锁。

## 行为与设计

后台操作完成后释放没有修改、未被切图面板使用且不是 currentPsd 的读取会话。保留页面 artPsd 关联和返回的预览快照。切换切图通过 ensure 从磁盘重新载入，不使用已释放会话。

生成允许复用本工作台的干净会话，并沿用 ensure 的源哈希检测刷新；拒绝未保存的切图配置、脏文本文件和其他工作台/编辑器持有的会话。读失败也清理已创建的干净后台会话。保留草稿、切图历史与已有配置校验规则，不主动清除配置。

## 实现与验收

1. 在宿主操作 finally 中释放纯读取会话，并区分实际编辑占用。
2. 宿主适配器回归覆盖加载后释放、连续同名生成、活动切图与草稿保留、其他会话保护。
3. 运行 npm test、npm run build 和 diff 检查。真实 VS Code 原生对话框手动验收：连续生成同名 PSD，进入切图后保存再生成；未保存配置时应被保护。

## 验证结果

394 项共享测试通过，包含新增三组宿主回归；类型检查、生产构建和 git diff --check 通过。原生 VS Code 文件对话框与真实 Photoshop 文件往返未在本轮执行。
