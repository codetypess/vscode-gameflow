# Layer Tree Context Menu and Dragging

Status: Done
Date: 2026-11-13
Scope: 页面内部层级树的右键新增/删除，以及拖动排序和调整父容器。

## 1. Context

当前层级树只支持选择、隐藏锁定和展开折叠。用户要求在层级树直接右键添加节点、删除，并拖动调整位置。继续使用 VS Code 主题与 shadcn/ui 基础组件。

## 2. Goals

- 右键页面根、节点或树内空白显示菜单；支持容器、矩形、文字、按钮、图片新增，以及节点子树删除。
- 容器的菜单新增子节点；普通节点的菜单新增同级节点；根或空白新增根节点。新增后选中并展开对应父级。
- 拖动节点可在目标前后排序、移入容器或移回页面根，始终移动整棵子树。
- 放置更换父级时保留视觉位置；取消拖动不提交，成功放置只提交一个可撤销事务。

## 3. Non-Goals

多选、跨页面拖放、跨应用拖放、外部文件拖入、修改画布已有坐标拖动方式。不删除页面根节点。

## 4. Current Behavior

节点数组保存兄弟顺序，parentId 保存层级；画布已支持控件坐标拖动，属性中已可改父容器。右键和树内拖动尚未接入。

## 5. Proposed Behavior

菜单跟随鼠标位置并避让边缘，点击外部或 Escape 关闭，支持方向键和 Enter。右键首先选中目标，删除对准该目标而非之前选择。删除容器会删除所有后代并清理选择。锁定/继承锁定节点不能删除或拖动，锁定容器不能接收新增/拖入。

菜单内按键独立于画布快捷键；尤其 Radix 在 document capture 阶段关闭菜单后，画布的 window listener 仍须通过原事件目标的 menu 祖先忽略 Escape，保留当前选择。

拖动行的上/下边缘显示前/后插入线；容器行中部高亮表示移入。普通节点上/下半部只调整同级。拖到页面根或树内空白可移回根末尾。拖动滚动区边缘时滚动列表；成功移入后展开目标。禁止放到自身、后代、无效父级。拖动后吞掉此次 click，保持源节点选中。

## 6. Design

- 新增共享纯操作 `insertNode` / `moveNode`，处理锁定、防环、子树排序与局部坐标转换；不变更 Schema 或宿主协议。
- Tree 只保存菜单/拖动预览等视图状态，通过回调将一次变更交给现有文档会话。
- 菜单复用 shadcn Popover，提供 menu/menuitem 语义和键盘操作，不新增依赖。
- 拖动使用 pointer capture；移动中只显示目标，pointerup 才运行纯操作并提交。Escape、pointercancel 和窗口失焦清除预览。
- 兄弟顺序与现有数组绘制顺序一致，后面的控件在画布上更靠前。仅顺序变化不改变坐标。

## 8. Testing Plan

纯测试覆盖同级前后移动、跨父级视觉位置、嵌套子树整体移动、防环、锁定、无效目标、相邻无操作、插入位置与不变性。浏览器验证右键目标与菜单操作、边缘菜单、拖动反馈、保存/撤销/重做；记录 Extension Host 验证边界。

## 9. Acceptance Criteria

- [x] 右键根/空白/普通节点/容器均产生对应新增位置，删除作用于正确子树。

- [x] 树可拖动排序、移入/移出容器，防环和锁定生效。

- 浏览器未捕获运行时错误；交互验证视口为 1280×720。真实 VS Code Extension Host、窄视口边缘避让及长列表边缘滚动尚未完成人工验收；菜单碰撞处理复用 Radix，滚动逻辑随拖动指针移动生效。

## 10. Risks and Rollback

小高度行的嵌套放置易与排序混淆，使用明确的边缘插入线和中部高亮。复用既有 parentId 与数组顺序，回退交互不需要迁移文档。
