# 关联 PSD 外部保存后刷新画板

Status: Done

## 复现与根因

打开已绑定 PSD 的画板，在另一程序中修改同一路径的文件并保存。宿主只监听原型文档和引用画布，Webview 以绑定路径和文档身份缓存预览，因此磁盘内容变化无法触发重新加载。带有切图配置的文件即使重新读取，也会因配置来源指纹过期而要求再次绑定。

预制体预览缓存已导出 PNG 的读取结果，包括文件缺失。切图导出成功的回执只更新导出面板。返回原型工作台沿用之前的预制体资源模式，资源根目录和路径也相同，磁盘读取没有重新执行。

## 行为与验收

- VS Code 工作台监听当前画板绑定的 PSD。写入、替换、删除与重建触发对应画板重新读取，重新绑定和关闭工作台释放监听。
- 在后台预览中，身份相符时采用新美术稿和仍可匹配的切图配置。普通 Photoshop 稿以已绑定的配置身份和可唯一匹配的原生图层 ID 对应已有配置。保留磁盘配置和切图草稿，身份冲突或读取错误由对应画板显示。
- 回归检查覆盖同身份的不同文件、重绑、关闭、外部修改像素以及删除后恢复。普通浏览器预览继续使用用户选择的本地文件快照。
- 当 PNG 和来源清单成功写入后，通知使用该资源目录的预览重新读取磁盘。首次导出补全缺图，再次导出更新同路径的像素。失败或取消继续显示原有结果。

## 验证结果

Edge 回归从预制体缺图状态进入 PSD 切图，点击导出后直接返回，原位置随即显示新图片。同路径再次导出不同颜色的 PNG 后也验证了像素变化。Windows VS Code 宿主收到了外部 PSD 写入事件，读回了修改后的图像字节，磁盘切图配置与刷新前一致。408 项共享测试、59 项原生宿主检查和生产构建通过。
