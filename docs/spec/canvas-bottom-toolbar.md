# Canvas Bottom Toolbar

Status: Done
Date: 2026-11-12
Scope: 对话内原型的画布工具条与产品规格。

## 1. Context

用户提供浮动工具条参考，希望在画布下面集中放置工具。现有无限画布只有分散的缩放、关系开关和操作说明。

## 2. Goals

增加底部居中的紧凑浮动工具条，让选择、平移、评论、绘制和 AI 入口可发现、可切换。绘制菜单向上展开，明显显示当前工具。

## 3. Non-Goals

不接入真实 AI 生成或多人评论服务。本次仅实现文字、矩形和椭圆三种基本绘制；完整矢量编辑器、画笔和连接线创作后续扩展。

## 4. Current Behavior

选择和空白平移是隐含操作。画布底部只有关系开关、范围提示和帮助文案。

## 5. Proposed Behavior

- 工具条位于画布底部居中，随视口固定，不随内容平移缩放。
- 选择 V：总览移动页面组，页面内编辑控件。
- 平移 H：从页面上拖动也只移动视角，空格可临时平移。
- 评论 C：点击落点创建本地批注，右侧编辑内容；页面内批注跟随页面组移动。
- 绘制菜单：文字 T、矩形 R、椭圆 O。点击放置文字，拖动创建图形。
- 总览绘制产生画布标注；页面内部绘制产生当前页控件。不得误写其他页面。
- AI 菜单提供需求分析入口，并明确图像生成尚未接入。
- 创建后回到选择工具；Esc 优先关闭菜单、取消手势或返回选择，再退出页面编辑。输入文字时不触发工具快捷键。

## 6. Design

工具状态属于视图，不进入内容撤销栈。新增批注和画布形状存为带可选页面锚点的 annotations；页内矩形、椭圆和文字使用已有 nodes。一次创建为一个事务，可撤销、重做；取消未完成绘制不落盘。

浮层与画布手势隔离。菜单在工具条上方显示，窄窗口工具条换行，菜单宽度不超出画布。

## 7. Implementation Plan

1. 添加工具条、上弹菜单、作用范围提示及属性面板。
2. 连接选择/平移、评论和三种基础绘制；复用撤销、保护与状态保存。
3. 核对旧的组拖动与双击编辑，验证新工具、菜单和窄屏布局。

## 8. Testing Plan

浏览器检查工具切换、手形平移不移动页面、评论编辑与撤销、图形创建、页内作用范围、快捷键输入隔离、Esc、菜单关闭及 320 像素布局。重跑原无限画布验收脚本。

验证结果（2026-11-12）：本地 Edge + Playwright 的原无限画布检查通过；新工具条检查覆盖底部定位、向上展开、手形平移、总览绘制、本地评论、撤销/重做、页内绘制、输入时快捷键隔离、取消手势、AI 入口和 390/320 像素布局，全部通过，未报告脚本运行错误。已目视检查浅色菜单、深色工具条与窄窗口截图。实际 AI 服务和扩展安装不在本次验证范围。

## 9. Acceptance Criteria

- [x] 工具条底部居中，平移与缩放后位置不变，菜单向上展开。
- [x] 选择与平移模式行为不同且高亮准确。
- [x] 评论可创建、编辑、删除及撤销；没有发送外部消息。
- [x] 总览绘制标注，页内绘制当前页控件；创建可撤销。
- [x] 菜单和输入控件不会触发画布拖动；输入 T/R/O 等文字不切换工具。
- [x] Escape 与取消手势不留下未提交形状。
- [x] 原无限画布交互检查通过，窄窗口无非预期溢出。
- [x] 规格同步并如实标示 AI 尚未接入。

## 10. Risks and Rollback

风险集中在工具条与拖动事件穿透、世界与页面局部坐标混用，以及快捷键干扰输入。通过独立的工具判断、坐标转换和输入目标过滤控制。可恢复上一版原型源文件与本次文档差异，无外部数据写入。
