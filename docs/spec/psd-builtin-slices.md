# PSD 切图识别内置图片

Status: Done

## 行为

团队可以先用内置素材交付原型和预制体，再把同一份页面 PSD 交给美术。生成 PSD 时记录每个内置图层的素材身份、绘制尺寸和初始像素指纹。读取 PSD 时按解码后的 RGBA 像素逐层验证。移动、改名、重新压缩不改变像素身份。修改像素、裁剪区域或九宫格后使用该图层的 PSD 切图路径。没有生成记录的 PSD 延续原有切图规则。效果、蒙版等继续使用现有导出诊断。

## 实现与验收

1. 生成、重新打开 PSD，验证图层像素和尺寸。比较只针对原型实际渲染的尺寸，并校验内置资源版本。
2. 切图工作台、页面绑定、内存预览与 Prefab 导出采用相同路径。识别成功的普通内置图使用库中的原始 PNG 和九宫格，默认占位图沿用按尺寸生成的资源路径。
3. 两个窗口或多个控件使用同一内置图时复用同一文件并保留内置来源。一个窗口改图后有独立的美术切图，公共图片继续供其他窗口使用。
4. 用真实生成和改动的 PSD 检查分类，用目录导出测试检查文件、来源清单和重复导出行为。现有预制体的结构同步沿用当前规则。

## 验证记录

374 项共享测试与生产构建通过。Edge 中生成并重新打开 PSD 后，普通态单个颜色通道改变 1 进入美术路径，移动并重新压缩的选中态沿用内置按钮，90×52 占位图使用对应尺寸的内置路径。页面绑定和运行预览浏览器回归通过。该往返测试使用 ag-psd，尚未在 Photoshop 中实测另存后的元数据保留情况。
