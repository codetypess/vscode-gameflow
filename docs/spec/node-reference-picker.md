# 节点引用树形选择弹窗

Status: Done
Date: 2026-11-16
Scope: Slider/CheckBox/Radio 部件绑定与 RadioGroup 成员引用的选择交互。

## 1. Context

当前使用原生下拉框，节点名称和 ID 平铺展示，不能判断层级与同名节点的归属。用户要求参考 Laya 的引用框和选择弹窗，改为树形结构，并明确正在为哪个节点选择。引用框选中后支持 Delete 和 Backspace 清空。

## 2. Goals

- 属性中使用可聚焦的引用框与独立选择按钮，显示已绑定节点名。
- 弹窗显示绑定发起节点、属性名、页面节点树、当前绑定及待选择节点；支持搜索与折叠。
- Delete / Backspace 清空引用，RadioGroup 保留空槽；不删除被引用节点。

## 3. Non-Goals

不改变文档结构、皮肤只能引用直接子节点、Slider 皮肤无相对约束或 RadioGroup 同页且不重复的规则。不添加跨页选择、资源选择或 Prefab 导出。

## 4. Current Behavior

`ControlPartsProperties` 为皮肤与成员分别过滤候选后显示 select。画布全局 Delete / Backspace 会删除当前节点，引用输入必须拦截这两个事件。

## 5. Proposed Behavior

- 单击引用框使其聚焦并高亮；选择图标、双击或 Enter / Space 打开弹窗。选择按钮采用 Laya 风格的方框加鼠标指针图标。
- 弹窗标题与上下文指明“正在为「节点」的「属性」选择”。树保留真实层级与兄弟顺序，显示名称、Laya 类型；当前绑定、正在设置的节点有独立标记，类型排在标记右侧并靠右对齐。待选项高亮，并在底部显示完整路径与 ID 区分同名节点。
- 单击候选只更新待选状态；确认提交一次，取消、关闭或 Escape 不修改。提供“不绑定”。无效节点保留上下文但不可选，展示原因。
- 搜索名称、变量、类型、ID，保留匹配祖先路径；搜索与普通折叠状态独立。打开时定位当前绑定。树支持方向键、Home / End、Enter 选择与确认。
- 引用框 Delete / Backspace 直接清空且可撤销；RadioGroup 清空保留空槽。弹窗搜索内删除键只删字，弹窗与引用框事件不触发底层节点删除、移动或画布快捷键。
- 弹窗限制在视口内，树独立滚动，焦点限制在弹窗内，关闭回到触发按钮。锁定和不合法关系不可提交。

## 6. Design

共享 UI 引用组件负责引用框与原生 dialog（Portal 至 body），复用现有按钮和节点图标。纯函数负责候选约束、路径和可见树行，测试覆盖规则与层级搜索。继续通过现有 onNode / setRadioOptions 提交，无新持久化字段。

## 7. Implementation Plan

1. 添加引用候选/树辅助函数与共用选择组件。
2. 替换皮肤、单选组成员下拉，接入清空快捷键，补充样式。
3. 测试候选约束、同名节点路径与搜索；浏览器验证选择、取消、清空、撤销及键盘隔离。
4. 更新布局基线与验收记录。

## 8. Testing Plan

纯函数测试直接子节点、Slider 约束、Radio 类型/跨组占用、当前绑定、搜索祖先和折叠；构建及类型检查。浏览器验收当前/待选标记，确认/取消，Delete / Backspace，搜索删字不删除节点，RadioGroup 空槽及撤销，窄视口与焦点。

## 9. Acceptance Criteria

三类节点皮肤与 RadioGroup 成员共用树形弹窗；上下文及当前绑定明确；无效节点不可提交；取消不产生编辑；清空引用不删除节点且可撤销；既有数据/状态规则不变；检查通过。

## 10. Risks and Rollback

弹窗键盘事件不能冒泡为编辑器快捷键。搜索不得破坏原树层级。多处同名节点通过路径和 ID 区分。需要回退时可恢复下拉框，持久化格式无需迁移。

## 11. Verification Record

- 新增 6 项纯函数测试，覆盖候选规则与共享引用校验一致、成员占用/锁定、空槽保留、交错数组层级、搜索祖先与同名路径。146 项共享测试通过。
- 浏览器验证：取消不写入；确认清空与重新绑定正常；Delete / Backspace 只清空引用且撤销恢复；搜索 Backspace 正常删字；树内 Delete 不删除画布节点；搜索、折叠和双击选取正常。RadioGroup 清空保留空槽，其他选项占用节点不可选择。
