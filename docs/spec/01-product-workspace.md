# Product Workspace Baseline

Date: 2026-11-14
Status: Confirmed product direction; runnable extension scaffold

## Purpose

GameFlow 是面向游戏策划的 VS Code 扩展方向。Agent 从策划需求生成结构化 UI 原型，策划能继续手动调整，之后再进入美术资源与开发交付流程。

## Workspace Model

1. 一份策划文档所需的全部界面共享一张无限画布，页面与弹窗均为可独立摆放的页面组。
2. 总览模式选择和拖动整页；拖动整页不改变内部控件的相对位置。
   新增界面不自动适应全部页面或跳到新页面；总览保持当前平移/缩放。页内新增返回总览并选中新页面，通过补偿当前页面的总览位置保持原页面屏幕位置与缩放。新页面可在视野外，用户可手动平移或点击“适应画布”；内容撤销/重做不改变相机。详见 [新增页面视角](page-insert-camera.md)。
3. 双击进入页面内部编辑范围，编辑控件与层级；退出后回到原总览视角。页内单击只选择当前编辑层的直属子节点（命中后代时选其直属祖先），双击容器进入子层，单击空白取消选择，双击空白退一级并选中刚退出的容器；页根空白双击不退出页面。左上导航显示当前容器路径并可返回祖先，树选择直接跳到节点所在层。容器层用 40% 黑色遮罩压暗背景和其他分支，当前容器子树保持明亮；页根不遮罩。层级导航不改变相机、文档或撤销历史。
   底部工具条最左端提供默认关闭的“直选模式”，位于虚线框之前。开启后页内点击直接选择实际命中的可见子节点，可跨容器分支；导航/树/属性同步到目标，整页保持正常绘制顺序和明暗。关闭后恢复逐层选择及当前层遮罩。开关仅影响会话，切页/工作模式切换保留，刷新关闭，不修改文档、选择、相机或历史。详见 [画布直选模式](canvas-direct-selection.md)。
   原型节点支持 Ctrl/Cmd 点击增减选择、Shift 点击连续选择，Ctrl/Cmd+Shift 追加区间。树中范围按当前展开/搜索可见行顺序，画布按当前层子节点顺序。多选共享最近公共父容器作为编辑层，树/画布同步显示全部选择，属性面板显示数量和名称。方向键、拖动、删除和复制按整组操作，父子同时选中只处理最上层选择；内容变更可一次撤销。鼠标树选中直接接管键盘操作，不显示名称按钮额外焦点框，Tab 仍保留按钮焦点提示。
4. 页面组在画布上的位置、控件父子关系、页面间业务跳转分别建模。
5. 相机平移与缩放改变观看方式；总览画布支持鼠标定点滚轮缩放和空白区域抓手平移。原型的缩小、比例、放大及适应画布控件固定在画布左上，页内层级导航位于其右侧、同一行；两者外框均高 34px，上下边缘对齐。窄窗口保持单行，导航在剩余宽度内横向滚动。原型和 PSD 切图的背景点阵跟随相机，以每倍增/减半缩放循环密度，屏幕间距保持 24px 至不足 48px，点大小固定、交点对齐世界原点。页面拖动与控件编辑改变文档内容，背景网格不影响吸附或持久化。
6. 页面总览、控件树、内部编辑与 Agent 使用同一份结构化数据；修改需保留稳定标识和需求来源。
7. 画布底部提供集中工具条，工具作用范围遵循总览或当前页面；添加菜单向上展开，页面根/控件分组使用紧凑单列，正常宽 225px，窄窗口按可用宽度收缩，空间不足时允许内部滚动。原型的撤销、重做、保存按此顺序集中在顶栏左侧，位于工作台名称后、总览导航前，保留图标提示与快捷键；底部不重复放置。同步中或文档未就绪时禁用。顶栏不常驻显示保存/备份状态，VS Code 原生标签未保存标记承担关闭保护；真实错误保留。工具与相机状态不混入文档内容撤销事务。
8. 页面在总览范围创建，根类可选堆叠界面 (UIStack)、顶层界面 (UITop)、场景界面 (UIScene)。自由容器 (UIBox) 在总览创建独立组件画板，可用于 ItemRender 设计；进入页面后创建子容器。文字、按钮、图片和面板等控件在当前编辑层创建，坐标持久化为父容器局部坐标；页面层使用页面局部坐标。添加菜单标注 LayaUI 类名，省略右侧快捷键提示；UIView 不作为可选根类型。“矩形”不再作为新增/转换选项，保留旧节点读取与渲染，使用面板容器创建对应控件。
9. 页面内部的控件树右键菜单提供复制、粘贴、重命名、生成副本、删除，以及添加/转换节点类型的二级菜单。容器中创建或粘贴子节点，普通控件旁创建或粘贴同级节点，根/空白创建或粘贴根节点；删除容器时删除整棵子树。复制使用编辑会话内的子树快照，粘贴生成新 ID、改写内部父引用；重命名支持行内 Enter/失焦提交、Escape 取消。转换保留身份与内容，禁止带子节点转为叶子类型及改动锁定节点。单个未锁定的自由容器 UIBox 可通过“存到画布”提取为组件，原位置保留关联引用；其他普通节点类型不支持直接保存。引用实例可展开编辑内部节点，修改存为本实例覆盖；可通过“编辑源组件”进入定义。树中拖动按兄弟顺序排序或调整父容器，更换父级保持视觉位置，禁止循环层级和修改锁定节点。
10. 画布、页面和控件默认显示普通箭头，放置控件时也不显示十字准星。实际拖动显示抓取指针；抓手快捷键和尺寸手柄保留对应的操作指针。底部选择/抓手按钮由默认关闭的“虚线框”开关替代，开启时显示可见容器组件的虚线辅助边界；仅影响当前会话视图，不改变文档或选择，V/H/空格仍可切换选择与平移。
11. 新建画布、添加与复制的页面/控件由 Nano ID `customAlphabet` 生成 8 位小写字母/数字 ID（`[a-z0-9]{8}`，首位可为数字），分配时检查文档及会话占用。同一文档全部页面与控件共享唯一 ID 空间；v1/v2 的读取、保存及编辑消息均拒绝重号，报告 ID 和两个冲突位置，不自动修复歧义。未带 `elementIdScheme: "nanoid-8"` 的旧原型首次进入编辑会话时，一次性重分配全部页面/控件 ID，同步改写 parentId 和页面跳转引用，并记录该标记；迁移是宿主可撤销事务，保存后重开不重复。普通解析/序列化不改写身份；迁移后的改名、移动、换父级、保存加载保持 ID，撤销能恢复旧文档且同会话不会强制重迁移。复制整页/子树生成新 ID 并改写内部引用，会话内撤销/删除不释放已分配 ID。跨文档关联以 documentId 加元素 ID 识别，pageId 可用于定位页面。
12. 原型的图层树/属性面板自动贴近当前页面左/右边缘，通常间隔 16px、顶部对齐，跟随缩放和平移而保持控件尺寸。正常宽度均为 280px，窄窗口等比例缩窄；面板限位在屏幕内且互不重叠，过高内部滚动，顶部避开左上缩放条和页内层级导航，底部避开底部工具条。跟随页面顶部时动态缩短可用高度，降至 400px 就停止向下跟随；窗口不足 400px 时以实际空间为限。总览只让属性面板跟随选中页面。自动定位取代属性面板手动偏移，不随控件选择或面板内容高度改变锚点。原型属性面板与图层树共用覆盖式滚动条，不挤占内容宽度；空闲隐藏，滚动时显示，停止约 800ms 后淡出，操作滑块期间保持显示。有无滚动/折叠切换时字段宽度保持一致。
13. 图层标题下方提供当前页面搜索，可按名称、变量名、ID、中文组件类型、内部类型或 Laya 类名进行不区分大小写的子串筛选。仅显示匹配节点及其祖先路径，自动展开匹配路径并显示匹配/总数；无结果显示空态。清除按钮或 Escape 恢复完整树及原折叠状态，搜索本身不改选择、画布和文档。筛选时保留节点选择及右键编辑，停用拖动排序并显示原因；搜索框固定在滚动树上方。
14. 控件属性以“名称”编辑显示名，其下“变量”可设置程序变量名。变量与显示名/稳定 ID 独立，允许留空，须满足 ASCII JS/TS 标识符和严格模式保留字规则，且同页不可重名；错误输入显示提示并阻止提交。复制/粘贴自动为冲突变量追加数字，整页副本保留自身变量作用域。变量随 v2 文档保存并支持撤销重做，尚未连接运行时绑定或代码生成。

## Human and Agent Collaboration

容器控件允许独立子节点：UIButton 默认无需文案，UILabel 按需添加；Slider、CheckBox、Radio 使用可编辑图片部件及显式皮肤引用。RadioGroup 的成员关系独立于显示树。属性面板编辑设计状态与绑定，图片部件可绑定工具生成的 PSD 切图；游戏业务由目标项目处理；顶栏已支持原型 PSD 与当前页面 Prefab 导出；见 [原型复合控件](prototype-control-parts.md)。

Agent 输出区分明确需求、推断和待确认项。策划可编辑生成结果；后续 Agent 局部建议需尊重受保护的手动修改。素材生成是后续环节。

## Runtime Slice Preview

顶栏纯 Play 图标“运行预览”在当前工作台打开弹窗。先在 PSD 标记切图，再在原型图片属性中选择资源；也可填写已导出的根目录相对 PNG 路径。绑定随原型保存、撤销及实例覆盖，不按同名猜测。预览直接消费裁切后的内存 Canvas，无需落盘或 PNG 编码；正式导出编码相同产物。已导出资源由 PNG 和同目录来源清单共同验证装载，缺失/损坏/已知来源改名或删除显示控件诊断，不用旧图掩盖错误。

编辑与预览共用布局和控件绘制，资源自然尺寸支持内容布局。选控件可看实际纹理、来源、九宫格及设计/加宽/加高/双轴/小尺寸；临时 CheckBox/Radio/Slider 状态可重置，尺寸和状态不进入设计历史。PSD 原图提供独立对照。预览支持现有独立像素层和区域，正常混合的简单图片分组可合成切图；效果、蒙版与特殊混合仍不支持。完整游戏业务运行时不在预览范围。详见 [切图装载运行预览](runtime-slice-preview.md)。

## PSD Workspaces

- 工作台设置中的路径为“资源导出根目录”和“预制体导出根目录”，各成员保存在本机 workspaceState。每份 `.gameflow.json` 在“当前文件”区编辑可选 `exportDirectory`，用于当前页面预制体导出；随文件、历史及恢复保留，留空不补值，相对路径禁止绝对路径和 `..`。PSD 图片统一遵循资源根目录下的分类/独立图集规则，不叠加此字段；设置面板说明两者用途。详见 [文件导出目录](file-export-directory.md) 与 [PSD 独立目录](psd-independent-directory.md)。

- [星海远征竖版样例](../../examples/star-sea-login/README.md) 提供 750×1334 UIStack 原型与分层 PSD：UIButton 自身持有 normalSkin，PSD 中使用 @normal，文案为独立 UILabel，UIImage 对应 PSD 图片导出组，UILabel 为独立文字层。配套图片、九宫格、显式原型/PSD 映射及重建脚本随样例交付；浏览器 `?sample=star-sea-login` 使用独立存储查看，原型文件可由现有自定义编辑器打开。样例与通用原型 PSD / Prefab 导出及图片槽位规则保持一致。

- 顶栏中央通过紧凑纯图标切换原型、PSD 合并和 PSD 切图，使用原有 `LayoutPanelTop`、`GitMerge`、`Scissors`，图标 16px；悬停提示及无障碍名称保留中文。按钮为 30×22px、间距 2px，整组无外层边框、背景或内边距，仅当前按钮高亮。切换保留当前会话，原型快捷键仅在原型模式生效。详见 [模式切换图标](workspace-mode-icons.md)。
- PSD 切图通过显式选文件读取真实图层树、保存的合成图及基础单层图。勾选图层、设置导出名，使用数字或拖动四条虚线编辑上/右/下/左九宫格，至少保留 1 像素中心；提供重复填充、拉伸预览、缩放平移及确认/取消。
- 区域编辑的拖动边界复用九宫格的贯穿虚线，隐藏左/右/上/下文字并保留无障碍名称，整条虚线均可调整导出范围，不叠加蓝色实线框；图片居中和恢复原始区域采用预览右下角工具栏图标。
- 九宫格下方“编辑区域”可独立设置 PNG 导出宽高，在固定区域内拖动图片，方向键微调 1 像素、Shift+方向键移动 10 像素；提供位置输入、居中、恢复原始和确认/取消。四边线可拖动调整范围，图片和对边保持原位；滚轮围绕鼠标缩放预览，右键平移，并提供缩放/适应窗口按钮，这些视图操作不改变导出参数。两行输入框对齐，预览区不显示外侧聚焦框。弹窗支持拖动标题栏移动（普通箭头指针）及拖动右下角缩放，预览随窗口伸缩，窗口位置/尺寸受视口约束且不进入切图配置或历史。图层保持原像素大小，区域外内容裁剪，留白透明；九宫格及预览使用导出区域尺寸。配置确认进入一次历史并随保存/恢复保留，画布用独立虚线标出自定义导出范围。详见 [切图导出区域](psd-slice-region.md)。
- 浏览器切图及合并来源 A/B 支持从文件管理器拖入单个 .psd，合并须拖到对应来源区域。多文件/非 PSD 拒绝且保留原会话，忙碌或弹窗期间不接收新拖入。VS Code 切图通过原生选择器定位源文件，在当前工作台内打开，标签数不增加；Webview 拖入的 File 不提供可信绝对路径，因此拖入后需在选择器中定位一次。Explorer 显式“打开方式”仍提供独立 PSD 编辑器。详见 [工作台内 PSD](psd-in-workbench.md)。
- 切图画布滚轮围绕鼠标缩放，拖动 PSD 或空白平移；图层树与属性面板贴着 PSD 左右侧跟随、顶部对齐，控件不随画布缩放。两面板沿用原型的 400px 最小可用高度跟随规则，内容增减不改变顶边锚点，空间不足时两侧一起停靠并在内部滚动。两面板通常同为 278px 宽；碰到视口边界时停在屏幕内，互不重叠，窄窗口同宽缩窄、矮窗口内部滚动。缩放条固定在画布左上角，复用原型工作台的 34px 外框、25×26px 图标按钮和响应式边距；保留点击比例恢复实际大小及适应窗口。PSD 属性与图层树也复用原型属性面板的覆盖式滚动条，不占内容宽度，滚动时显示，停止约 800ms 后隐藏；标题栏留在滚动区域外。画布外层仅裁切、不作为浏览器原生滚动容器，确保键盘及焦点滚动不偏移画布。两侧面板预留 48px 顶部空间；面板内部操作不驱动画布，模式切换保留视角。详见 [PSD 缩放条左上布局](psd-zoom-top-left.md)。
- 左键轻点 PSD 元素选中最上方可见内容层，文字按区域、图片按非透明像素命中；隐藏层和分组不拦截。树自动展开祖先并滚动定位，选框及属性同步。空白点击清除选择，移动超过 4 屏幕像素则平移并保持原选层，中/右键仅平移。选中与导出勾选互相独立。
- “标记为切图”决定 PNG 输出，仅导出勾选图层。用户选定的资源根目录包含 `builtin/`（内置资源预留）、`shared/`（共享图片）、`unclassified/`（普通图片）；根目录的 `image-files.meta.json` 按完整相对路径登记生成 PSD、图层身份、尺寸、九宫格与内容摘要。不同目录可保留同名图片。VS Code 记住工作区根目录，浏览器在支持目录选择能力时保留当前会话句柄。
- 中文图层名保留，默认导出名仅显示在 placeholder：图层名包含“按钮”使用 `btn_`，其他使用 `img_`；非共享资源使用 `{btn或img}_{图集名}_{图层名}`，共享资源使用 `{btn或img}_{图层名}`，省略图集名；名称转拼音首字母并保留 ASCII 英文数字。切图属性顶部“文档配置”提供文件级“图集名”，默认输入值为空，仅 placeholder 显示去掉 `.psd` 后规范化的文件名；图集名统一为小写英文字母、数字和下划线，中文转拼音首字母，分隔符合并为下划线并去除首尾下划线。输入完成（失焦或回车）后显示规范名，中文输入法组合期间保留原文，自定义输入覆盖当前 PSD 非共享图层默认名中的图集段，清空恢复默认。切换共享即时更新默认名和预览路径，取消共享恢复当前图集名，文件级图集设置保留；手填导出名称优先，输出名限英文数字下划线并转小写。图集名、自定义导出名和共享标记随配置保存、草稿恢复及撤销/重做，运行预览路径同步更新。详见 [PSD 图集名](psd-atlas-name.md)。
- 切图属性最顶部为始终可编辑的“文档配置”，包含文件级图集名和“使用独立目录”（默认关闭）；下方为所选图层信息/预览、导出设置（导出名称/切图开关/共享）、九宫格及导出区域。各区使用与控件属性相同的横线、标题和组内间距。勾选后非共享图层进入资源根目录下的图集名目录（缺省按规范化文件名推导），共享图层始终进入 `shared/`；关闭后普通图层进入 `unclassified/`。图集名禁止使用 `builtin`、`shared`、`unclassified`，规范化后同名也禁止。选项随配置、PSD 副本、草稿及历史保存，宿主与浏览器导出、资源选择及预览共用路径规则；改名或切换不迁移旧文件和绑定。详见 [PSD 独立目录](psd-independent-directory.md)。
- 每个最终导出目录内同名表示同一资源。同 PSD 同名图层同时导出或最终导出名碰撞均冲突；同源可更新，异源或无来源记录的同名资源须标记共享才可覆盖。共享且勾选导出时覆盖图片并更新生成来源。PSD 图层树每层缩进 10px；共享且勾选导出的非分组图层在名称右侧显示分享图标，悬停提示“共享导出”，取消共享或导出后即时移除，图标与九宫格/冲突提示并列。冲突直接标记在图层树及祖先分组，折叠后仍可见；悬停与属性区显示原因，整批检查通过后才写入。详见 [PSD 导出命名](psd-export-names.md)。
- 原型与关联 PSD 会话由同一原生工作台文档管理；任一修改触发该标签未保存标记及关闭确认。`Ctrl+S`/保存全部/自动保存聚合保存原型和 PSD 配置，PSD 写同目录 `登录.meta.json`，源 `登录.psd` 不改写。没有配置时新建配置处于未保存状态。重开自动读取同名配置，源变化按身份校验并确认；配置不匹配时仍可打开 PSD 修复，保留原配置并在替换保存前确认。更换 PSD 先处理未保存配置；历史关联会话保留到工作台关闭，备份和保存覆盖其未保存修改。
- 宿主自动备份尚未正式保存的元数据及恢复所需 PSD 快照，区分“草稿已备份”与“配置已保存”；重复 ID 未修完也可恢复。保存失败或外部文件变化保持 dirty，保存/明确放弃后清理恢复草稿。浏览器按文件名和源指纹备份配置，重新选择同一 PSD 可恢复，正式配置仍通过下载保存。
- PNG 导出和更多菜单“导出带配置的 PSD…”不清除配置未保存状态；独立 PSD 编辑器的原生另存为输出带元数据的 PSD 及相配套 sidecar。保存过程中出现的新修改保持未保存，不被旧保存结果清除。
- 切图操作集中在工作台顶栏：打开 PSD、撤销/重做、保存、更多使用图标；“导出”是独立文字按钮。移除切图内额外操作条、手动读取配置入口、完整配置路径行和导出目录行，保存图标悬停显示配置路径，打开时只自动读取相邻同名配置。齿轮打开“工作台设置”，分别选择资源、预制体导出目录；目录存入本机 VS Code 当前工作区 workspaceState，不进入项目/SVN。旧资源目录自动沿用，跨工作台更新，下一次导出使用最新目录。缺资源目录时导出打开设置面板。预制体目录用于当前页面 `.lh` 输出，包含内置或已绑定美术图片。详见 [顶部操作与设置](workbench-toolbar-settings.md)。
- 身份依据元数据，缺失分配新 ID，重复要求明确指定新节点。源文件指纹完全一致时，配置可恢复已分配及修正的身份；不同源只按有效身份匹配并要求确认。不会按图像内容推断身份或合并来源。
- PSD 合并当前提供 A/B 真实图层树、checkbox 选层和带祖先层级的结果预览。同一身份互斥选择来源；父分组隐藏状态被继承。完整三方自动比较与 PSD 合并写出尚未接入。
- 首版限制为标准 8 位 RGB PSD、32 MB、边长 4096、800 万画布像素、128 个图层/分组及 2400 万累计解码像素。依赖蒙版、剪贴、效果及特殊混合的单层不参与选层输出；整图可参考已保存的合成预览。当前 PNG 导出及装载预览沿用独立像素层；九宫格按像素无损缩减中段，导出参数以实际纹理为准，保留原布局尺寸。组重建及 Laya 配套导入仍待接入。见[九宫格切图产物与导出参数](nine-grid-export-product.md)。

## Canvas Component References

画布支持同文件及跨模块 `.gameflow.json` 引用：进入目标页面后通过添加菜单的“引用画布组件…”选择本文件画布，或通过“引用其他画布…”选择源文件及其中的画布。UIStack、UITop、UIScene、UIBox 均可引用。实例位置、尺寸、变换、名称及显隐独立；内容与外观跟随源。实例可展开并逐层/直选选择内部节点，局部属性覆盖和附加节点保存在实例中；继承结构禁止删除、剪切、换父、排序和改类型，整个本层实例仍可删除。源文件丢失、身份变化、根节点删除及循环引用显示明确诊断，保留实例数据。浏览器预览使用导入快照，需重新导入更新；VS Code 跟随源文档未保存修改与磁盘变更。详见 [画布组件引用](canvas-component-references.md) 和 [实例编辑](canvas-instance-editing.md)。

## Current Delivery Boundary

原型现已提供 15 种可创建的基础 UI 节点（另兼容旧矩形节点），以及与项目 LayaUI 对齐的无缩放布局子集：六项像素/百分比约束、固定/内容/拉伸尺寸、横排/竖排/网格、内边距/间距/对齐、裁剪和静态滚动。组件、层级、属性、选择及拖动遵循统一解算结果，详见 [11-prototype-ui-layout.md](11-prototype-ui-layout.md)。游戏运行时业务绑定、虚拟列表及完整目标编辑器联调仍由后续交付验收覆盖。

当前仓库已经具备可由 VS Code Extension Host 运行的扩展脚手架、`*.gameflow.json` 自定义编辑器、基础保存链路，以及可手动编辑的简化页面原型编辑器：总览画布、双击进入页面、页面内层级树、浮动属性面板、控件拖动/缩放、文字样式、图片导入、复制删除与撤销重做均已接入。编辑器外壳跟随 VS Code 主题变量和紧凑布局。真实 Agent 接入、策划文档自动分析、美术素材生成、LayaAir 导出和 Marketplace 发布仍未实现，不把浏览器预览视为真实 Extension Host 的完整交互证据。

PSD 切图配置、九宫格、同名配置及 PSD 元数据副本输出、资源分类目录 PNG 和根级来源清单已接入；受限手动合并预览不等于完整 PSD 三方合并。浏览器交互与独立 PSD 解析验证不替代 Photoshop 往返及真实 Extension Host 验证。

引用图层使用专色和引用图标，局部覆盖另加圆点；本地附加节点在类型图标右下角叠加“+”，普通附加节点保留普通颜色。属性面板标出实际覆盖字段，右键/Shift+F10 可还原或应用到明确源定义；图层与属性面板的无操作区域屏蔽浏览器默认菜单。跨文件应用采用一笔关联编辑，保留源未保存修改，源文件正常进入待保存状态；一次撤销/重做同时恢复两个文件。浏览器仅支持同文件应用，外部快照需在 VS Code 操作。

## 原型、美术与预制体资源

原型和运行预览使用同一控件树，通过原型 / 美术 PSD / 预制体三个按钮切换图片来源。UIBox 外观由普通 UIImage 提供，UIButton 提供三态图片，ProgressBar 支持横向与圆形，Radio/Checkbox 使用底框与标记图片。内置资源可直接生成原型 PSD 并导出 Prefab；坏掉的美术引用在导出前列明，由用户选择取消或保留坏引用继续。规则见 [图片资源模式](prototype-art-prefab-resource-modes.md) 与 [UI 布局基线](11-prototype-ui-layout.md)。
