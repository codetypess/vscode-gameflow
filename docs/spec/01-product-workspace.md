# Product Workspace Baseline

Date: 2026-11-13
Status: Confirmed product direction; runnable extension scaffold

## Purpose

GameFlow 是面向游戏策划的 VS Code 扩展方向。Agent 从策划需求生成结构化 UI 原型，策划能继续手动调整，之后再进入美术资源与开发交付流程。

## Workspace Model

1. 一份策划文档所需的全部界面共享一张无限画布，页面与弹窗均为可独立摆放的页面组。
2. 总览模式选择和拖动整页；拖动整页不改变内部控件的相对位置。
3. 双击进入页面内部编辑范围，编辑控件与层级；退出后回到原总览视角。
4. 页面组在画布上的位置、控件父子关系、页面间业务跳转分别建模。
5. 相机平移与缩放改变观看方式；总览画布支持鼠标定点滚轮缩放和空白区域抓手平移。原型和 PSD 切图的背景点阵跟随相机，以每倍增/减半缩放循环密度，屏幕间距保持 24px 至不足 48px，点大小固定、交点对齐世界原点。页面拖动与控件编辑改变文档内容，背景网格不影响吸附或持久化。
6. 页面总览、控件树、内部编辑与 Agent 使用同一份结构化数据；修改需保留稳定标识和需求来源。
7. 画布底部提供集中工具条，工具作用范围遵循总览或当前页面；添加菜单向上展开，页面根/控件分组使用紧凑双列，正常宽 440px，常用窗口完整展示全部选项。窄窗口回退单列，空间不足时允许内部滚动。工具与相机状态不混入文档内容撤销事务。
8. 页面在总览范围创建，根类可选堆叠界面 (UIStack)、顶层界面 (UITop)、场景界面 (UIScene)。自由容器 (UIBox) 在总览创建独立组件画板，可用于 ItemRender 设计；进入页面后创建子容器。矩形、文字、按钮和图片等控件在当前页面范围创建，其坐标持久化为页面局部坐标。添加菜单标注 LayaUI 类名，省略右侧快捷键提示；UIView 不作为可选根类型。
9. 页面内部的控件树支持右键创建/删除节点。容器中创建子节点，普通控件旁创建同级节点，根/空白创建根节点；删除容器时删除整棵子树。树中拖动按兄弟顺序排序或调整父容器，更换父级保持视觉位置，禁止循环层级和修改锁定节点。
10. 画布、页面和控件默认显示普通箭头，放置控件时也不显示十字准星。实际拖动显示抓取指针；显式抓手和尺寸手柄保留对应的操作指针。
11. 新建画布、添加与复制的页面/控件使用 8 位 Laya 风格 ID（小写字母及数字，首位字母），分配时检查文档及会话占用。同一文档全部页面与控件共享唯一 ID 空间；v1/v2 的读取、保存及编辑消息均拒绝重号，报告 ID 和两个冲突位置，不自动改号。改名、移动、换父级、保存加载保持 ID；复制整页/子树生成新 ID 并改写内部引用，会话内撤销/删除不释放已分配 ID。已有文档唯一的长 ID 和可读 ID 原样保留，跨文档关联以 documentId 加元素 ID 识别，pageId 可用于定位页面。
12. 原型的图层树/属性面板自动贴近当前页面左/右边缘，通常间隔 16px、顶部对齐，跟随缩放和平移而保持控件尺寸。正常宽度均为 280px，窄窗口等比例缩窄；面板限位在屏幕内且互不重叠，过高内部滚动，避开底部工具条及上移后的缩放条。跟随页面顶部时动态缩短可用高度，降至 400px 就停止向下跟随；窗口不足 400px 时以实际空间为限。总览只让属性面板跟随选中页面。自动定位取代属性面板手动偏移，不随控件选择或面板内容高度改变锚点。

## Human and Agent Collaboration

Agent 输出区分明确需求、推断和待确认项。策划可编辑生成结果；后续 Agent 局部建议需尊重受保护的手动修改。素材生成是后续环节。

## PSD Workspaces

- 顶栏中央通过紧凑纯图标切换原型、PSD 合并和 PSD 切图；悬停提示及无障碍名称保留中文。按钮为 30×22px。切换保留当前会话，原型快捷键仅在原型模式生效。
- PSD 切图通过显式选文件读取真实图层树、保存的合成图及基础单层图。勾选图层、修改切图名，使用数字或拖动四条虚线编辑上/右/下/左九宫格，至少保留 1 像素中心；提供重复填充、拉伸预览、缩放平移及确认/取消。
- 切图画布滚轮围绕鼠标缩放，拖动 PSD 或空白平移；图层树与属性面板贴着 PSD 左右侧跟随、顶部对齐，控件不随画布缩放。两面板通常同为 278px 宽；碰到视口边界时停在屏幕内，互不重叠，窄窗口同宽缩窄、矮窗口内部滚动。提供实际大小和适应窗口；面板内部操作不驱动画布，模式切换保留视角。
- 左键轻点 PSD 元素选中最上方可见内容层，文字按区域、图片按非透明像素命中；隐藏层和分组不拦截。树自动展开祖先并滚动定位，选框及属性同步。空白点击清除选择，移动超过 4 屏幕像素则平移并保持原选层，中/右键仅平移。选中与导出勾选互相独立。
- “标记为切图”是后续独立图片导出的选择开关：仅导出勾选图层，未勾选图层仍留在源 PSD。当前仅保存选择及九宫格配置，图片输出待与 Laya 对齐。
- 配置命名为 `登录.psd → 登录.meta.json`；也可写入 PSD 副本。PSD 与原型独立保存。界面提示未保存配置，替换当前 PSD 前确认；会话内支持撤销/重做。关闭或重载 Webview 后需重新打开 PSD 及配置文件，不承诺跨会话自动恢复。
- 身份依据元数据，缺失分配新 ID，重复要求明确指定新节点。源文件指纹完全一致时，配置可恢复已分配及修正的身份；不同源只按有效身份匹配并要求确认。不会按图像内容推断身份或合并来源。
- PSD 合并当前提供 A/B 真实图层树、checkbox 选层和带祖先层级的结果预览。同一身份互斥选择来源；父分组隐藏状态被继承。完整三方自动比较与 PSD 合并写出尚未接入。
- 首版限制为标准 8 位 RGB PSD、32 MB、边长 4096、800 万画布像素、128 个图层/分组及 2400 万累计解码像素。依赖蒙版、剪贴、效果及特殊混合的单层不参与选层输出；整图可参考已保存的合成预览。图片导出与 Laya 配套格式待定。

## Current Delivery Boundary

原型现已提供 16 种基础 UI 节点，以及与项目 LayaUI 对齐的无缩放布局子集：六项像素/百分比约束、固定/内容/拉伸尺寸、横排/竖排/网格、内边距/间距/对齐、裁剪和静态滚动。组件、层级、属性、选择及拖动遵循统一解算结果，详见 [11-prototype-ui-layout.md](11-prototype-ui-layout.md)。游戏运行时绑定、虚拟列表、精确字体/变换和 Prefab 输出仍未接入。

当前仓库已经具备可由 VS Code Extension Host 运行的扩展脚手架、`*.gameflow.json` 自定义编辑器、基础保存链路，以及可手动编辑的简化页面原型编辑器：总览画布、双击进入页面、页面内层级树、浮动属性面板、控件拖动/缩放、文字样式、图片导入、复制删除与撤销重做均已接入。编辑器外壳跟随 VS Code 主题变量和紧凑布局。真实 Agent 接入、策划文档自动分析、美术素材生成、LayaAir 导出和 Marketplace 发布仍未实现，不把浏览器预览视为真实 Extension Host 的完整交互证据。

PSD 切图配置、九宫格、同名配置及 PSD 元数据副本输出已接入；受限手动合并预览不等于完整 PSD 三方合并。浏览器交互与独立 PSD 解析验证不替代 Photoshop 往返及真实 Extension Host 验证。
