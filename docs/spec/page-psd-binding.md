# 页面级 PSD 绑定

状态：Done（2026-11-19）

## 目标与根因

一个 GameFlow 文件可以有多个布局。美术预览必须以页面明确绑定的 PSD 为来源。现有页面只记录节点切图引用，没有 PSD 文件关联；资源池汇总所有观察到的 PSD，所以打开某份 PSD 被误当作关联，保存重开无法自动定位来源，同名路径也可能跨页冲突。

## 数据与责任

- v5 页面新增可选 artPsd: { source, documentId }。source 是相对 GameFlow 所在目录的 .psd 路径（允许 ..，统一 /）；documentId 为 PSD 稳定身份。无需升级版本；无绑定的旧页面保持原样，不推断关联。
- 扩展宿主负责文件选择、读取和生成保存，复用工作台已有 PSD 文档模型与草稿，不切换当前 PSD 工作区。不以当前打开 PSD 或文件名猜测页面关联。打开、恢复或查看切图均不创建绑定、不修改 GameFlow 内容、不保存 GameFlow 文件；仅显式绑定/生成动作提交可撤销页面编辑，随后沿用正常保存流程。
- 绑定与稳定身份槽位关联在同一次页面编辑中持久化，可撤销。普通 PSD 通过公开控件组名和直接子层标记匹配，旧文件兼容稳定身份。具体规则见[页面 PSD 图层约定](page-psd-layer-conventions.md)。
- 加载校验持久身份；文件不存在、读取失败或身份变化显示页面级错误与重新绑定/重试。异步结果按目标页面与原绑定校验，取消不改变文档，过时结果不覆盖新绑定。
- 原生保存重开按绑定自动载入；另存为时重算相对 PSD 路径。本地 Windows 盘符路径按 Windows 语义计算，盘符/共同目录大小写差异不视为跨盘，保存 / 分隔及目标名称；POSIX/远程路径保持大小写敏感，真正跨盘仍拒绝。浏览器预览使用会话内文件缓存，刷新需重新选择本地文件，界面说明这一限制。

## 交互

- 美术 PSD 和预制体模式下，未绑定页面在画板内显示“尚未绑定美术 PSD”，提供“生成 PSD”“绑定 PSD”。不渲染该页节点的缺图占位。
- 生成 PSD 基于该页原型内置资源，保存成功后直接绑定生成结果；取消不修改绑定。绑定 PSD 打开文件选择器。画布底部工具栏最右侧提供“更多”图标按钮，向上展开“生成 PSD”“绑定 PSD”（已有绑定时为“重新绑定 PSD”）菜单。只有当前正在编辑页面或总览中明确选中页面时才可执行；未选择页面时两项置灰，不默认使用首个页面。页面操作处理中同样禁用；关闭菜单保留原选择。右上角移除这两个入口，保留 Prefab 导出。
- 已绑定页面装载中显示加载状态；加载失败显示原因、重试与重新绑定。进入原型模式继续显示内置图片。
- 多页总览、单页编辑和运行预览使用相同页面级状态。每页资源池只含该页 PSD，两个 PSD 具有相同切图路径也能分别预览；Prefab 导出使用目标页资源。
- 示例文件和生成脚本默认保持页面未绑定，由用户在页面明确生成或绑定；不按打开过的切图补写来源，不增加旧数据自动转换。

## 验证与验收

- 共享测试：绑定格式、相对路径校验、稳定身份关联、无匹配与错误身份、多页同名资源隔离。
- 宿主测试：选择/加载/生成、取消、错误、页面绑定身份、后台读取不改变当前 PSD、保存重开和另存为路径。
- 浏览器测试：未绑定入口、原型切换、绑定和生成后显示、页面切换与两个来源隔离、加载失败恢复。
- 运行共享、相关宿主/浏览器回归与生产构建；记录实际结果与无法自动验证的边界。

## 实现与验证结果

- 页面 artPsd 模型、JSON Schema、协议与相对路径验证完成。生成/绑定使用捕获的页面 ID，文件绑定与槽位关联同事务，可撤销重做；跨页切换、取消与旧关联保护均有回归。
- 原生后台加载复用工作台 PSD 模型；内嵌身份的纯读取不改 dirty，普通 PSD 的新身份随 sidecar 保存。保存/重开、缺文件、另存为重算路径经过真实 VS Code 宿主验证。
