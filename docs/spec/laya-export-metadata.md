# Laya 预制体与图片导入信息

Status: Done

日期　2026-11-23

## 现状与目标

PSD 切图导出把九宫格写入来源清单。首次导出预制体会额外生成图片导入信息，已有预制体只为新增控件补资源，预制体自身的 UUID 由引擎创建。两个导出入口都需要在生成文件时交付 Laya 可以直接使用的导入信息。

## 写入与合并

- 每份 `.lh` 的相邻 `.lh.meta` 保存预制体 UUID。每张导出 PNG 的相邻 `.png.meta` 保存图片 UUID、纹理类型和按上、右、下、左、重复排列的九宫格。关闭九宫格时五项归零。
- 使用磁盘已有的有效 UUID，缺少时按目标相对路径分配稳定 UUID。按字段合并顶层和 importer 对象，保留引擎自定义字段。损坏的 JSON、UUID 或 importer 触发写入前错误。
- 已有预制体沿用节点审阅合并。可单独同步预制体或仍在使用的导出图片的导入信息，保留工程另行指定的皮肤和脚本。受管理的图片引用对应落盘 UUID。重复同步后可再次返回零差异。
- 来源清单与实际产物的九宫格一致。导入信息与产物参加同一次检查、提交和失败恢复。

## 实施与验收

1. 共用导入信息生成器，接入 PSD 切图与预制体事务。
2. 在现有预制体审阅中识别纯元数据修改，复用原有提交入口。
3. 验证新建、缺失字段、已有 UUID 与自定义设置、修改及清除九宫格、重复导出、损坏文件和写入失败恢复。运行共享测试、构建与预制体工作台浏览器用例。

377 项共享测试、生产构建和 VS Code 原生宿主测试通过。Edge 工作台用例在导出后更换图片 UUID、修改九宫格并删除预制体导入文件，验证同步恢复了关联和九宫格，保留过滤设置与挂载脚本，再次审阅为零差异。
