# Document Element ID Uniqueness

Status: Done
Date: 2026-11-13
Scope: 原型页面与控件在整份文档内共享唯一 ID 空间

## Context and Root Cause

用户确认 ID 是核心识别依据，必须确保唯一。现有分配器已收集全部页面/节点和会话分配历史，创建及复制使用碰撞重试；普通编辑保持 ID。校验器却分别检查 pages 数组和每个 page.nodes 数组，因此手改/导入的数据可让不同页面的节点重号，或让节点与页面根重号。这是分配范围与校验范围不一致，随后读取/保存/宿主消息均复用该校验而接受了歧义身份。

## Behavior and Design

- 同一文档内所有 page.id 和 node.id 共用一个唯一空间，包括独立 UIBox 组件画板；重复跨页面、跨层级或跨页面/节点类型均拒绝。
- 共享校验用一次文档级 Map 记录 ID 对应的首个 JSON 路径。重复错误包含 ID 和两个冲突位置，方便定位；不自动改写 ID、层级引用或关联信息。
- 解析、序列化、Webview→Host 校验继续统一调用 validateGameFlowDocument，无法通过导入/保存候选绕过身份规则。
- v1/v2 规则一致。唯一的旧长 ID、可读 ID 原样保留；8 位只是新建规则。需求和交互 ID 仍属于各自已有命名空间。
- 新建、Ctrl+D 页面/子树复制继续使用共享占用集合，新副本及其全部子节点获得新 ID，内部 parentId 指向副本；重试耗尽明确失败。同会话撤销/删除后不重用已分配 ID。
- 跨文档继续使用带 documentId 的作用域身份；短 ID 不宣称跨项目全局唯一。本轮不引入项目级注册表、删除历史持久化、自动修复重复身份、PSD/Prefab 转换或新的 schema 版本。

## Implementation and Verification

1. 先添加确定性跨页面/根节点冲突测试，确认当前校验错误地接受冲突。
2. 用文档级唯一校验替换页面元素的分组校验，保留其他结构/引用验证。
3. 验证读取、序列化和协议边界拒绝冲突且不修改输入；兼容旧 ID 与相同名称的不同节点。
4. 使用受控碰撞候选覆盖连续复制、父引用重写及撤销后保留分配；运行全部测试及构建，检查两个样例文件仍可加载。
5. 同步身份基线与既有 ID 工作项。

## Risks and Rollback

以前被错误接受的跨页重复 ID 文档现在会报错，需要显式解决身份歧义后继续使用；无法自动决定哪个节点应继承外部绑定。旧 ID 不因格式而被替换。回退校验会重新放开歧义输入，不建议用回退掩盖数据冲突。

## Verification

- 修改前的回归测试确认：v1 跨页节点重号被错误接受，解析未抛出 GameFlowValidationError；其余原有 72 项测试通过，证明缺口位于身份范围校验。
- 修改后 `npm test`：77 项全部通过。覆盖 v1/v2 的六类冲突、错误定位、不修改输入、解析/序列化/协议拒绝、唯一旧 ID 与同名节点兼容、受控碰撞下连续复制和恢复复制前状态后继续分配。
- `sample/backpack.gameflow.json` 与 `sample/ui-components.gameflow.json` 均通过更严格校验及不改写往返。
- `npm run build`：宿主/Webview 类型检查与生产构建通过；保留既有 Vite 单包体积提示。
- 本次变更位于共享文档验证边界，无 UI 变更；未追加真实 Extension Host 或 Photoshop 验证。
