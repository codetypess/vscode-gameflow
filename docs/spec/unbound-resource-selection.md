# 未绑定资源页面的节点选择

Status: Done
Date: 2026-11-24
Scope: 美术 PSD / 预制体资源模式下未绑定页面的页内画布选择。

## 1. Context

未绑定 PSD 的页面在非原型资源模式下会显示页面级状态卡。当前状态卡替换整棵节点树，进入页面编辑后画布没有节点 DOM，点击无法命中单个控件。

后续验收发现，完整状态卡始终按约 290×170 的内容尺寸等比缩放。378×40 的短画板只能使用 0.25 倍缩放，32px 高的“生成 PSD / 绑定 PSD”按钮实际约 8px，文字和操作入口无法辨认。

## 2. Goals

- 未绑定 PSD、PSD 加载中或 PSD 加载失败时，页内编辑仍可按原型几何选择节点。
- 保留页面级状态提示，以及生成、绑定和重试入口。
- 短画板不缩小完整卡片，生成和绑定操作保持可辨认、可点击。
- 选择结果继续使用现有命中、图层树、属性面板和选框同步规则。

## 3. Non-Goals

- 不为未绑定页面伪造 PSD 或预制体资源。
- 不改变总览默认选择整页的交互。
- 不改变资源模式、文档数据或 PSD 绑定持久化。

## 4. Current Behavior

在“预制体资源”或“美术 PSD资源”模式下，`pagePreviewBlocked` 为真时，`webview/app.tsx` 只渲染 `PageArtState`。浏览器复现显示未绑定页内编辑没有 `data-node-id` 元素，因此画布点击不能触发 `canvasHitNode` 的节点命中。

节点命中修复后，`PageArtState` 仍只有一种纵向卡片布局。其缩放取页面宽高与 290×170 的比例，最低 0.25；短画板因此展示一个被压到不可读尺寸的完整卡片。

## 5. Proposed Behavior

页内编辑保留不可见的原型节点命中层，画面只显示不透明的未绑定、加载中或失败状态。状态层允许画布事件穿透，生成、绑定和重试按钮保持可点击。总览仍显示页面级状态并按页面选择。

状态组件根据画板可用尺寸选择三种布局。普通画板使用完整纵向卡片；宽而矮的画板使用单行紧凑状态栏，保留状态文字和操作文字；宽高都受限时使用最小图标状态栏，按钮通过图标、原生提示和可访问名称表达操作。布局先切换，再按当前画布缩放抵消比例和可用边界计算缩放，避免用极小比例压缩完整卡片。

## 6. Design

节点树继续由 `NodeView` 提供命中几何，在资源状态阻断时隐藏其视觉内容。`PageArtState` 使用不透明背景并作为非阻塞状态层，仅将自身操作按钮设为可交互。修复放在画布渲染边界，避免在命中函数中对缺失 DOM 做特殊兜底。

`PageArtState` 负责布局分类与缩放基准。完整、紧凑和最小布局分别使用各自的自然尺寸；紧凑布局横向排列状态和操作，最小布局隐藏视觉文字并保留图标按钮。DOM 标记暴露当前布局，供真实浏览器回归验证尺寸和可见性。

## 7. Implementation Plan

1. 在未绑定资源状态下渲染不可见节点命中层和不透明状态层。
2. 让状态层背景与文本区域不拦截节点点击，仅保留操作按钮命中。
3. 增加浏览器回归，验证未绑定页进入编辑后存在节点并能选中控件。
4. 运行共享测试、类型检查、生产构建和资源模式浏览器回归。
5. 为短画板增加紧凑及最小状态布局，并验证按钮的实际屏幕尺寸与画板边界。

## 8. Testing Plan

- `test/resource-modes-browser.cjs` 在预制体资源模式进入未绑定页面，点击节点并检查选中状态。
- 浏览器使用 378×40 和 160×40 的未绑定页面，分别验证紧凑文字按钮与最小图标按钮，操作入口高度至少 24px 且不超出画板。
- 现有资源模式、页面 PSD 绑定及画布选择回归。
- `npm test`、`npm run check`、`npm run build`。

验证结果：`npm run check` 通过，382 项共享测试通过，资源模式 Edge 回归的 17 组检查、页面 PSD 绑定回归及小画板状态专项回归通过，生产构建通过。浏览器实际复现确认状态页不透出原型内容，直选时可选中遮罩下的“角色名称”，选框、图层树和控件属性同步更新；378×40 的紧凑布局与 160×40 的最小布局中，生成和绑定入口实际高度均不少于 24px 且未超出画板。

## 9. Acceptance Criteria

- 未绑定页面不显示原型内容，点击其节点所在位置后图层树和属性面板选中对应节点。
- 状态卡仍显示“尚未绑定美术 PSD”，生成和绑定按钮可用。
- 378×40 页面显示单行“未绑定 PSD / 生成 / 绑定”，按钮可读且不被裁切；更窄页面显示清晰的生成、绑定图标入口及提示。
- 总览仍按页面选择，资源模式切换和文档序列化行为保持原规则。

## 10. Risks and Rollback

紧凑布局的切换阈值可能在临界尺寸产生视觉跳变。回归覆盖阈值两侧，并让每种布局使用固定自然尺寸，避免动态内容改变布局。回滚时可移除紧凑分类并恢复完整卡片缩放。
