# 未绑定资源页面的节点选择

Status: Done
Date: 2026-11-24
Scope: 美术 PSD / 预制体资源模式下未绑定页面的页内画布选择。

## 1. Context

未绑定 PSD 的页面在非原型资源模式下会显示页面级状态卡。当前状态卡替换整棵节点树，进入页面编辑后画布没有节点 DOM，点击无法命中单个控件。

## 2. Goals

- 未绑定 PSD、PSD 加载中或 PSD 加载失败时，页内编辑仍可按原型几何选择节点。
- 保留页面级状态提示，以及生成、绑定和重试入口。
- 选择结果继续使用现有命中、图层树、属性面板和选框同步规则。

## 3. Non-Goals

- 不为未绑定页面伪造 PSD 或预制体资源。
- 不改变总览默认选择整页的交互。
- 不改变资源模式、文档数据或 PSD 绑定持久化。

## 4. Current Behavior

在“预制体资源”或“美术 PSD资源”模式下，`pagePreviewBlocked` 为真时，`webview/app.tsx` 只渲染 `PageArtState`。浏览器复现显示未绑定页内编辑没有 `data-node-id` 元素，因此画布点击不能触发 `canvasHitNode` 的节点命中。

## 5. Proposed Behavior

页内编辑保留不可见的原型节点命中层，画面只显示不透明的未绑定、加载中或失败状态。状态层允许画布事件穿透，生成、绑定和重试按钮保持可点击。总览仍显示页面级状态并按页面选择。

## 6. Design

节点树继续由 `NodeView` 提供命中几何，在资源状态阻断时隐藏其视觉内容。`PageArtState` 使用不透明背景并作为非阻塞状态层，仅将自身操作按钮设为可交互。修复放在画布渲染边界，避免在命中函数中对缺失 DOM 做特殊兜底。

## 7. Implementation Plan

1. 在未绑定资源状态下渲染不可见节点命中层和不透明状态层。
2. 让状态层背景与文本区域不拦截节点点击，仅保留操作按钮命中。
3. 增加浏览器回归，验证未绑定页进入编辑后存在节点并能选中控件。
4. 运行共享测试、类型检查、生产构建和资源模式浏览器回归。

## 8. Testing Plan

- `test/resource-modes-browser.cjs` 在预制体资源模式进入未绑定页面，点击节点并检查选中状态。
- 现有资源模式、页面 PSD 绑定及画布选择回归。
- `npm test`、`npm run check`、`npm run build`。

验证结果：`npm run check` 通过，382 项共享测试通过，资源模式 Edge 回归的 17 组检查通过，生产构建通过。浏览器实际复现确认状态页不透出原型内容，直选时可选中遮罩下的“角色名称”，选框、图层树和控件属性同步更新。

## 9. Acceptance Criteria

- 未绑定页面不显示原型内容，点击其节点所在位置后图层树和属性面板选中对应节点。
- 状态卡仍显示“尚未绑定美术 PSD”，生成和绑定按钮可用。
- 总览仍按页面选择，资源模式切换和文档序列化行为保持原规则。

## 10. Risks and Rollback

状态层透明后可能让缺失资源节点更显眼。若视觉验收不接受，可仅保留半透明遮罩而继续让指针事件穿透。回滚时恢复页面状态分支的整页替换即可。
