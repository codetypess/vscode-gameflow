# 画板标题的 PSD 和预制体状态图标

Status: Done

## 显示规则

在每个原型画板标题的尺寸左侧，按 PSD、预制体的顺序显示该页已具备的状态。图标沿用参考图的单色实心主体与右下角角标，颜色跟随工作台主题。

- 页面有 `artPsd` 时显示叠层与链环，悬停提示「已绑定 PSD」及绑定路径。
- 页面有 `prefabSync` 时显示立方体与对勾，悬停提示「已同步预制体」及上次同步的目标路径。
- 两项独立显示。图标读取页面工作副本，跟随编辑、撤销和重开后的记录。

## 验收

Edge 回归通过实际绑定、同步、撤销和重做验证四种状态及路径提示。180px 宽的长标题画板中，标题省略，两个图标仍在尺寸左侧，尺寸右端与画板对齐。421 项共享测试和生产构建通过。
