# 重新切图后的预制体图片引用

Status: Done

## 复现与根因

先导出使用内置图片的预制体，修改绑定 PSD 的按钮状态或图片图层，导出新切图，再打开「预制体同步」。画板按当前 PSD 重新匹配槽位，导出计划却读取原型保存时的槽位。即使计划拿到了新图，同步树也没有比较图片引用，合并已有节点只处理已经指向目标图片的引用。

## 行为和验收

- 导出计划使用本次绑定 PSD 的槽位和切图名称。页面结构、组件引用和导出开关沿用原型。
- 在已有节点逐槽审阅 UIImage 和 UIButton 的图片引用，可采纳或跳过。底图、图标、滑块、进度填充、单选和复选标记都按所属 UIImage 处理，父控件的部件引用仍指向原节点。
- 切图已落盘时采用相邻导入文件的 UUID。图片同路径重新导出且引用正确时，预览显示新图，再次同步应为零差异。保留引擎专用资源和脚本。
- 用导出、重新切图、审阅、写入和再次审阅的回归验证各状态、部件、清空槽位及跳过决定。通过工作台菜单验证已关联预制体上的实际操作。

## 验证结果

共享回归覆盖独立图标、容器背景、按钮普通态和选中态换图、清空禁用态、四类复合控件及单选组的嵌套图片。选择和跳过分别作用于对应槽位。已有外部皮肤 UUID 遇到已绑定切图时默认跳过，可显式选择更新。

Edge 回归在已有预制体上修改按钮切图名称并导出，两态分别列出差异。提交后直接读取目标文件，两项引用都等于各自 PNG 导入信息的 UUID，重开预览的像素符合测试 PSD。另已验证同路径 PNG 更新、引擎组件保留和重复同步。409 项共享测试、两项 Edge 工作台流程及生产构建通过。
