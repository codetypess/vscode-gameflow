# 从 PSD 导入原型

Status: Done
Date: 2026-11-25
Scope: 原型画布底部菜单、图层转换及原型预览

## 1. Context

策划和美术可以从已有 PSD 的结构开始编辑原型。

## 2. Goals

一次选择文件，得到保留设计尺寸、层级顺序、位置和可见性的可编辑画板。原型可随 GameFlow 文档保存、重开及撤销。

## 3. Non-Goals

交互及控件语义在原型中由作者配置。预览保留复杂 PSD 保存的整页合成外观。编辑控件后的逐层渲染支持普通像素蒙版及剪贴底层透明度，复杂混合与多样式文字仍按现有原型绘制能力近似。

## 4. Current Behavior

底部「更多」可生成、绑定、审阅同步和打开切图。绑定作用于已有页面和图片槽位。

## 5. Proposed Behavior

原型工作区有文档时，可从底部「更多」或总览空白处的右键菜单选择「从 PSD 导入原型…」。选择单个本地 PSD，完成后打开新画板并切换到原型资源模式。取消和读取失败保留当前画布。画板名称来自文件名，位置在已有画板右侧。

## 6. Design

本地文件由现有 PSD Worker 读取。分组、文字和像素分别转换为容器、文本和内嵌图片控件。图层坐标按父级原点转换，画布保留源尺寸。保留图层独立显隐，透明度和基础字体样式按原型现有字段表达。没有可用像素的非文字图层会在结果中提示。较大的单层图片使用 WebP 或降采样以适配现有内嵌格式限制。导入通过常规文档编辑事务提交一次，原始文件只读。

文字按 Photoshop 的点文本或段落文本导入。点文本关闭自动换行，保留内容里的换行；使用有效的文本排版框与变换，按该框对齐。段落文本使用变换后的段落框并自动换行。缺少有效框或遇到无法直接映射的变换时使用像素框和已有的位置回退。文字仍按原型字体测量。

《获取途径》的三个 24px 点文本在 PSD 的字形框宽 95px，排版框宽 96px。旧导入使用字形框，且点文本沿用原型自动换行的缺省值，Chrome 中把四个字拆成两行。点文本的字形顶边还被用作 UILabel 的行框顶边，使 24px 文字的实测基线较 PSD 低约 5px。

## 7. Implementation Plan

接入选择文件和 Worker 转换，追加页面并打开画板。沿用内嵌图片字段及其原型预览。

## 8. Testing Plan

用合成 PSD 验证嵌套几何、堆叠顺序、可见性、图像渲染和文字样式。用仓库 PSD 验证实际菜单、错误处理、撤销及重开。

生产构建、398 项共享测试和 Chrome 浏览器回归通过。导入回归覆盖合成 PSD 与《星海远征 · 登录》样例。页面 PSD 回归覆盖原有绑定、生成和切图入口。

用《获取途径》确认标签和按钮文案原先的折行与基线偏移。Chrome 回归使用相同的 95px 字形宽度和 96px 排版宽度，验证点文本单行显示、基线位置、段落框换行和显式换行数据。生产构建和 398 项共享测试通过。

## 9. Acceptance Criteria

- 总览无页面选中时可打开导入入口。
- 一次导入新增一个页面并打开编辑；正常编辑、撤销和重开保留图层数据。
- 取消或无效文件返回画布；无效文件显示原因。

## 10. Risks and Rollback

PSD 解析沿用现有尺寸、编码和内存预算。导入页使用现有节点字段，按需在页面的可选字段 `psdImportPreview` 中保存合成图和控件外观指纹。旧页可从匹配的绑定源文件恢复原始外观。详见[导入原型的 PSD 合成预览](psd-import-preview-fidelity.md)。
