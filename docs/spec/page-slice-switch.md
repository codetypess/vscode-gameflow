# 从原型画板切换到绑定的 PSD

Status: Done
Date: 2026-11-26

## 根因

「获取途径」的磁盘 PSD 已换成 36 层，同名配置仍引用之前的 68 层。页面宿主复用会话时调用 revert 刷新，如果配置无法套用，revert 会把整份文档恢复为旧内存基线。随后同路径打开仅聚焦旧会话。首次打开该路径也会被页面资源加载的配置检查提前拦截。浏览器的切换对话框只有继续打开和取消，继续打开后还会从本地草稿恢复已放弃的改动。

## 修复与验收

画板上的切图入口需要已有 PSD 绑定。按绑定路径打开磁盘上的最新 PSD，即使相邻配置属于旧文件。有效配置继续按原有规则读取，旧配置保留在磁盘，替换保存仍须确认。用于原型渲染和同步的身份校验继续独立执行。重复进入同一文件、同一版本保留正在编辑的图层。

切换文件或版本前同步当前切图编辑。干净会话直接切换，有未保存修改时可保存并打开、不保存并打开或取消。保存针对当前切图配置，保存失败或取消保留当前编辑。放弃时清理其草稿，目标会话只显示目标文件的图层和状态。

## 验证结果

生产构建、403 项共享测试和 57 项 VS Code 宿主检查通过。宿主回归覆盖同路径替换、保留异源配置和工作台重开。Edge 回归实际从两个已绑定画板进入切图，核对取消、保存时下载的配置名与图层设置，以及放弃修改后再次进入时恢复上次保存值。
