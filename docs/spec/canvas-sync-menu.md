# 画布更多菜单与单向同步

Status: Done

2026-11-24

## 入口与范围

原先独立的预制体导出 / 同步按钮占用底部工具栏位置。将「PSD 同步」「预制体同步」放入当前页面的「更多」菜单，保留切图、生成和绑定 PSD 操作。两项同步沿用现有双向审阅流程，预制体目标尚未生成时支持首次导出。

## 固定快捷入口

「PSD 同步」和「预制体同步」各自提供一个可切换的图钉，初始均关闭。点击右侧图钉时菜单保持打开，点击左侧同步项执行对应操作。即使当前页面无法同步，也可以调整固定偏好。

固定后，底部工具栏在「更多」左侧按 PSD、预制体的顺序显示所选图标。快捷入口和菜单共用当前页面的同步操作及可用条件。固定偏好保存在本机界面设置，切换页面和重新打开工作台后恢复。验证独立切换、键盘操作、两个快捷入口执行、窄窗口位置和重载恢复。

## 单向操作

「单向同步」子菜单按以下顺序列出操作。选中方向后，同一轮中所有差异以选定来源为准。已有目标的变更可在写入前审阅或取消。

| 菜单 | 行为 |
| --- | --- |
| 原型 → 预制体 | 按原型创建或同步预制体中可往返的控件和属性，图片槽使用原型内置资源，沿用预制体合并的引用保护。 |
| 预制体 → 原型 | 从已存在的预制体读取控件与属性，应用到页面和撤销历史。源预制体、资源和导入元数据只读。 |
| 原型 → PSD | 已绑定时以原型为准预演文字与结构，通过原有副本流程更新绑定。首次使用可生成并绑定 PSD。 |
| PSD → 原型 | 从页面绑定的 PSD 读取识别到的控件、文案和字号，所有差异固定以 PSD 为来源并应用到原型及撤销历史。PSD 文件保持只读，原型继续使用自己的内置资源。 |

第四项曾被错误定义为“从 PSD 到预制体”，因此菜单命令直接进入预制体导出链路。正确的四项应形成原型分别与预制体、PSD 的双向闭环；单向菜单不提供跨过原型的 PSD 到预制体直达操作。

## 实施与验收

1. 把入口集中到同一菜单，未选页时置灰，鼠标和键盘均可展开子菜单。
2. 在现有审阅与提交路径落实来源方向，区分文件缺失时的创建与读取，复核目标版本后提交。
3. 验证各方向实际写入的文案、结构或资源，检查来源和第三方文档、取消、首次创建和重复执行。运行共享测试、浏览器回归和生产构建。

## 验证结果

图钉的 Chrome 回归覆盖两个入口分别固定与取消、键盘切换、刷新后恢复、无选中页面时的禁用状态、两个快捷图标打开对应同步窗，以及 360px 宽度下的图标顺序和可见性。生产构建通过。

Chrome 通过键盘展开子菜单，完成四个单向操作并回读原型、预制体和下载的 PSD 副本。用例确认“PSD → 原型”固定采用 PSD 文案与结构，只写入原型及同步基线，保留原型图片资源并保持预制体只读；重复执行无待写入项。原有 PSD 双向同步回归、385 项共享测试及生产构建通过。
