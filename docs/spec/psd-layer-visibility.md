# PSD 切图画布的图层可见性

Status: Done

切图面板在每个实际 PSD 图层和分组行的最右侧提供眼睛按钮，左侧复选框继续标记导出。眼睛只控制当前文件的切图画布。原型美术资源、导出像素和保存的切图配置使用原有来源。智能对象内部的只读树由外层智能对象统一控制。

初始显示 PSD 保存的合成图。切换组时保留各子层的开关状态，祖先隐藏时子层随之隐藏。画布点击和轮廓采用当前有效可见性。恢复原始状态后直接显示保存的合成图，打开另一份文件时按该文件初始化。

桌面通过临时 PSD 快照的可见标志重新合成复杂文档，保留画布尺寸、画板和图层效果。普通像素可直接叠加。独立浏览器对复杂效果显示基础像素预览提示。验证覆盖单层、分组往返、原始隐藏层、快速切换、画布命中与导出隔离。

Chrome 与本机 PhotoCraft 验证了实际工作台切换图层、画布命中和恢复合成图。独立浏览器回归覆盖分组继承及原始隐藏层，原型绑定切图与九宫格导出的像素回归通过。
