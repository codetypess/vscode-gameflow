# Canvas Navigation Inputs

Status: Done
Date: 2026-11-12
Scope: 为页面总览画布增加鼠标滚轮定点缩放和空白画布直接抓手平移。

## 1. Context

当前画布只能通过底部加减按钮缩放；平移前必须先切换手型工具。用户要求滚轮直接放大缩小，并在点击空白画布时出现抓手后拖动画布。

## 2. Goals

- 滚轮在页面总览中缩放画布，缩放中心为鼠标所在位置。
- 选择模式或手型模式下，按住空白画布都能平移。
- 按下空白画布时光标从抓手变为抓取中状态，松开恢复。
- 页面组拖动仍移动页面，不触发相机平移。

## 3. Non-Goals

- 不改变页面内部编辑视图的缩放。
- 不加入触控板双指手势识别、惯性平移或相机状态持久化。
- 不改变文档协议或撤销历史。

## 4. Current Behavior

底部缩放按钮可修改 40%–160% 缩放。只有显式选择手型工具后，画布指针拖动才会更新相机平移。

## 5. Proposed Behavior

鼠标位于总览画布时，滚轮按固定倍率缩放；计算新平移量以保持光标下世界点不变。选择模式下按住空白画布临时进入抓手平移，松开后工具仍为选择；手型模式行为保持不变。

## 6. Design

- 滚轮事件仅绑定中央画布视口，调用 `preventDefault()`，不影响两侧面板滚动。
- 使用视口本地坐标、当前 pan 和 zoom 计算光标下的世界坐标，再反算新 pan。
- 空白画布的指针捕获由视口拥有；页面组继续停止事件冒泡并使用原页面拖动逻辑。
- 相机状态仍是 Webview 本地状态，不进入 GameFlow 文档和撤销事务。

## 7. Implementation Plan

1. 增加鼠标滚轮定点缩放函数。
2. 放宽空白画布平移入口并调整抓手光标状态。
3. 构建并在本地预览验证缩放中心、平移和页面拖动互不冲突。

## 8. Testing Plan

- `npm run build` 和 `npm test`。
- 浏览器预览记录滚轮前后缩放百分比和页面屏幕位置。
- 拖动空白画布后检查世界容器 transform 改变。
- 检查页面卡片仍可独立拖动。

## 9. Acceptance Criteria

- [x] 滚轮可在 40%–160% 范围缩放总览画布。
- [x] 缩放时鼠标下的世界点保持稳定。
- [x] 选择模式点击空白画布显示抓手并可拖动平移。
- [x] 页面拖动不会同时平移画布。
- [x] 页面内部编辑和侧栏滚动行为不受影响。
- [x] 构建、测试和差异检查通过。

## 10. Risks and Rollback

滚轮缩放会接管中央视口的默认滚动；限制作用域可避免侧栏受影响。回退只需移除视口 `onWheel` 和选择模式临时平移入口。

## 11. Verification Results

- 浏览器预览中滚轮将缩放从 68% 提升到 75%，世界容器 pan 同步反算。
- 空白画布拖动后 pan 变化约 `(120, 80)`，默认光标为 `grab`。
- 拖动页面后相机 transform 不变，只有页面世界坐标更新。
- `npm run build`、`npm test` 与 `git diff --check` 通过。
