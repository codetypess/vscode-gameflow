# Cyclic Canvas Grid

Status: Done
Date: 2026-11-13
Scope: 原型和 PSD 切图画布共用循环缩放点阵

## Context and Behavior

原型点间距直接乘缩放，缩小时过密、放大后过疏；PSD 切图背景固定 24px，不跟随相机。用户要求放大/缩小循环点阵，并让切图同样处理。

- 每放大一倍进入更细一档，每缩小一半进入更粗一档；屏幕点间距维持在 24px（含）至 48px（不含），100%、200%、50% 均回到 24px。
- 档内点阵随缩放和平移，点大小保持屏幕像素尺寸；档位切换仍以画布原点对齐，旧交点成为新点阵的交点，不让点阵整体错位。
- 背景位置使用有界余数，支持正负平移；仅为视图装饰，不提供吸附或影响页面/PSD/节点坐标和保存内容。
- 原型总览、页面编辑及 PSD 切图复用同一算法与点阵组件；PSD 内透明棋盘格和九宫格编辑不受影响。

## Acceptance and Verification

纯函数验证两种相机的完整缩放范围、倍增/减半周期、切换前后原点对齐及正负平移。构建与测试通过；浏览器验证两种画布滚轮缩放、拖动、点阵密度、切换模式保持相机及不产生文档修改。

## Risks and Rollback

档位边界增减网格点属于预期行为；交点保持对齐，点不随缩放变粗。回退背景组件不影响文档数据。
