# 切换资源模式清除节点选择

Status: Done
Date: 2026-11-19
Scope: 原型 / 美术 PSD / 预制体切换时的节点选择

2026-11-23 后续：独立运行预览已由 [画布预览与 Prefab 动作归位](canvas-prefab-action.md) 移除；本文关于画布三种资源模式清除选择的规则继续有效，独立预览会话的记录仅是历史验收。

## Context / Root Cause

资源按钮只调用 setResourceMode 和 refresh，App 的 NodeSelection 及运行预览自己的 nodeId/compare 独立保留。美术模式在 PSD 未绑定时不绘制节点，但选框和属性仍投影旧选择，出现空页面覆盖上一模式选框的问题。

## Behavior / Design

- 实际切换原型、美术 PSD 或预制体时，清空全部节点选择、临时拖拽预览及节点上下文菜单。
- 保留当前页面、页内编辑状态、相机和层级位置，页面 PSD 操作仍有明确目标。
- 点击已经激活的资源模式仅刷新资源，保留选择。
- 运行预览切换模式同样清空临时节点选择及资源对比；不重置临时控件状态。
- 复用 App 的节点选择拥有者和统一资源切换回调，不写入 GameFlow 文档。

## Acceptance / Testing

浏览器先复现：页内选中节点后切至未绑定 PSD，美术占位提示出现但选框仍在。修复后切至三种模式都不保留节点选择，页内编辑、相机、文档及页面 PSD 更多菜单保持稳定；运行预览不保留旧节点检查信息。生产构建和相关浏览器回归通过。

## Verification

- 修复前，页内选中节点后切到美术模式，treeitem aria-selected 仍为 true，新增回归失败。
- 修复后，三种模式间切换都清除选框与图层树选择；当前页面、页内编辑状态、相机、更多菜单页面目标和文档序列化内容保持稳定；刷新当前模式保留选择。
- 运行预览切换三种模式后不再显示上一模式节点的尺寸编辑器，当前页面保持不变。
- 页面 PSD 浏览器回归、默认图片全链路浏览器回归、三模式整体浏览器验收、364 项共享测试及生产构建通过。
