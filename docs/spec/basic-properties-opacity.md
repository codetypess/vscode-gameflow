# Basic Properties and Opacity Slider

Status: Done
Date: 2026-11-16
Scope: 属性分组名称及不透明度滑块

## Context and Behavior

用户要求将“位置与尺寸”改为“基础属性”，并把不透明度移入该组，以截图中的滑块加数字框调整。现有不透明度位于外观组末尾，以百分数输入。

- 页面/控件的“位置与尺寸”标题统一改为“基础属性”。控件在旋转后显示“不透明度”行：左侧名称、中间滑块、右侧数字框。
- 使用本地 shadcn/ui Slider 源码与 Radix Slider primitive，沿用 VS Code 主题；抽取可复用 SliderPropertyRow。范围 0～1，步长 .01，数字最多两位、不补零；数字框沿用 Enter/失焦提交、Escape 恢复、范围钳制规则。
- 滑块与数字互相同步，滑块连续调整实时更新当前节点 style.opacity；沿用现有样式事务、保存和 undo/redo。父子不透明度叠乘行为不变，缺省为 1，0 合法。锁定/继承锁定禁用两种输入。页面根不新增不透明度字段。
- 外观组移除原来的“不透明度 %”输入。无文档字段或协议变更，不迁移旧数据。

## Verification

类型检查、现有共享测试及生产构建通过。浏览器独立样例验证分组与位置、滑块点击/拖动/键盘、数值输入/精度/边界/取消、双向同步与画布预览、锁定、撤销重做和保存重载，检查 280px 面板及截图。现无 DOM 组件自动化，不新增 CSS/实现镜像测试。

2026-11-16 验证：121 项共享测试与生产构建通过，构建保留现有大包体提示。独立 5174 样例中拖动滑块得到 .34，数字/画布同步；键盘 Home/End 到 0/1，箭头按 .01 调整；输入 .376 提交为 .38，超范围钳制，Escape 恢复，撤销/重做恢复值。自身及祖先锁定禁用输入；父 .5 × 子 .6 预览为 .3，保存重载保留。页面基础属性无新增不透明度，旧标题与百分数字段已移除。280px 面板无横向溢出，控制台无警告或错误。截图：`basic-properties-opacity-20261116.jpg`。未执行真实 VS Code Extension Host 测试。

## Non-Goals and Risks

不增加 Visible 控件或页面 Alpha，不改变父子渲染，不扩展独立的历史合并协议。滑块沿用现有连续样式编辑的事务粒度。
