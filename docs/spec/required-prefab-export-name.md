# 预制体导出名称必填

Status: Done
Date: 2026-11-25

## 行为与原因

清空页面属性中的导出名称后，原有生成器会取页面显示名称作为文件名和根节点名。引用模板也可直接沿用已关联的路径。页面仍可正常编辑和保存，生成或同步写出预制体时需要显式填写导出名称。

## 实施与验收

- 在选择导出目录或同步目标前检查当前原型及其引用的画布和列表项模板。按页面身份去重，一次提示所有缺少导出名称的原型，跨文件引用附带来源路径。
- 缺省、清空或全空白都拦截整次导出。补齐后可重试，其他独立画板可以继续留空。
- 共享导出规划校验同一规则。单向从预制体读取、PSD 文件命名和编辑器文档校验保留各自的行为。
- 通过共享测试验证单页、嵌套引用与补填重试，通过工作台交互验证报错及实际输出。

## 验证结果

401 项共享测试、类型检查和生产构建通过。Chrome 工作台回归确认名称留空时会提示页面名称，资源和预制体目录均为空，补填后成功导出。跨文件列表项导出和单向同步浏览器回归通过。
