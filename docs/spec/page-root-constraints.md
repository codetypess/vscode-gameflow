# Page Root Constraints

Status: Done
Date: 2026-11-16
Scope: 页面根的布局约束配置及持久化

## Context and Behavior

UIStack、UITop、UIScene 与独立 UIBox 页面根在游戏中也支持相对父容器的六项约束。用户确认本次配置并保存约束，原型画布继续按设计尺寸展示，供后续生成 Prefab 使用；不增加父容器预览。

- 页面属性增加“根节点布局”，复用控件的六项 checkbox、方位图和已启用项偏移框，支持像素与百分比。新启用项缺省 0；已有项重复启用保持数值，关闭写 null。数字沿用整数显示/直接输入及 Enter、失焦、Escape 规则。
- 控件现有“宽度来源/高度来源”合并为“尺寸来源”一行，右侧并排 W/H 两个只读文本框，复用基础属性紧凑行的轴前缀和间距，保留宽度来源/高度来源的无障碍名称。
- 该行与约束单位保持 8px 行距；约束单位使用相同的 48px 标签列和 25px 控件高度，输入左边缘对齐。浏览器复现发现初版来源行未命中 details 的间距选择器，导致行距为 0；旧 Select 使用 60px 标签/27px 高，较来源行右移 12px、增高 2px。在布局所属的样式规则修复，不全局改动其他下拉框。
- 可选 v2 `page.layout` 仅接收 left/right/centerX/top/bottom/centerY（有限数值或 null）和 layoutUnit（absolute/percent）。不接收节点的测量、排布、Padding 或补偿等字段。复用 ConstraintLayout 类型，节点继续支持原有扩展字段。
- 根节点没有预览父容器，切换单位保留原始数字，由用户按新单位填写，不用页面摆放坐标或设计尺寸假定父级换算。面板明确提示“相对于游戏父容器生效，画布保持设计尺寸；切换单位保留数值”。百分比 10 表示 10%。
- 约束不参与当前画布几何解算；page.frame 的 x/y 保持无限画布摆放坐标，width/height 保持设计尺寸。根配置不会改变内部控件布局。拖动、改名、换根类保留约束；整页复制深拷贝约束并分配新 ID。
- 读取旧文档不补默认值；v1 拒绝页面 layout，首次编辑经现有会话事务升级 v2。解析、序列化、宿主消息与 JSON Schema 校验一致。沿用保存与 undo/redo，不新增协议消息。

## Implementation and Acceptance

1. 扩展类型、共享运行时校验和 JSON Schema；旧文档往返不变，非法字段与 v1 新配置拒绝。
2. 页面属性接入复用约束控件；六项可独立开关，0/null 区分，单位保留数字，不改画布位置/尺寸。
3. 验证整页复制隔离、几何不变、会话升级与撤销/重做、保存重载；现有控件约束行为保持。
4. 共享测试及生产构建通过，浏览器独立样例检查原型页面根、单位/数字、画布稳定、历史与重载及面板显示。

对齐回归用独立样例选中图片或按钮，比较尺寸来源 W 输入与约束单位 Select 的左边缘和高度，要求均为 25px 高、左边缘相同、行距 8px；复查根节点单位、锁定控件、尺寸来源的显式/拉伸状态。仓库没有 DOM 组件自动化运行器，使用浏览器实际几何及截图验证，不新增 CSS 镜像断言。

## Verification Results

2026-11-16：127 项共享测试、类型检查和生产构建通过；保留现有大包体提示。新增 6 项测试覆盖四种页面根的约束往返、非法/节点专有字段与 v1 拒绝、旧页面无默认写入、复制隔离与身份、画布及后代几何不变、升级/保存/撤销重做。

独立 5174 浏览器样例验证六项开关、0 有效、负偏移、12.6 提交为 13、Escape 恢复、切换单位保留 13/-5、撤销恢复像素和重做百分比、取消约束隐藏偏移框、保存重载保留配置，根编辑前后页面和所有后代 DOM 几何完全相同。修复后实测尺寸来源和 Select 的 X 坐标一致、均高 25px、行距 8px，无横向溢出；W 双边拉伸/H 显式尺寸只读，祖先锁定禁用约束单位。控制台无警告或错误。截图 `page-root-constraints-20261116.jpg` 与 `compact-size-source-20261116.jpg`。未执行真实 VS Code Extension Host 或 Laya 引擎验证。

## Non-Goals

不增加运行时父容器或舞台预览、不实现 Prefab 输出、不扩展页面根的排布/测量/变换，不改变控件约束换算算法。
