# 每份 GameFlow 的相对导出目录

Status: Done
Date: 2026-11-17
Scope: 本机资源/预制体根目录，加上随 GameFlow 文件保存的独立相对导出目录。

## Context and Goals

2026-11-18 更新：PSD 图片分类与清单位置由 [PSD 独立目录](psd-independent-directory.md) 定义，替代本项最初的 PNG root/dir 路由；exportDirectory 保留用于后续预制体导出。

用户要求工作台设置里的两个路径改称“根目录”。每份 `.gameflow.json` 单独设置 `dir`，并将其写入 GameFlow 文件。输出路径为对应根目录 / dir；本机绝对根路径仍不进入共享文件。

## Behavior and Ownership

- 设置面板将资源、预制体路径更名为“资源导出根目录”“预制体导出根目录”，保留已有 workspaceState 数据与选择行为。
- 当前 GameFlow 的“导出目录”保存共享相对路径，如 `ui/login`，供后续预制体根目录使用；留空使用其根目录。PSD 图片使用资源根目录下的 `shared/`、`unclassified/` 或独立图集目录，来源清单固定在根目录，独立及嵌入 PSD 会话一致；设置面板明确说明这一区别。
- 新增可选文档顶层 `exportDirectory`，所有现有 schemaVersion 可读，旧文件不补默认值。通过原型现有候选编辑、原生 dirty/save/history/backup 和浏览器持久化保存；与页面 `exportName` 独立。
- 编辑提交时去除首尾空白、把反斜线规范成 `/`；不允许绝对路径、父目录/当前目录段、空段、Windows 不兼容字符/保留名/末尾空格或点；允许中文和内部空格。非法输入显示就地错误且不提交，Enter/失焦提交，Escape 恢复。完成或关闭通过正常失焦提交有效输入。
- PSD 宿主从权威 PSD 文档决定分类与独立图集目录，不接受 Webview 任意路径；每次读取最新本机资源根目录，整批写入 PNG 后更新根来源清单，保留冲突检查和失败回滚。文件系统符号链接不新增特殊处理。
- 浏览器从所选资源根句柄访问分类/图集目录并按需创建。预制体仍只有设置和目的地说明，尚不实现 Prefab 生成。

## Implementation and Validation

共享路径规则供 UI、模型、JSON Schema、宿主和浏览器复用。设置面板展示当前文件字段，顶栏导出在原型候选尚未同步时禁用，防止新目录编辑尚未到宿主就导出。

测试覆盖有效/非法路径、文档与消息校验、往返/清空/旧文件、两个文件隔离、历史/原生保存与重开、实际根目录下子目录输出以及更改 dir 后不写旧目录。运行共享测试、完整构建及真实 PSD/工作台宿主集成。浏览器验证新文案、输入提交/取消/错误、保存重载和设置路径预览。

## Acceptance and Limits

根目录留在 workspaceState；dir 写在各自 `.gameflow.json`，不会串文件。PSD 图片按资源分类/图集输出，exportDirectory 不影响其路径。根目录变化无需改共享文件。同一资源根目录共用来源清单，完整相对图片路径决定冲突与覆盖。此项不生成预制体，不自动移动之前已导出的文件，也不改变其他未完成的 PSD 切图区域工作。
