# 每份 GameFlow 的相对导出目录

Status: Done
Date: 2026-11-17
Scope: 本机资源/预制体根目录，加上随 GameFlow 文件保存的独立相对导出目录。

## Context and Goals

用户要求工作台设置里的两个路径改称“根目录”。每份 `.gameflow.json` 单独设置 `dir`，并将其写入 GameFlow 文件。输出路径为对应根目录 / dir；本机绝对根路径仍不进入共享文件。

## Behavior and Ownership

- 设置面板将资源、预制体路径更名为“资源导出根目录”“预制体导出根目录”，保留已有 workspaceState 数据与选择行为。
- 当前 GameFlow 的“导出目录”是一个共享相对路径，分别用于资源与预制体根目录；例如 `ui/login`。留空直接使用根目录。该字段位于工作台设置中的“当前文件”部分，明确随文件保存。独立 PSD 编辑器没有 GameFlow，继续直接使用资源根目录。
- 新增可选文档顶层 `exportDirectory`，所有现有 schemaVersion 可读，旧文件不补默认值。通过原型现有候选编辑、原生 dirty/save/history/backup 和浏览器持久化保存；与页面 `exportName` 独立。
- 编辑提交时去除首尾空白、把反斜线规范成 `/`；不允许绝对路径、父目录/当前目录段、空段、Windows 不兼容字符/保留名/末尾空格或点；允许中文和内部空格。非法输入显示就地错误且不提交，Enter/失焦提交，Escape 恢复。完成或关闭通过正常失焦提交有效输入。
- 宿主导出读取所属工作台的权威文档，不能用 Webview 的任意路径覆盖；现有导出器每次读取最新根目录和当前文件相对目录，创建缺失子目录后再使用既有 PNG/来源清单导出逻辑。未改动的空目录与原行为一致。文件系统符号链接不新增特殊处理。
- 浏览器资源导出遍历所选根句柄下的相对目录并按需创建。预制体仍只有设置和目的地说明，尚不实现 Prefab 生成。

## Implementation and Validation

共享路径规则供 UI、模型、JSON Schema、宿主和浏览器复用。设置面板展示当前文件字段，顶栏导出在原型候选尚未同步时禁用，防止新目录编辑尚未到宿主就导出。

测试覆盖有效/非法路径、文档与消息校验、往返/清空/旧文件、两个文件隔离、历史/原生保存与重开、实际根目录下子目录输出以及更改 dir 后不写旧目录。运行共享测试、完整构建及真实 PSD/工作台宿主集成。浏览器验证新文案、输入提交/取消/错误、保存重载和设置路径预览。

## Acceptance and Limits

根目录留在 workspaceState；dir 写在各自 `.gameflow.json`，不会串文件。资源实际输出到 root/dir，空 dir 保持原目录行为。根目录变化无需改共享文件。原有资源命名、冲突/覆盖和来源规则仍适用于每个最终输出目录。此项不生成预制体，不自动移动之前已导出的文件，也不改变其他未完成的 PSD 切图区域工作。

## Verification

新增 3 项共享测试覆盖路径/模型/协议/JSON Schema、五个文档版本、不同文件独立往返与清空，均通过。`npm run build` 通过。`npm run test:psd-host` 通过 33 项，包括新增真实嵌套目录 PNG/来源清单输出、动态更换 root/dir、越界拒绝和文件目录原生历史/保存/备份/重开。浏览器通过新字段输入、反斜线转 `/`、非法路径错误、Escape 取消、保存重载与 780×560 面板显示检查。浏览器根目录选择/实际输出未端到端覆盖，真实文件输出由宿主集成覆盖。

最终复核 `npm test` 全量 293 项通过，生产构建通过；先前并行切图区域用例的临时失败已由该项工作修正，本项未修改其区域代码或测试。
