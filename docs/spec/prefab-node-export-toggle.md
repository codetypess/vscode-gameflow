# 控件导出开关

Status: Done
Date: 2026-11-26

控件属性中的「导出节点」位于「变量」下方，独立成行。已有文档和新节点默认勾选，仅取消时保存 `exportEnabled: false`。切换进入原型文档历史。取消勾选后，该节点及后代仍可在原型画布编辑，预制体生成和同步预览跳过整个分支，专用资源和模板依赖也随之跳过。

目标预制体已存在对应分支时，预制体同步确认应用后移除它。待移除分支不进入两侧预览和差异树，应用明细显示影响。单向拉取保留原型中的这些节点及磁盘目标。已排除的控件部件引用只在预制体投影中断开。若引擎专用数据仍引用待移除节点，沿用同步引用完整性检查。

原型组件源里的普通节点可设置。组件定义根对应预制体文件的必需根，继承节点随组件源的设置。已存在的独立引用模板按其自身预制体同步入口更新。

验收覆盖默认值、撤销和保存、父级排除、资源跳过、既有目标预览和同步、单向拉取保留原稿以及重新勾选。

403 项共享测试和生产构建通过。Chrome 验证复选框、撤销与重做、同步预览省略、确认后文件内容和重开状态。现有预制体同步与四种单向同步浏览器回归通过。

### 左侧图层树

图层树按预制体的实际导出范围显示颜色。关闭「导出节点」后，该节点和后代的图标、名称与变量名立即置灰，仍可选中和编辑。重新勾选、撤销或重做时，按当前导出设置刷新颜色。
