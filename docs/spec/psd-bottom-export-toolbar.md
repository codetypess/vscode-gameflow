# PSD 底部导出工具栏

Status: Done
Date: 2026-11-24
Scope: 在 PSD 切图画布底部集中提供选择辅助、导出和打开资源目录的纯图标工具栏。

## 1. Context

PSD 切图的“导出”当前通过 portal 放在工作台顶栏右侧，与画布内正在编辑的切图操作距离较远。用户要求在 PSD 画布底部引入工具栏，并增加“在文件管理器中打开”。一次切图导出可能同时写入 `shared/`、`unclassified/` 或独立图集目录，因此不存在唯一的叶级输出目录。

## 2. Goals

- PSD 切图画布底部提供稳定可见的导出工具栏。
- 工具栏包含“直选模式”“虚线框”“导出”和“在文件管理器中打开”四个纯图标命令。
- PSD 直选默认开启；关闭后画布按原型的当前层级规则选择命中内容所属的直属图层或分组，拖动平移保持可用。
- 虚线框显示各层级可见 PSD 图层和分组的非空边界且默认关闭，不参与命中或导出。
- 两项选择辅助偏好只保存在本机，并使用独立于原型画布的存储键。
- 系统文件管理器打开本机工作区设置中的资源导出根目录，覆盖本批可能写入的所有分类目录和根来源清单。
- 顶栏保留 PSD 文档级打开、撤销、重做、保存和更多操作，不重复显示切图导出。

## 3. Non-Goals

- 不改变切图文件名、分类目录、来源清单或导出事务。
- 不允许 Webview 传入任意文件系统路径。
- 不为浏览器预览伪造系统文件管理器能力。
- 不移动工作台设置或 PSD 文档保存动作。

## 4. Current Behavior

“导出”作为顶栏右侧独立文字按钮渲染。PSD 画布底部没有工具栏，也没有打开资源目录的入口。

## 5. Proposed Behavior

有 PSD 资源时，画布底部中央显示紧凑浮动工具栏。最左侧提供默认开启的“直选模式”和默认关闭的“虚线框”；直选开启时沿用现有透明像素穿透点选并返回实际内容层。关闭时按原型画布规则维护当前分组层级：单击把命中的内容层映射为当前层直属项，当前层以外的分支不可选；双击分组进入其子层，双击空白返回父层并选中刚退出的分组，左上路径可直接返回任意祖先。虚线框绘制各层级可见 PSD 图层和分组的非空边界。分隔线右侧的“导出”沿用现有禁用条件和缺目录时打开设置的行为；“在文件管理器中打开”在 VS Code 中打开已配置的资源导出根目录，未配置或浏览器预览时禁用。四项都只显示图标，并保留无障碍名称与悬停提示。状态提示显示在工具栏上方，不与按钮重叠。

## 6. Design

- 工具栏复用画布底部工具栏的尺寸、浮层和响应式约束，使用 `MousePointerClick`、`SquareDashed`、`Download` 与 `FolderOpen` 纯图标按钮；按钮固定为 32×32，并通过 `aria-label`、`aria-pressed` 和 `title` 表达用途与状态。
- PSD 偏好使用 `gameflow.toolbar.psdDirectSelection` 与 `gameflow.toolbar.psdContainerOutlines`；不读取或覆盖原型的 `directSelection` 与 `containerOutlines`。未保存过偏好时，PSD 直选为 `true`，虚线框为 `false`。
- PSD 点选始终先按堆叠顺序和透明像素确定实际内容层；直选开启时返回该层，关闭时沿 `parentKey` 检查当前 scope 并返回 scope 下的直属祖先。图层树选择嵌套项时把 scope 切到其父分组。分组双击、空白回退和左上路径复用原型的层级导航语义；切换直选不重置 scope。画布平移和缩放不受模式影响。虚线框覆盖各层级可见图层和分组的非空边界，使用不接收指针的屏幕像素稳定虚线。
- PSD 面板布局已有 44px 底部预留，继续使用该空间，不改变画板相机和跟随面板算法。
- Webview 通过 `workbenchSettings` 的受限 `reveal` 动作请求打开 `resources` 或 `prefabs` 根目录；协议仍拒绝路径字段和未知目录类型。
- Extension Host 从 `workspaceState` 重新解析当前目录，确认目录仍存在，再调用 VS Code 的系统文件管理器命令。浏览器端返回不支持诊断，但切图工具栏直接禁用该入口。

## 7. Implementation Plan

1. 扩展受限设置协议和宿主目录控制器。
2. 将导出按钮从顶栏 portal 移入 PSD 画布底部工具栏，增加打开目录按钮并处理状态避让。
3. 移植直选与虚线框按钮，增加 PSD 独立本地偏好、点选开关和分组辅助框。
4. 更新独立 PSD 编辑器和统一工作台的调用边界，移除不再使用的导出 portal。
5. 增加协议、宿主和浏览器布局回归。

## 8. Testing Plan

- 共享测试验证 `reveal` 只接受固定目录类型且拒绝任意路径。
- 宿主检查验证缺少、失效和有效目录分支，并确认系统文件管理器只接收已配置 URI。
- 共享测试验证同一像素命中在直选模式返回实际内容层、非直选根层返回顶层分组、进入分组后返回直属子项，并拒绝当前分组之外的分支。
- 浏览器回归验证顶栏不再显示导出，底部工具栏包含四个纯图标命令，窄窗口内可见且不与提示重叠；PSD 默认直选、两项偏好与原型隔离、非直选分组选择及虚线框显示均有覆盖；现有真实导出仍写入预期 PNG。
- 运行 `npm run check`、`npm test`、`npm run build` 和相关浏览器回归。

## 9. Acceptance Criteria

- PSD 切图顶栏没有重复的“导出”按钮。
- 有 PSD 时，底部工具栏以纯图标显示“直选模式”“虚线框”“导出”和“在文件管理器中打开”，没有可见文字标签。
- PSD 首次使用默认开启直选、关闭虚线框；切换后刷新恢复本机选择，且不改变原型画布的两项偏好。
- 关闭直选后按当前层级选择直属图层或分组，可双击分组进入、双击空白返回并通过路径跳转；开启时选择透明像素穿透后命中的实际内容层。拖动仍平移。虚线框显示可见图层和分组的非空边界，可直接在框内点选。
- 导出禁用条件、冲突处理和输出结果保持不变。
- VS Code 只打开当前资源导出根目录；Webview 无法指定任意路径。
- 360px 宽窗口中四个命令仍可访问，状态提示不遮挡工具栏。

## 10. Risks and Rollback

系统目录被外部删除时，宿主返回明确错误并要求重新选择，不静默重建未知位置。若底部浮层影响极小视口，可回退为画布底部全宽命令栏；协议和宿主安全边界可继续保留。
