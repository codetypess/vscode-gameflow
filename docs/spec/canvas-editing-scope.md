# Canvas Editing Scope

Status: Done
Date: 2026-11-16
Scope: 原型画布分层选择、钻入/返回、导航及图层树快捷定位。

## 1. Context

画布当前从 DOM 的 data-node-id 直接选最深命中节点，缺少页面内部的编辑层级。Slider 的滑块是独立 UIImage，因此在页面层点击它会跳过 UISlider。用户要求按 Laya 的交互逐层编辑。

## 2. Goals

- 页面层单击复合控件的任意后代，先选中该控件；只操作当前层的直属子节点。
- 双击容器进入其子层，单击空白取消选择，双击空白退一级。
- 左上角导航显示页面和容器路径，允许快速返回祖先；树选择直接打开目标所在层。

## 3. Non-Goals

不改变模型、序列化或宿主协议；不实现游戏运行交互、PSD 编辑层级或自动聚焦相机。

## 4. Current Behavior

页面编辑只有 selectedNodeId，没有内部 scope；双击文字/按钮聚焦文字属性。画布新增总在页根，空选 Delete 和 Ctrl+D 会操作整页。

## 5. Proposed Behavior

- 页根为初始层级。单击深层图像映射为当前层的直属祖先；当前容器自身背景、其他分支和画布空白均视为空白。
- 双击可容纳子节点的控件进入（包括空容器），清空选择；文字/输入叶子的双击仍聚焦文字字段。双击空白返回父层并选中刚退出的容器；页根空白双击保持页根。
- 导航包含页面与每级容器，当前项有明确样式；点击祖先进入其子层并清空选择。导航和树跳转不改变相机或文档历史。
- 进入容器层后，用 40% 黑色半透明遮罩压暗画布背景、页面和其他分支；当前容器及其后代在遮罩之上保持原有明暗。遮罩不拦截指针，单击/双击空白规则不变；导航、树和属性面板保持明亮。返回/导航/树跳转时同步更新，页根不显示遮罩。
- 点击树任意节点切换至其直接父容器层并选中它；树根返回页面层。保持完整树、原有展开/搜索/画布选中定位能力。
- 工具栏放置新增及空选粘贴使用当前容器；放置坐标经容器逆矩阵和静态滚动换算。锁定或不可逆容器不接受放置。
- 页面内空选 Delete/Backspace/Ctrl+D 不操作整页；整页操作仍在总览提供。
- 删除、撤销、重做、转换、换父级后校正层级：优先跟随有效选中节点的父级，否则沿先前路径退到最近仍存在的容器。退出/重新进入页面重置为页根。

## 6. Design

编辑路径与选择是 Webview 会话状态，路径保留祖先 ID 以便删除后回退。纯函数统一路径解析、命中映射与放置坐标，使用现有模型父关系和共享布局矩阵。画布继续显示完整页面；导航明确当前编辑层级。顶部为导航预留空间，面板继续跟随页面并避让导航。

## 7. Implementation Plan

1. 实现并测试层级路径、命中映射、结构编辑恢复和局部放置。
2. 接入画布、树、导航与当前层创建/快捷键。
3. 验证浏览器交互，更新产品/布局基线与本记录。

## 8. Testing Plan

纯函数覆盖 Slider/嵌套容器的逐级命中、跨分支/自身背景、树直达、删除/重挂/转换回退、变换与滚动下放置及锁定保护。执行 npm test 和 npm run build。当前没有 DOM 组件测试环境，通过本机预览验证双击事件顺序、导航、树快捷选择、清空/返回、复制/放置/删除/撤销和焦点回归。

## 9. Acceptance Criteria

- [x] 单击音量滑块先选 UISlider，双击后才可选 UIImage；多层容器可逐层进入。
- [x] 空白单击只清空，双击退一级；页根双击空白不退出页面。
- [x] 导航可跳祖先，树可直达任意节点且属性/选框一致，相机不变；容器层背景压暗、当前子树保持明亮，页根恢复。
- [x] 当前层新增/粘贴正确，空选删除不删整页，结构变化后路径有效。
- [x] 测试、构建和浏览器验收通过；现有键盘焦点修复保留。

## 10. Risks and Rollback

双击前有两次 pointerdown，需使用同一层命中规则，避免提前进入或把父背景误认作可选节点。矩阵不可逆时拒绝放置。回退只涉及 Webview 状态与界面，无文档迁移。
