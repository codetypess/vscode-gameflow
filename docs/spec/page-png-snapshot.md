# 画板 PNG 快照

Status: Done
Date: 2026-11-27

## 使用场景

策划希望把正在编辑的单张原型画板发给他人查看。总览中的画板右键菜单已有重命名和 PSD 操作，增加“另存为 PNG 快照…”作为直接保存图片的入口。

## 行为与实现

- 在“重命名画板”下方显示入口，操作对象是本次右键的画板。
- 按画板设计尺寸栅格化当前资源显示模式下的可见内容，包括已经应用到画板的编辑、组件实例、文字和图片。背景透明时保留 PNG 透明通道。
- Webview 从实际绘制的画板内容生成图片，保留布局和 Canvas 资源像素。相机、画板标题、选择框、容器辅助线和浮动面板在导出范围之外。
- VS Code 使用原生保存对话框，默认文件名取自画板名称。浏览器预览使用 PNG 下载。取消和写入失败均保持原型文档及历史。

## 实施与验收

1. 接入画板菜单和 PNG 保存流程，验证文件类型、建议文件名、取消及失败反馈。
2. 在浏览器使用多个画板验证右键目标、缩放后的原始像素尺寸、图片与文字、透明区域及辅助线排除。
3. 运行共享测试与生产构建。回退可移除菜单项和 PNG 输出分支，已有画布文件继续按原格式读取。

## 验证记录

- 417 项共享测试和生产构建通过。保存测试覆盖取消、选择其他扩展名、写入失败保留旧图和重试成功。
- Edge 在双倍设备像素比下从右键菜单下载 PNG，核对了设计尺寸、透明通道、文字、内置 Canvas、嵌入图片和辅助线。
- 「星海远征 · 登录」导出为 750 × 1334 像素，和相同尺寸的画板截图比对，所有像素各通道差值均在 10 以内。生产构建在与扩展相同的内容安全策略下通过了模拟宿主取消和重试验证。
