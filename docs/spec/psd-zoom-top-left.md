# PSD 缩放条左上布局

Status: Done
Date: 2026-11-18
Scope: PSD 切图画布缩放条与跟随面板布局。

## Behavior and design

- 将底部居中的 PSD 缩放条移到画布左上角，复用原型工作台的 canvas-top-controls / canvas-zoom / toolbar-button 外观和响应式定位。普通视口距左 16px、距上 12px；800px 及以下均为 8px。外框高 34px、内边距 3px、图标按钮 25×26px、比例位宽 38px，并显示适应窗口按钮前的分隔线。
- 保留 PSD 的缩小、点击比例恢复 100%、放大、适应窗口行为及可访问名称。比例仍为按钮，字号、占位尺寸与原型保持一致。缩放条不随 PSD 缩放或平移，控件操作不启动画布手势。
- 跟随面板和初始适应在顶部预留 48px，与原型工作台一致；维持两侧等宽、视口内钳制和内部滚动，避免缩放条盖住面板。
- 仅改变临时视图，不修改配置、导出、PSD 数据或历史。

## Acceptance and verification

1. 使用同一浏览器分别测量原型与 PSD 缩放条、图标按钮和比例区，验证普通及窄窗口的位置和尺寸一致。
2. 使用真实 PSD 验证缩小、放大、100%、适应窗口及平移后缩放条位置不变，顶部面板不相交。
3. 现有 PSD 布局测试补充顶部保留区断言，运行共享测试、生产构建和 diff 检查。

## Verification results

- `npm test` 322 项共享测试通过，既有 PSD 布局测试补充顶部 48px 保留区及标题适应断言。
- `npm run build` 通过，包含宿主/Webview TypeScript 检查；保留既有 Vite 产物体积提示。
- 1280×720 浏览器中，对照原型与 PSD：外框均为 130×34px，图标均为 25×26px，比例位宽均为 38px；相对画布坐标均为 (16,12)。
- 520×760 窄视口对照：两者坐标均为 (8,8)，尺寸保持 130×34px，PSD 面板与控件不相交；测试后已恢复默认视口。
- 真实 PSD 点击比例得到 100%，放大为 120%，缩小回 100%，适应为 70%。拖动 PSD 上移 220px 后缩放条保持原位，两面板停在顶部保留区下方。
- 控制台无 error；最终截图 psd-zoom-top-left.jpg。本次不涉及原生保存流程，未重复 Extension Host 联调。
