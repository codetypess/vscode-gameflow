# 顶栏原型图切换

Status: Done
Date: 2026-11-25

## 交互

进入原型的页内编辑后，点击顶栏「总览 /」右侧的当前页名，可按文档顺序查看本文件的所有原型图。列表用勾标出当前页。选择其他页直接进入其根层，画布适应目标页，图层树与属性面板同步切换。再次选择当前页或取消菜单时保留当前选择和视角。

## 实现与验收

- 复用顶栏的下拉菜单组件，按页面 ID 调用已有的进入页面操作。页面切换属于视图导航，不写入文档历史。
- 验证鼠标切页、键盘选择及 Escape 关闭。检查窄窗口仍可打开列表，长名称可辨认。
- 跨页后点击「总览」应回到进入页内编辑前的视角。

Chrome 交互测试已覆盖按文档顺序列出页面、当前页标记、重选当前页、键盘切换、Escape 关闭、360px 窗口切换以及返回总览时恢复视角。生产构建通过。
