# 引擎产物说明

`engine/` 下的内容全部是 LayaAir 引擎编译生成的产物，不是本项目维护的引擎源码：

- `engine/libs/`：引擎编译后的 JavaScript、Source Map 和 WebAssembly 文件。
- `engine/types/`：引擎编译生成的 TypeScript 声明文件。

## 修改规则

禁止直接修改、格式化、补丁式编辑或手工替换 `engine/` 下的任何文件。这里的文件必须与同一版本的引擎构建结果保持一致，直接修改会在下次构建时被覆盖，也会导致产物无法追溯。

如果需要修复或调整引擎行为，请修改引擎源码仓库或维护对应的引擎构建补丁，再通过工具重新构建并生成本目录产物。具体流程见 [核心架构中的引擎构建说明](../docs/spec/core/架构.md#引擎构建)。
