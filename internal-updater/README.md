# Bit 内部插件更新器

首次安装此 VSIX 后，会自动识别当前本地 Profile 已安装的原型工作台（原 GameFlow）和其他内部插件。也可以在命令面板执行 **Bit 内部插件: 浏览与安装插件**，安装其他工具。

无需手动加入检查。启动约 30 秒后检查，之后每六小时检查；手动安装新的内部插件时也会触发检查。更新器同时检查自身，目录里尚未安装的插件不会自动安装。

发现新版会显示插件名称、当前版本和新版本，并提供“安装更新”和“稍后”。点击“安装更新”后才下载、校验并安装；关闭提示或选择“稍后”会保留现有版本。更新器自身升级也需要确认。可以在“管理插件 → 更新模式”暂停全部自动检查，或在插件列表中单独暂停/恢复、固定版本和回退。暂停会在后续扫描和重启后保留。

从旧版升级后，原自动安装设置会改为确认后安装，已暂停的自动检查保持暂停。

更新不会主动重载窗口。VS Code 的信任提示和组织策略仍然生效。如需重载，请先保存文档，再使用 VS Code 的提示操作。

首版只支持本地桌面和 universal 安装包；在 Remote SSH、WSL、Dev Containers 或扩展开发环境中不会自动安装。

内网地址暂定 `http://vsix.bitserver.wang/`。更新器内置发布公钥，对目录验签、对安装包校验 SHA-256 和包内身份；首次安装请使用管理员交付的可信 VSIX。未来切换 HTTPS 可修改用户设置 `internalUpdater.serverUrl`，签名验证始终保留。
